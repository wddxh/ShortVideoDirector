# Series Mode: scriptwriter-script 专属指南

## 额外上下文读取
- 读 `story/episodes/{ep}/outline.md` (本集大纲，含场景列表 + arc 节点标注 + 集尾钩子)
- 读 `story/episodes/{ep}/novel.md` (本集小说原文，作为文学素材库)
- 读 `story/arc.md` (识别本集对应 arc 节点，保持人物弧延续)
- mode='continue-series': 可参考上一集 `story/episodes/{prev_ep}/script.md` 末场景，保证开场承接自然

## 处理原则

### novel 作为文学素材库
- novel 是本集的**完整文学叙事**，承载对白细节、内心独白、情感纹理、视觉氛围
- scriptwriter 的职责: **提炼 + 转译**为可拍摄剧本，**不简化、不抛弃**
  - 对白: 从 novel 角色对话中提炼出最具戏剧张力的台词，保留角色声音特征
  - 动作: novel 中的动作描写转化为可拍摄的角色行为
  - 视觉细节: novel 中的环境/道具/光线描写提炼为"视觉摘要"字段
  - 内心独白: novel 中的心理描写转化为剧本内心独白 (主角优先)
- **不是照搬**: 不要把 novel 段落整段粘贴进"场景内容"。要重组为剧本结构 (动作 + 对白 + 反应交织的 prose)

### 与 arc 节点对齐
- outline.md 的"在 arc 中的位置"字段标注了本集应推进的 arc 节点
- 每个场景必须服务于该节点的推进 (冲突升级 / 关系转折 / 信息揭示 / 人物弧位移)
- 若某场景无法关联到 arc 节点推进，须重新评估该场景是否冗余

### 集尾钩子落地
- outline.md 末尾"集尾钩子"必须在剧本最后一个场景中**具象化呈现** (画面 / 对白 / 动作)
- 不要把钩子写成旁白或字幕

## Series 专属失败模式 (须主动规避)

1. **忽视 novel**: 剧本不参考 novel 的对白/情感细节 → 失去 novel 文学层价值
2. **与 arc 节点脱节**: 剧本场景不服务本集 outline 标注的 arc 节点推进
