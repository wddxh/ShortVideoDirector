# Short Mode: scriptwriter-script 专属指南

## 额外上下文读取
- 优先读用户剧本或故事材料；已有 outline / novel 与本次改编有关时参考，不要求先生成。
- 单集表达按已确认意图成立，可以闭合、开放或片段式呈现；不因 short 模式强行封闭结局，也不拒绝相关文学素材。

## 处理原则

以下按委托和材料缺口选用；可先整理成熟场景，也可先试写关键选择，不要求固定阶段顺序。配置使用 SVD_CONFIG（未设时 config.md）。

### 按材料成熟度采用或展开
- 有 outline 时参考场景功能、冲突和关键信息；无 outline 时从委托组织可拍场景，成熟剧本保留合适内容
- scriptwriter 的职责: 将每个场景从"概念描述"展开为"可拍摄剧本":
  - 视觉摘要: 提炼场景的画面焦点 (构图 / 对比 / 符号道具)
  - 场景内容: 用 prose 风格写出角色动作 + 对白 + 反应 + 音效融合的连贯叙事
  - 对白 / 内心独白: 基于人物关系、冲突及可用文学素材设计，保留角色声音

### 时长目标硬约束
- 时长以用户确认的实际配置与严格边界为准，不以模式模板估定
- 场景总时长**必须**落在 config 时长目标范围内
- 保存后按 rules.md 实跑 `scripts/scene-duration.sh`；FAIL 在授权内调整或报告冲突，不自动扩大范围或拉长目标
- 建议: 写完每场景立即估算时长 (对白密度 + 动作节奏)，避免最后超目标整体重写

### 开场、节奏与结尾意图
- 行动驱动短片可试用“迫切问题或反常画面 → 尝试带来变化 → 关键选择 → 情感反应”的节奏草图。把“和解”落到收下钥匙、停下离开的脚步等具体行为，并给对方反应留时长；也可从结果回溯，或以声音和意象承载抒情，草图不是四场配额。
- 第一个场景具象化已确认的开场意图；可直接进入冲突或跳跃式开场，但给出理解处境所需的线索。节奏角色描述实际功能，不限定为“开场”或“铺垫”；有 outline 时核对策略。
- 铺垫、冲突、高潮、收束用于诊断信息、因果与情绪推进，不要求独立成场、固定顺序或四段闭环；高潮出现时应有足够动作与情绪支撑。
- 最后场景给出意图可辨的情感落点：观众记住的画面、台词、情绪或问题。有意开放结尾可保留悬念与解释空间，不等于未完成；检查留白有无铺垫及必要因果，而非强补答案。有 outline 时核对结局设计。

1. **时长目标失配**: sum(场景时长) 超出 config 时长目标范围
