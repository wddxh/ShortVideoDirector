# Short Mode: scriptwriter-script 专属指南

## 额外上下文读取
- 读 `story/episodes/{ep}/outline.md` (本集大纲，含场景列表 + 开场策略 + 结局设计)
- **无 novel**: short 模式不经过 novel 中间产物，scriptwriter 直接从 outline 展开
- **无 arc**: short 模式无跨集人物弧，单集自闭合

## 处理原则

### 直接从 outline 场景列表展开
- outline.md 的"场景列表"已给出每个场景的节奏角色 + 核心冲突 + 关键信息
- scriptwriter 的职责: 将每个场景从"概念描述"展开为"可拍摄剧本":
  - 视觉摘要: 提炼场景的画面焦点 (构图 / 对比 / 符号道具)
  - 场景内容: 用 prose 风格写出角色动作 + 对白 + 反应 + 音效融合的连贯叙事
  - 对白 / 内心独白: 直接基于 outline 给出的人物关系与冲突自行设计 (无 novel 可参考)

### 时长目标硬约束
- short 模式时长目标通常较紧 (config 标注，如 "3-5 分钟")
- 场景总时长**必须**落在 config 时长目标范围内
- Phase 6 自检通过 `scripts/scene-duration.sh` 严格校验，FAIL 必须回 Phase 4 调整
- 建议: 写完每场景立即估算时长 (对白密度 + 动作节奏)，避免最后超目标整体重写

### 单集自闭合
- 开场策略 (outline 顶部) 必须在第一个场景中**具象化呈现**: 不靠"下集承接"，第一秒就要抓人
- 结局设计 (outline 末尾) 必须在最后一个场景中给出**情感落点**: 不是"故事结束"，而是观众离场时记住的画面 / 台词 / 情绪

## Short 专属失败模式 (须主动规避)

1. **时长目标失配**: sum(场景时长) 超出 config 时长目标范围
