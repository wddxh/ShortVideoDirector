# Short Mode: reviewer-review-script 专属指南

## 额外上下文读取
- 本轮 STATE 绑定的实际配置、相关资产与已确认素材；outline 仅存在且适用时读取，不补造规划文档。本文配置均指显式 SVD_CONFIG 经 start 绑定的路径。

## Short 专属 review 项

1. **单集戏剧弧与意图**
   - 铺垫、冲突、高潮、收束是诊断方法，不强制四段顺序或闭环；开放结尾、悬念和片段式表达按确认意图判断
   - 本片在需要时提供身份/关系、处境、欲望、利害与规则依据，不能依赖不存在的前集或未来补课；冲突开场与慢热均按实际理解判断
   - 结尾需要有意图可辨的情感落点，不把有意留白判成漏写
   - 首场景节奏角色应准确描述实际叙事功能，允许跳跃式开场
   - 关键情绪转折应有足够触发与反应支撑；一句有铺垫的台词或有意义的沉默也可完成高潮
   - 铺垫长度应足以传达必要信息，不按秒数孤立判断

2. **开场策略具象化**
   - 开场是否以画面 / 对白 / 动作实现已确认意图；存在适用 outline 时，对照其「开场策略」
   - 不能是"用紧张刺激场景吸引观众"等空话翻版
   - 开场宜尽早建立关注点或感官吸引力，例如明确欲望、反差或悬而未决的动作；慢热可服务意图，不设第一秒门禁

3. **结局情感落点**
   - 剧本最后一个场景是否给出符合已确认意图的**情感落点**: 观众离场记住的画面 / 台词 / 情绪；存在适用 outline 时，对照其「结局设计」
   - “故事结束”不能代替实际表达；离开、沉默或一个短答若有前文支撑也可完成情感落点，不凭动作字面判潦草
   - 适用 outline 已声明结局类型时，与剧本结局段落的画面 / 动作核对 (类型字段说"反转"但剧本只是"主角揭露真相"，没真反转 → 打回)
   - 核对本片所作的情感/信息承诺及结尾支撑；自足不等于全部解谜，不强制首尾形式呼应或关闭已确认的开放问题

4. **时长目标硬约束**
   - `scene-duration.sh` 必须 PASS (range 由 config 时长目标决定)
   - FAIL 时优先列入意见，比节奏曲线美感更高优先级

## Short 专属失败模式
- **单集体验失据**: 铺垫/冲突挤掉必要反应，或将本片理解必需的信息推给假定续集；开放结尾本身不是失败
- **戏剧弧断裂**: 必要动机/因果缺失，或结尾背离已确认意图
- **开场策略空话化**: 第一场景未具象化策略，写成"紧张场景"
- **结局类型 / 描述脱节**: 适用 outline 已声明"反转"但剧本无真反转
- **结局仅完成事件**: 写成"故事结束"，无观众离场记忆点
- **时长 FAIL 被忽视**: 模型靠"节奏感"判断，忽略 scene-duration.sh 硬数据
- **第一场景节奏角色错位**: 标注与实际功能不符，造成错误时长或内容安排
