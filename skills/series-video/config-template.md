准备写入前运行 `video-task-inputs.mjs profile TASKS`，使用实际 SVD_CONFIG（未设时 config.md）。持久快照缺项/冲突、固定配置与继承不一致或 provider=none 均停止新准备/付费，不补造值，查询下载仍可用。Task 身份/成员、派生时长、内容、引用及 grants 不从 profile 继承；集总时长由初始用户目标跨集共用。不得为换型删除快照；系列准备串行，本集锁不是跨集事务。四元组只保存在任务 submission，不设额外注册表。

## 参数选择授权

此处记录参数裁量，不是额外许可。series 本集请求包含所需新增资产图和本地参考，真实配置、intake/审核满足后执行，始终停在付费视频提交前；后续手动 generate-video 请求才登记 initial grant。不重复许可握手或自动改固定值。图片制作含同范围恢复重试、必要修复/重生和独立复审，无默认轮次上限；用户明确次数、范围、检查点及费用限制优先。按共享规则诊断进展，不盲目无限尝试，真实阻塞只停受影响工作。视频独立遵守 grants/次数。

必要选择尽早逐题解决。原角色一次提供全部相关问题/表、明确题界、完整选项/解释、稳定标签和分支。主 AI 内部保留全表，仅沿作者题界完整展示当前题后用可用原生键盘选择器，questions 恰好一项；相关原始答复及条件批量回原角色，不逐题往返。仅缺内容/映射、不相容或计划外决定才提前回询，不有损改写或倾倒全表。Markdown 不替代可用控件，宿主限制须明说。已答/已定/已委托字段不重问，后续艺术细节由 owner 决定，范围内修复/审核不逐轮批准，也不追加启动确认。

复用固定/继承/已委托设置，续集沿用 profile。Creator 只读查询能力，给齐 images/video 的 provider -> model -> 相容 ratio -> resolution、全部具体值/解释、逐字段委托选项及分支。主 AI 只按作者条件逐题询问；委托模型需解析且无后续分支时先回 Creator。跳过已答/继承/委托项，横屏不等于数值比例；不存静态模型表，不隐藏选项。

用户选定模型即按可访问处理，不查权益/会员/凭据/账号/积分，不索证明或要求确认访问不确定性声明。仍验证当前 CLI/API 技术组合与工作流接入，不声称访问已核实或生成成功。按选定参数使用，不做预算/余额/最低价前置、不为省钱降级；用户明确限制有效，仅授权执行实际返回账号/provider 错误时报告并处理必要决定，不换固定模型。示例不是用户决定，不复制为授权或执行值。
仅在实际授权后保存一个 JSON 块，例如：

```json
{"decision":"用户允许Creator选择资产图片比例和分辨率","delegated":{"images":["ratio","resolution"]}}
```

scope 为 images/video；字段为 provider/model/ratio/resolution。缺失、空值或 auto 不授予自主权。固定值冲突先澄清；图片比例与视频比例分别选择。任务选择留在任务中，不提升为默认。上方注释只说明字段，启用时填写实际值。

## 创作配置

剧情未指定但基本意图足够时默认三个展开候选故事，每个含人物动机、冲突、推进和结局，作为当前单题全部展示后选择，可委托 Director。明确候选数、已有剧本/方向/选择委托优先，续集不重开已定方向；不先问谁决定，不以类型标签代剧情。无关技术设置不阻塞候选探索；正式剧本/资产仍待相关选择已知或委托。此默认仅指未指定数量的剧情探索，不将下方风格/时长示例变为默认。

具体创作（包括预览材料）前按 `${CLAUDE_PLUGIN_ROOT}/skills/_meta/rules/user-decision-relay.md` 复用已知需求，只问必要缺口或让用户明确委托责任角色决定。将实际决定、角色、范围和约束记入配置说明/委托，不增加状态 schema。沉默不是授权，受托艺术细节可留待创作；初始共同集时长仍由用户确认。风格、数量、时长示例均不是启用默认，只有实际选择才去注释填写。
# - 总集数: 用户确认的整数 N>=2，无默认值
- 语言: auto                 # auto(跟随输入语言) / zh / en / 自定义
# - 每集分镜数: 用户固定值或明确委托 Storyboarder 按叙事决定
# - 每集时长目标: 用户确认的单值或允许范围（注明单位；正式制作前填写，无默认值）
# - 单镜头时长范围: 用户限制或明确委托按叙事在集时长边界内分配正整数秒
- 上下文集数: 1              # 续集选择相关前集剧本与来源材料的参考范围
- 默认模式: default           # default / full-auto

第一集开始时由用户确定原始集总时长，全部集共用，不按本轮或前集实际时长滚动继承。已有明确配置复用，缺失先问，模板不是决定。单值初次设置说明并确认 ±10% 创作预算及秒数边界；owner 可主动用于揭示、倾听与反应，不只是完稿容错。精确值按相等上下界，更严格限制优先，显式范围不放宽。本段保留原始目标与确认边界，不用调整后的合计覆盖基准。范围内由 Director 协调 owner 更新 canonical script/storyboard 和受影响参考/manifest，无需逐次许可；既有任务与授权记录仍受保护。

每集分镜数是规划参考，用户固定值仍绑定。摄影 shot 按叙事分配正整数秒，可用短镜；provider 最短/70% 目标仅用于 Creator 设计后装组的生成任务。装组保留当前 canonical 时长、对白和切点；不适配按上述预算由 Director 协调 owner 重设计，不在装组中偷加秒，参数裁量不改变用户基准。仅查看配置不建文件或填目标。

## 制作前确认记录（按需）

outline、arc 是按需要选择的规划材料；缺少它们不阻止常规制作。用户小说、章节和节选按实际路径与采用范围作为 Scriptwriter 改编输入。
仅当用户要求先看材料时，由用户交互上下文在本配置中增加独立的
`## 制作前确认 epNN` 段，段内只放一个 fenced JSON（语言标记 `json`）：

```json
{"episode":"ep01","required":["outline"],"approval":null}
```

`required` 只允许 outline、arc，分别指本集 outline.md 和 story/arc.md。
required 中的未知类型阻塞正式制作，不静默过滤或自动批准。详见 [制作前确认](../director-orchestrate/SKILL.md#来源与制作前确认)。
缺失、空白或尚未批准的指定材料阻止正式制作。
实际确认后，用户交互上下文将 approval 写为
`{"decision":"保留用户实际确认内容","inputs":[...]}`；inputs 使用
`node "${CLAUDE_PLUGIN_ROOT}/scripts/review-evidence.mjs" fingerprint PATH...` 返回的 path/sha256 对。
确认前后核对相同输入；材料变化后需重新确认。审核通过不能代替用户确认。
无请求时保留本说明即可，勿创建 episode-specific 记录。
图像提供方 none 仅禁新图片提交；必需图仍须存在且审核有效。`task-inputs/taskNN.json` 草稿恰为 `{shots,references}`，最终恰为 `{shots,references,prompt}`，含 Creator 编写的非空白最终 prompt；草稿不就绪。每生成任务至少一个全组 MP4，静态段可用 clip，sources 不上传。独立 shot-input 审核最终 prompt 源忠实度、完整性、集成、内部切点/声音桥及必要跨镜/跨集边界；部分选组报告完整成员/额外镜头，不扩授权。None 不豁免材料。
