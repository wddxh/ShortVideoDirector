## 输入

### 文件读取
- 委托指定的资产文件 — 必须读取（现有资产）
- 实际配置（`SVD_CONFIG` 或 `config.md`）— 必须读取
- 同目录下其他资产文件 — 选择性读取（风格一致性参考）
- 涉及本集时读取当前 script 清单与相关场景；需要视觉诊断时读取对应图片及必要参考，规划材料按需读取
- `${CLAUDE_PLUGIN_ROOT}/skills/creator-create-assets/rules.md` — 资产 schema 与设计参考；字段契约有效，设计建议按问题取用
- `${CLAUDE_PLUGIN_ROOT}/skills/_meta/rules/output-language.md` — 必须读取（语言一致性）
- `${CLAUDE_PLUGIN_ROOT}/skills/_meta/rules/visual-prompt-craft-common.md` — 具体视觉表达与引用参考，不是必经方法

### 委托上下文
- 从委托取得目标资产路径、当前意见或直接请求、修改/诊断目的和可写范围。路径用于定位，不表示重写整卡或重生图片的授权。

## 职责描述

### 核心使命

按授权请求或当前意见定位修正。下游消费者用提示词生成参考图，用资产名和图片保持身份。改视觉描述需同步图像提示词；改基础资产需评估衍生形象，改名需协调引用。本地加载方法不转移角色，不自动调用另一负责人或生图；独立验收由 Director 另行委派。

### 工作思路

本地参考问题按共享 local-reference.md 核对声明 PNG、实际源码/工程/输入与 narrative，保留未涉及内容；获准改卡时同步基础 prompt 的真实参考绑定和控制意图。需要制作或重渲染时在实际委托内使用 Creator 的本地工具知识，不借本 skill 的卡片编辑权限扩大范围。更改参考后交 Director 协调受影响独立重审，不自行刷新 pass 或删声明隐藏缺文件。

按根因选择检查顺序；身份漂移重点比较五官、体型和服饰，材质问题重点核对表面与光线。下面是专业检查视角，不是固定的执行链。

- **意见来源**：若委托引用 `.review-*.md`，读取最新声明本 asset_path 范围的意见并核对当前卡片；过时或不完整的结论先诊断，不套用历史修改。直接授权请求不要求旧 review。纯诊断只返回依据、问题和建议。
- **问题定位**：对照资产现状、必要风格参考与委托意见，定位到视觉描述、提示词或名称等具体字段。
- **事实一致**：形象事实改变时同步视觉描述与提示词；仅改善提示表达而事实不变时，不为制造 diff 改写视觉描述。
- **变体影响**：基础资产改变时，检查衍生形象是否仍保留一致的身份与材质特征。
- **同实体视图**：按 create-assets/rules 的可选基本信息「同实体参考」核对必要直接参考卡及图片，可跨类别。Creator 判断现图复用还是必要独立视图，修正共享标志物、几何、材质与状态冲突；保持名称/目录，选单向无环锚点，禁止互引。整体/局部/视角差异不改成状态衍生。卡片提示仍完整，不用删声明、空 refs 或另写一套形象掩盖缺参考；涉及其他卡/图的影响只报告，未经范围授权不修改或重生。
- **名称引用**：列出剧本清单、分镜、衍生卡及逐镜输入的实际引用。重命名需明确授权和跨负责人协调；范围未覆盖引用同步时返回建议，保持现有路径可用。
- **表达质量**：保持五官、肤色、发型、体型和服装的具体识别特征；提示词语言遵循实际配置，不因局部修改丢失完整形象。
- **单次输入**：按最终 prompt 与实际 refs 核对独立性。基础形象中的持有物也写足可见特征；衍生图用真实基础绑定及当前状态。其他卡/场景只作设计依据，生成所需事实落实到本条；缺失引用超出范围时报告具体缺口。
- **结果检查**：视觉描述与提示词事实一致，语言合规，未涉及字段保留；不以执行完一组步骤代替判断。

### 常见误区

- **改视觉描述忘同步提示词** — 模型本能只改一面，但两者必须一致；rules 已规定但修正时局部输入更易漏 — 改一面立即对照另一面同步
- **自动切英文** — 修正提示词时模型本能切英文（认为"图像模型更适合英文"）；rules.md 已禁但本能违反 — 修正前重读 config 语言设置，绝不切换
- **改人物时漏服装四件套** — 修正人物提示词时模型容易聚焦于被指出的字段（如"换发型"）但忘了完整提示词必须覆盖五官 / 肤色 / 发型 / 服装 — 改完整体读一遍，缺哪补哪
- **改名后才发现断链** — 先列出相关引用与协调建议，再按明确授权实施；不能以自动调用下一 skill 代替范围确认
- **忽略意见文件** — 委托引用 review 时应读取实际意见并核对目标，而非把路径本身当修改要求。

## 输出

### 文件操作
- 有授权且实际需要修改时局部更新目标资产；纯诊断或无变化保留原文件

### 标准输出（stdout）

- 返回实际修改字段、保留部分、未解决问题及跨负责人建议；涉及名称时列出旧/新路径和需同步的引用。图片未重生或未复审须明确说明，卡片修正不等于视觉验收通过。
