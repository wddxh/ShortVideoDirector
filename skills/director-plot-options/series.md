# director-plot-options — series mode 专属指南

适用 mode: `new-series` | `continue-series`

## 相关上下文

- 优先读委托材料；已有 arc / 全局摘要只取相关规划。
- 续集读取能说明当前角色状态、冲突和伏笔的前集 script；人物声音或文学改编需要时再读相关 novel。按 `上下文集数` 选取参考范围，不全量读取历史。

## 模式细分

- **new-series**：新系列可比较不同剧概念，数量与比较维度服从委托。
- **continue-series**：委托为续集方向探索时，可比较稳健 / 激进 / 拓展的演绎；尊重既成事实及已有阶段目标。是否新系列不由 outline 文件是否存在决定。

## 候选表达参考（按比较目的选择）

基本主题/前提/期待体验足够即可探索，不要求先选剧情或解决无关技术设置。未指定剧情且未指定数量时默认三个完整故事；明确数量、已有剧本/方向/委托优先，续集不重开已定方向。以下 craft 示例不提供用户意图或固定节奏；真缺口按共享 relay 逐题询问，不先问谁决定，不设费用门槛。

剧情选择一题包含三个候选的全部动机、冲突、推进与结局/本集落点，不是类型标签。原角色一次给齐相关问题、完整解释、稳定标签及题界/分支。主 AI 内部保留计划，沿作者题界完整展示当前题后原生单选加委托，相关原始答复/条件批量回原任务；仅缺映射、不相容或计划外决定等共享规则例外才提前回询，不有损改写或倾倒全表。宿主限制按共享映射披露，局部修订不强制重写整组。

### 让续集带来新后果

连续行动线可比较**递进（前次行动使代价上升或可选办法减少）**：更高的损失、无法再用的退路、盟友关系改变，通常比不断增加更强敌人更有延续力。对每个重要揭示追问“谁因此改变判断，接下来采取什么行动”，给揭示余波留空间，避免揭晓后所有人恢复原状。

例如，调查者为获得证据隐瞒同伴；拿到证据却失去同伴信任，只能独自承担公开它的风险。稳健方向可修复信任，激进方向可让他继续隐瞒，拓展方向可转看同伴的选择。按委托选取有意义的比较，不要求三种齐备；单元剧可保留独立事件，通过关系变化积累长期回报。

```markdown
## 选项 X: {主题名称}
- **主题：** {一句话主题陈述}
- **人物动机与冲突：** {谁为什么行动、遭遇什么阻力或代价}
- **剧情节点序列：** {N1 → N2 → N3 → ... ; 每节点一句，含明线暗线主要事件}
- **主要角色弧：** {主角 / 关键配角的成长或转变曲线}
- **关键转折分布：** {需要时标注重要选择或反转所在集数，不限定数量}
- **结局/情感落点：** {推进如何抵达系列或本集结局，开放问题也说明落点，不只贴类型}
- **卖点分析：** {为什么适合短视频系列}
```

continue-series 候选可简化为:
- 关键转折 (本集核心冲突 / 反转)
- 涉及角色
- 集尾钩子
- 对后续剧情影响
有适用 arc 时呼应节点位置；否则说明对当前冲突、人物关系和待回收伏笔的推进。

## 诊断线索

- **节点推进弱**：关键事件缺乏因果或情绪支撑；节点数量本身不是质量依据。
- **转折分配不服务意图**：重要变化没有展开空间，或后续余波空洞；集中转折、单元式展开均可成立，不按位置配额判断。
- [ ] (continue-series) 候选无理由违背已确认的连续性或适用 arc 目标
