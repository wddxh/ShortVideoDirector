# director-plot-options — short mode 专属指南

适用 mode: `short` (单集短视频)

## 必读上下文 (在公共 Phase 2 阶段读取)

- 仅 `config.md` (公共 Phase 2 已读)
- **不**读 arc.md / outline.md / 历史 novel (single ep 无此概念)

## 每候选必含字段

```markdown
## 选项 X: {主题名称}
- **剧名：** {剧名}
- **主题：** {一句话主题陈述}
- **核心冲突：** {单集驱动力 — 谁 vs 谁 / 什么 vs 什么；必须强烈、具体、可视化}
- **情感落点：** {结局观众应留下的情绪 — 反转震撼 / 温馨治愈 / 黑色幽默 / 余韵悲凉 / ...}
- **节奏曲线：** {三幕节奏速写 — 开端钩子 → 中段升级 → 高潮收束；标明张力走向}
- **结局类型：** {反转 / 温馨 / 开放 / 幽默 / ...}
- **卖点分析：** {为什么适合单集短视频}
```

## 强制问用户 (Phase 4)

**short mode 不问总集数** (single ep；总集数概念不适用)。

Phase 4 仅呈现 3 候选并等待用户选择 / 提偏好。

## 自洽完整性

- 每候选须自洽完整: 开端 / 发展 / 结局齐备，可在单集时长内闭合
- 避免侵权: 禁止照搬已有影视的剧情结构 / 角色关系

## 专属失败模式 (Phase 6 自查清单)

- [ ] **核心冲突不强**: 冲突模糊 / 主角缺乏明确对手或目标 / 缺乏可视化对抗
- [ ] **情感落点平淡**: 结局未在某种情绪上达峰，仅是"事件结束"
- [ ] **节奏曲线倒置**: 高潮在前 / 中段无升级 / 收束拖沓导致张力下行
- [ ] 候选间差异仅在表面 (换名字 / 换场景) 而非结构 (冲突类型 / 情感落点 / 节奏)
- [ ] 误问"总集数" (本 mode 严禁)
