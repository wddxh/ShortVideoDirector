# director-plot-options — short mode 专属指南

适用 mode: `short` (单集短视频)

## 相关上下文

- 实际配置 `SVD_CONFIG`（未设时 `config.md`）与用户材料；若基于已有 outline、novel 或剧本，读取相关部分，保留用户要求的元素。
- 不引入无关的系列历史，也不因 short 模式拒绝采用小说素材。

## 候选表达参考

基本主题/前提/期待体验足够即可探索，不要求先选剧情或解决无关技术设置。未指定剧情且未指定数量时默认三个完整故事；明确数量、已有剧本/方向/委托优先。以下 craft 示例不提供用户意图或固定节奏；真缺口按共享 relay 逐题询问，不先问谁决定，不设费用门槛。

### 从人物处境到观众体验

人物行动驱动的短片，可先明确**戏剧目标（人物此刻想达成什么）**、阻力与**利害关系（得不到会失去什么，得到又要付出什么）**。把“想和好”具体化为“让母亲收下这把备用钥匙”；阻力可能是对方拒绝、自己的羞怯或错过见面的时间，不一定需要反派。这样候选才有可展开的行为，而非只有主题。

“开场钩子 → 递进 → 高潮/情感落点”是可用的节奏速写：开场用异常、迫切行动或关系反差引出问题；**递进（让尝试带来新后果、选择更难）**避免重复同一种阻碍；关键选择或认知改变形成高潮，再以具体反应留下情绪。它适合有明确行动线的短片，不是三幕数量或顺序要求。

例如：女儿把钥匙推过去，母亲退回；女儿解释却暴露即将远行，争执从“收不收”转为“还回不回来”；母亲最终把钥匙系在旧钥匙圈上。动作同时改变关系与观众感受。抒情片也可沿意象变化展开，回溯片可先呈现结果；只比较表达方式时保留原剧情，不为了套示例重构。

按请求数量或默认三个，以当前比较的差异选择表达。每个故事完整交代动机、冲突、推进和结局，不用类型标签替代。全部候选仍属一个选择问题，加稳定标签与委托；其他相关问题一次提供但单列题界/分支。主 AI 内部保留全计划，沿作者题界完整展示当前题再原生单选，相关原始答复/条件批量回原任务；仅缺映射、不相容或计划外决定等共享规则例外才提前回询，不有损改写或倾倒全表。下面示例保留 craft 参考，局部修订不必重填全部字段。

```markdown
## 选项 X: {主题名称}
- **剧名：** {剧名}
- **主题：** {一句话主题陈述}
- **人物动机：** {人物为什么此刻必须行动，得到或失去什么}
- **核心冲突：** {单集驱动力：人物目标、关系张力、内在矛盾或外部对抗；具体说明如何呈现，不强制敌手或激烈对抗}
- **情感落点：** {结局观众应留下的情绪 — 反转震撼 / 温馨治愈 / 黑色幽默 / 余韵悲凉 / ...}
- **节奏曲线：** {按候选意图说明注意力入口、张力变化和情感落点；三幕可作方法，也可高潮先行、回溯或片段式展开，不强制顺序}
- **结局类型：** {反转 / 温馨 / 开放 / 幽默 / ...}
- **故事展开与结局：** {具体尝试如何带来后果，关键选择怎样抵达结局；不能只填类型}
- **卖点分析：** {为什么适合单集短视频}
```

## 自洽完整性

- 每候选须在单集时长内表达清楚约定意图，有理解处境、动机和情绪所需的支撑。开放、悬念或闭合结尾均可；有意留白不等于漏写，不要求三幕齐备或解答所有问题。
- 素材采用按委托和实际授权判断，不因相似结构、角色关系或出现现实名称就断言侵权。具体权利疑虑或角色规则冲突按主指南交 Director / 用户确认，不擅自改名或重设计。

## 诊断线索

- [ ] **驱动力不清**: 人物目标、矛盾或关系变化无可辨依据；没有敌手或激烈对抗本身不是失败
- [ ] **情感落点失据**: 结尾缺少支撑约定感受或问题的表达；平静余韵与开放留白可以成立，不要求结尾情绪达峰
- [ ] **节奏不服务意图**: 必要处境或因果线索缺失、重复段落挤掉关键表达；高潮在前、中段不升级或张力回落本身不是失败，检查回溯、余波或留白是否有作用
- [ ] **差异未回应比较目的**：探索不同剧情方向时，仅换名字或场景可能不足；若委托只比较同一剧情的措辞、声音或表现方式，则评价该维度的有效差异，不要求改变结构、冲突或结局。
- [ ] 误问"总集数" (本 mode 严禁)
