# director-input-confirm — short mode

## 上下文加载

- `config.md` — 必读
- **不读** arc.md / outline.md / 历史 novel (单集短视频无系列上下文)

## 字段清单

### 输出格式

```markdown
## {主题名称}
- **剧名：** {剧名}
- **剧情概要：** {一句话概括完整剧情走向}
- **结局类型：** {反转 / 温馨 / 开放 / 幽默 / ...}
- **卖点分析：** {为什么适合短视频}
```

## 强制确认项 / 强制问用户

- **无 arc 提问**
- **无总集数** (单集短视频)
- 若用户材料涉及现实版权 IP，在确认说明末尾追加版权规避提示：
  - 建议改编人名、地名、设定
  - 列出需替换的具体元素

## 专属失败模式自查

- 出现 arc / 多集相关字段 → 失败 (应走 series mode)
- 涉及现实 IP 未加版权规避提示 → 失败
- 剧情概要超过一句话 → 失败 (短视频要极简)
