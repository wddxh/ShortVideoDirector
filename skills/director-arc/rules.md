# director-arc 规则

本文件由 `${CLAUDE_PLUGIN_ROOT}/skills/director-arc/SKILL.md` 强制读取。规定 `story/arc.md` 的输出 schema、节点集数标注约定与常见误区。

## 1. 输出 schema

```markdown
# {故事名} 叙事弧

## 总集数
{N}

## 故事核心
{核心主题、故事问题、本 arc 要回答什么；篇幅按实际需要}

## 剧情节点

### 节点 1: {节点名} (ep01-03, 节点预算 ~Zs)
- 核心事件:
  - {事件 1 一句话概括} (~Ns, 必需)
  - {事件 2 一句话概括} (~Ns, 必需)
  - {可选事件 一句话概括} (~Ns, 可选)
- 推进目标: {本节点结束时 arc 进度}
- 关键转折: {可选；若本节点含重要转折，在此描述并标 epXX}

### 节点 2: {节点名} (ep04-07, 节点预算 ~Zs)
- 核心事件:
  - {事件 1 一句话概括} (~Ns, 必需)
  - {事件 2 一句话概括} (~Ns, 必需)
  - {可选事件 一句话概括} (~Ns, 可选)
- 推进目标: ...
- 关键转折: ep07: {主角发现 X 真相}

### 节点 3: {节点名} (ep08-10, 节点预算 ~Zs)
- 核心事件:
  - {事件 1 一句话概括} (~Ns, 必需)
  - {事件 2 一句话概括} (~Ns, 必需)
  - {可选事件 一句话概括} (~Ns, 可选)
- 推进目标: ...
- 关键转折: {可选}

## 主要人物弧

### {角色名}
- 起点状态: {ep01 时}
- 关键转折:
  - ep03: {转折描述}
  - ep07: {转折描述}
- 终点状态: {arc 结束时}

### {角色名}
- 起点状态: ...
- 关键转折: ...
- 终点状态: ...

## 世界观要点
- {对全集叙事关键的设定 / 时空规则 / 关键关系}
- {……}
```

**保留字段**：总集数 / 故事核心 / 剧情节点 / 主要人物弧 / 世界观要点。

示例中的节点、人物与转折数量不是配额；按委托和故事结构增减，不适用的内容说明原因，不凭空补造人物或反转。

**已删除字段**（与旧 schema 区别）：
- 节点的 `节奏角色` 字段 — 节奏归属单集 outline / scriptwriter，不在 arc 节点声明
- 独立的 `## 关键转折点 (跨节点)` section — 转折并入各节点的"关键转折"字段

## 1.5 节点预算秒数计算

节点 header 必须含 `节点预算 ~Zs` 字段，Z = 节点集数 × 每集时长上限。

先用 `bash "${CLAUDE_PLUGIN_ROOT}/scripts/read-config.sh" "每集时长目标" "${SVD_CONFIG:-config.md}"` 读取实际目标。`arc-budget.sh <ep_count>` 只读取工作目录的 config.md，不接受配置路径，也不识别 SVD_CONFIG；仅实际配置就是该文件且边界适用时可用它辅助计算。自定义配置按已确认秒数上限乘节点集数计算，不伪造参数或回退默认文件。

config `每集时长目标` 两种写法均支持：
- 范围 `3-5 分钟` / `60-120 秒` → 取上限
- 单值 `90s` / `4 分钟` → 直接取值

以上为工具解析规则；实际预算还须服从已确认的严格限制，不能从单值自动推定容差。系列各集沿用初始共同目标，不以前集实际时长滚动重设。配置缺失、冲突或边界不清先确认；节点上限不替代后续每集总时长的独立硬校验。

`节点预算 ~Zs` 字段格式严格：
- 数字 + s 字面
- 不可写"约 270 秒"或"~4.5 分钟"等其他形式

## 2. 节点集数标注约定

**每个节点 header 必须标注集数范围及预算**，例如：

```
### 节点 1: 铺垫 (ep01-03, 节点预算 ~900s)
### 节点 2: 冲突升级 (ep04-07, 节点预算 ~1200s)
### 节点 3: 收束 (ep08-10, 节点预算 ~900s)
```

约束：
- 集数编号统一两位数零填充（`ep01` 而非 `ep1`）
- 节点序列**首尾相接、无重叠、无 gap**
- 节点集数总和**严格等于** `## 总集数` 中声明的 N
- 单节点单集合法（如 `(ep05-05)` 表示该节点仅 1 集）

**用途**：使用 arc 规划时，通过集数范围定位本集节点，核对事件分配与连续性。该格式约束不意味着必须先生成 arc 才能制作剧本。

## 3. 阶段划分与节奏建议

三段式节奏可作为连续剧情的规划起点，比例不是所有系列的硬模板；单元剧可按各集独立问题与长期人物变化调整：

- **铺垫段**（约前 30%）：建立世界观、引入主要人物、埋设核心冲突的种子
- **发展段**（约中 40-50%）：冲突升级、人物关系变化、关键转折密集出现
- **收束段**（约后 20-30%）：高潮 + 大结局，回应"故事核心"中提出的问题

节点数量由阶段问题、人物选择和跨集连续性决定，不按集数套数量表。悬疑可围绕认知变化划分，单元剧可围绕独立问题与长期关系划分；不适合三段式时不强套比例。

### 节点规模示例

尚无分段思路时，可试排下表观察是否装得下关键事件，再按因果与表演空间调整。它是草案示例，不是推荐数量门禁或验收标准：

| 系列规模 | 一种试排方式 | 适用观察 |
| --- | --- | --- |
| 6-10 集 | 3 个节点 | 建立问题、尝试改变、承担结果是否各有空间 |
| 11-20 集 | 4-5 个节点 | 阶段目标或关系联盟改变时是否值得分段 |
| 21 集以上 | 5-7 个节点 | 长线伏笔与阶段兑现是否便于追踪 |

节点过粗时补内部事件与选择，不一定增节点；节点过碎时合并共同的阶段问题，不一定删事件。单元剧或短促实验叙事可完全不用此表，确认总集数与预算不变。

### 递进与铺垫回收

**铺垫与回收（先建立线索、习惯或承诺，后让它产生意义）**不只用于反转。前段角色拒绝求助，后段主动交出钥匙，也能兑现关系变化。回收既要有可辨依据，也要改变当下选择，避免为了“埋伏笔”堆无用物件。

连续剧情可沿“尝试 → 后果 → 新选择”安排**递进（代价、风险或抉择难度增加）**：成功也可能损伤关系，失败也可能换来认知。揭秘之后安排人物消化、行动或关系重新定位，让真相有后果。静态主角也可通过周围关系和处境的改变承载阶段意义。

## 3.5 核心事件 bullet 格式（强制）

节点核心事件字段格式：

- 必须改为 bullet 列表（不再是长 prose 段混合所有事件）
- **每事件必须**末尾加 `(~Ns, 必需|可选)`，两项缺一即 schema 违规
- 估时由 LLM 根据剧情复杂度自决，但不能省略
- "必需" = 节点剧情骨架，不可砍
- "可选" = 锦上添花，时长紧张时优先砍
- 单节点已估时 bullet sum 必须 ≤ 节点预算（含可选）

创作参考（非固定步骤）：
1. 先列必需事件并估时
2. 有独立叙事价值时才加入可选事件，不自动填满预算
3. 超预算可合并、删减次要事件或调整节点分配；不改已确认集数，不用降低估时或改标签假装解决冲突
4. 估时考虑表演、动作和信息理解所需空间；复杂事件与纯动作都按实际内容判断，不设统一秒数底线

例如，包含试探、揭示和关系反应的一段事件，可先试排 60-90s；包含进入、受阻和脱身的动作桥段可先试排 30-60s，再按实际节拍核对。只是写“追赶”或“发现”无法确定时长，一次瞬间察觉也可能很短；示例不是下限，更不能压过用户确认的集预算。

## 4. 人物弧要求

- 选择实际承担主题与关系推进的人物，不设配角或转折数量配额
- 变化型人物说明信念、关系、能力或处境如何在选择中改变；稳定型人物说明其价值如何被检验、代价如何显现，不强造性格转变
- 转折按故事需要分配；实际转折描述带 epXX 锚点，便于核对事件与角色认知

## 5. 常见误区（必须规避）

以下用于区分叙事诊断与格式/预算问题；创作者自检不替代独立审核：

1. **节点失去统筹价值**：节点过粗且没有内部推进，或逐集重复摘要而无阶段目标。10 集分 3 节点本身合理，问题在事件因果与人物变化是否支撑分配。
2. **节点集数分配失衡**：例如 8 集铺垫 + 2 集高潮 + 0 集收束 → 高潮被压缩、结局仓促。参考第 3 节"阶段划分与节奏建议"。
3. **人物表达空泛**：只说“更勇敢”而无选择、代价或关系依据，无法支撑约定情感；稳定型主角不等于缺乏人物弧价值。
4. **阶段失去作用**：前段转折后，后续既无余波、关系变化也无主题展开。检查后续表达是否有意义，不要求每节点反转或按全 arc 均匀分布。
5. **节点 bullet 格式违规** — 任何核心事件 bullet 缺 `(~Ns, 必需|可选)` 完整标记（含两项的标记顺序必须是 `(~Ns, 必需|可选)`，反序 `(必需, ~Ns)` 算违规）→ review FAIL（schema 违规, 报具体行号）
6. **节点剧情点超预算** — 所有事件估时 sum 超预算是硬约束失败。可合并重复事件、删除次要可选事件或调整节点分配，不改确认集数。拆细须保留真实估时；降级可选不减少 sum，核心取舍超授权先询问。

## 6. continue-series 额外要求

- 读取相关既有规划和已确认剧本；需要文学细节时补读相关 novel，不以缺少可选文件阻断规划
- 新生成的 arc.md 应包含已播出集数对应的回溯节点（保留既成事实），并向后延展剩余集数
- 已完成剧集的关键转折必须忠实反映已确认内容，不得用小说草稿覆盖最终剧本事实
- 新方向与已确认材料冲突时，指出具体集数、变化及伏笔影响，交 Director 协调授权；独立 reviewer 提供判断，不代用户决定改方向
