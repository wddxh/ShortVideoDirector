# director-arc 规则

本文件由 `skills/director-arc/SKILL.md` 强制读取。规定 `story/arc.md` 的输出 schema、节点集数标注约定与常见误区。

## 1. 输出 schema

```markdown
# {故事名} 叙事弧

## 总集数
{N}

## 故事核心
{1-2 段：核心主题、故事问题、本 arc 要回答什么}

## 主线 (A 线)

### 节点 1: {节点名} (ep01-03)
- 核心事件: {1-2 段}
- 推进目标: {本节点结束时 arc 进度}
- 关键转折: {可选；若本节点含跨节点的重要转折，在此描述并标 epXX}

### 节点 2: {节点名} (ep04-07)
- 核心事件: ...
- 推进目标: ...
- 关键转折: ep07: {主角发现 X 真相}

### 节点 3: {节点名} (ep08-10)
- 核心事件: ...
- 推进目标: ...
- 关键转折: {可选}

## 副线 (B 线)  — 可选

### 节点 1: {节点名} (ep02-05)
- 核心事件: ...
- 推进目标: ...
- 关键转折: {可选}

## 主要人物弧

### {角色名}
- 起点状态: {ep01 时}
- 关键转折:
  - ep03: {转折描述}
  - ep07: {转折描述}
- 终点状态: {arc 结束时}

### {角色名}
- 起点状态: ...
- 关键转折: ...
- 终点状态: ...

## 世界观要点
- {对全集叙事关键的设定 / 时空规则 / 关键关系}
- {……}
```

**保留字段**：总集数 / 故事核心 / 主线 (A 线) / 副线 (B 线，可选) / 主要人物弧 / 世界观要点。

**已删除字段**（与旧 schema 区别）：
- 节点的 `节奏角色` 字段 — 节奏归属单集 outline / scriptwriter，不在 arc 节点声明
- 独立的 `## 关键转折点 (跨节点)` section — 转折并入各节点的"关键转折"字段

## 2. 节点集数标注约定

**每个节点（主线、副线）的 header 必须以 `(epXX-YY)` 形式标注集数范围**，例如：

```
### 节点 1: 铺垫 (ep01-03)
### 节点 2: 冲突升级 (ep04-07)
### 节点 3: 收束 (ep08-10)
```

约束：
- 集数编号统一两位数零填充（`ep01` 而非 `ep1`）
- 同一线（A 或 B）的节点集数区间**首尾相接、无重叠、无 gap**
- 主线节点集数总和**严格等于** `## 总集数` 中声明的 N
- 副线（如有）首节点可晚于 ep01、末节点可早于 epN，但内部节点间同样首尾相接
- 单节点单集合法（如 `(ep05-05)` 表示该节点仅 1 集）

**用途**：continue-series 模式下，`director-outline` 和后续 pipeline 通过此标注严格定位 epXX 属于哪个 arc 节点，从而正确生成"在 arc 中的位置"字段。arc 节点 gap 由 `director-review-arc` catch。

## 3. 阶段划分与节奏建议

虽然不在节点层声明"节奏角色"，但 arc 整体仍需遵循三段式节奏：

- **铺垫段**（约前 30%）：建立世界观、引入主要人物、埋设核心冲突的种子
- **发展段**（约中 40-50%）：冲突升级、人物关系变化、关键转折密集出现
- **收束段**（约后 20-30%）：高潮 + 大结局，回应"故事核心"中提出的问题

总集数与节点数推荐对应（仅参考，复杂故事可调）：
- 6-10 集 → 3 个主线节点
- 11-20 集 → 4-5 个主线节点
- 21+ 集 → 5-7 个主线节点

副线节点数建议 ≤ 主线节点数，避免反客为主。

## 4. 人物弧要求

- 至少为主角与 1 名核心配角生成人物弧
- 起点状态与终点状态必须有**可观察**的差异（信念 / 关系 / 能力 / 处境之一发生改变）
- 关键转折至少 2 个，分布在不同 arc 节点上
- 转折描述带 epXX 锚点，便于 outline 阶段对齐

## 5. 常见误区（必须规避）

以下 5 类错误是 arc 规划阶段最常出现的失败模式，每条都会在 `director-review-arc` 阶段被 catch：

1. **总集数与节点数失配**：例如 10 集 arc 但只规划 3 个节点 → 单节点平均 3+ 集，节奏稀疏、推进无力；或 6 集 arc 切 6 个节点 → 节点退化为"单集大纲"，arc 失去骨架价值。
2. **节点集数分配失衡**：例如 8 集铺垫 + 2 集高潮 + 0 集收束 → 高潮被压缩、结局仓促。参考第 3 节"阶段划分与节奏建议"。
3. **人物弧深度不足**：起点和终点状态描述几乎一致（"由勇敢的少年成长为更勇敢的少年"）→ 主角"未成长"，arc 缺乏情感推进。必须给出**可观察的差异**。
4. **关键转折分布失衡**：所有关键转折集中在 ep01-03，后期节点空白 → 中后段叙事张力骤降。转折应分布于全 arc，每个节点至少有 1 个推进动作。
5. **A 线 / B 线脱节**：副线人物与主线人物无交集，副线事件不影响主线走向 → 副线沦为"独立小故事"。副线必须在 arc 中至少 1 次显式服务主线（提供关键信息 / 制造障碍 / 推动主角抉择 / 反衬主题）。

## 6. continue-series 额外要求

- 必读 `story/outline.md` 与最近 M 集 novel.md
- 新生成的 arc.md 应包含已播出集数对应的回溯节点（保留既成事实），并向后延展剩余集数
- 已播出集数的"关键转折"必须忠实反映 novel 中已发生的事件，不得改写
- 若用户在 plot-options 阶段提供的剧情方向与既有 outline 冲突，应在 arc.md 顶部加 `> 注意：本 arc 与 epXX outline 在 {点} 存在调整` 提示，由 review 阶段决断
