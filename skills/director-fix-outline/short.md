# Short Mode: director-fix-outline 专属指南

## 额外上下文读取
- 实际配置 SVD_CONFIG（未设时 config.md）与受影响材料；用户剧本或小说可作依据，不强制系列历史。

## Phase 3: Short 专属修正点

以下是定位当前问题的方法，不是补齐固定结构的任务。仅改授权目标及必要一致性范围；全篇检查发现其他问题先报告，改变开场、结尾意图或扩大场景范围须交 Director 协调。

### 改结局设计
- 结尾缺感染力时，回查人物先前想要什么、结尾选择付出什么，以及对方或环境怎样回应。优先恢复被压掉的反应或有意义的物件变化，而非再写一句“她终于释然”；若用户要留白，可停在选择之后，不替观众解释答案。
- 字段：「结局设计」
- 结局必须落地具体：观众离场时记住什么画面 / 情感落点
- 在授权内使结局类型与画面描述一致，保留已确认的开放、悬念或闭合意图；不能为“完整”擅改开放结尾
- 用铺垫、冲突、高潮、收束诊断结尾的因果和情绪支撑，不要求四段顺序或闭环。有意留白可让观众带着问题离场，检查其依据而不是强补答案

### 改开场策略
- 字段：「开场策略」
- 按已确认意图设计具体的注意力入口，不依赖不存在的前情
- 改时确保仍是可拍的具体画面或对白，不要写"用紧张刺激场景吸引观众"这类空话
- 第一场景按实际功能标注，允许直接冲突或跳跃式开场；确保必要处境可理解，不因标签另加铺垫场

### 改主要事件 / 场景列表
- 加事件后检查结尾意图是否仍有具体画面和情绪支撑；开放结尾不是“长剧第一集”，被挤掉必要表达才是问题
- config 时长目标内还能装下吗？
- 节奏角色互斥规则不破坏

### 改「本集信息传达」
- 改角色出场后核对观众此时需要知道什么，以及已确认的匿名、误认或延后揭示意图；不默认必须说出姓名
- 新角色仍单独登记制作身份和资产引用；信息传达条目可注明暂不向观众揭名，制作侧可定位不等于观众必须知道

## Phase 5: 输出 (无全局同步)
- 仅保存 `story/episodes/{ep}/outline.md` 的授权修订，保留无关段落
- 跳过 story/outline.md 同步 (short 无此文件)

## Short 专属失败模式
- 结尾表达受损：加事件挤掉必要支撑，或强补答案破坏已确认留白；不以开放结尾本身判失败
- 结局类型与描述脱节：改类型忘改描述，或反之
- 开场策略空话化："用紧张刺激场景吸引观众" → 下游不知拍什么
- 角色信息与意图不符：改出场后漏掉观众理解所需的信息，或擅自揭露本应匿名的角色；制作身份/资产引用缺失另按引用契约处理，不以未揭姓名判失败
- 叙事支撑断裂：必要处境、动机或因果缺失，或情绪推进背离意图；直接冲突开场、无独立收束场本身不算失败
