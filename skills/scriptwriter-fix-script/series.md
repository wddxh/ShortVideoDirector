# Series Mode: scriptwriter-fix-script 专属指南

## 额外上下文读取
- 已提供小说、章节或节选按实际路径选读；相关 arc / outline 存在时读取，分别核对文学纹理、人物弧和场景意图；缺少不阻止剧本修订。
- 涉及续集承接时读前集 script 末场景；涉及角色认知或伏笔回收时读其相关场景。

## Phase 3: Series 专属修正点

按当前问题选用以下方法，不是必须逐项处理的链条。核对相关事实后只改授权范围，跨场景或跨集影响先报告并协调。

### 改对白 / 内心独白
- 台词变得泛泛时，找回角色如何理解对方、维护关系与体面、提出所需和调整说法。隐瞒、直说或继续普通话题均按当前人物状态选择，不以固定吸气、岔开或抢话模板恢复个性；内心独白也可表现人物如何理解自己的选择。
- 声学身份另对照 `assets/characters/{name}.md` 的「声音特征」字段；音色、口音与发声基线不能代替人物语言。机器人等身份不自动推出冷漠措辞，有具体设定才据此限制表达。
- 另核对相关既有台词中的词汇、句法、称呼与比喻来源；跨集延续的是人物语言习惯与关系变化，不是每次都复制口头禅或仅保持音色。对当前回应改变策略，与人物成长相容的表达变化可保留。
- 若采用源文的相关交流，保留使关键台词成立的提问、倾听、回应、个人意义和情绪余波，不只摘取可引用的金句。可提炼重组、转译心理，直接说明与坦白不必改成潜台词；人物基调或核心事实的冲突按授权交 Director 协调。
- 主角内心独白改动后核对当前动机与已知信息；有适用 arc 时再核对人物弧位置

### 改场景结构 / 主要事件
- 若本次改了揭示内容，检查人物后续的判断、信任和行动是否仍成立；只改真相不改授权范围内必要反应，会让戏像没有发生。范围外的余波列入交接，不自动重写后续集。
- 有适用规划时回查本集目标；没有则核对委托和已确认剧本中的因果、人物变化与待回收伏笔。
- 若改动偏离既定阶段目标或与改编来源冲突，报告具体冲突与调整建议，交 Director 协调；不自行改 outline，源文保持原样。

### 改集尾钩子相关场景
- 有续集悬念委托时，最后场景具象化承载已确认钩子；单元剧或大结局保留本集情感收束，不强造“下集见”
- 画面、对白、动作、旁白或字幕都可承载钩子；应有具体戏剧含义，不能只剩空泛提示

### 改跨集承接场景（涉及承接时）
- 首集按观众尚未读设定修复必要起点；续集区分观众已知与各角色已知，保留前次行动后果及当前关系。单元/选集式系列只修实际共享连续性，不新增跨集牵连；连续剧也仅在已确认意图要求时修钩子，不默认添加悬崖结尾。
- 比对相关前集 script 的收尾、认知与关系状态，保留既成事实
- 可跳时、换视角或延后回应悬念；在需要理解时给足线索，不要求首场连续时空或固定情绪

## Series 专属失败模式
- **人物语言被抹平**: 套用通用措辞与回应方式，忽视既有生活经验和关系变化；依据相关前文恢复语言选择，不能只换音色或加口头禅。声学身份冲突另核对 character 资产「声音特征」
- **修正打破阶段推进**: 改后人物变化或事件与已确认目标冲突；有适用 arc / outline 时回查对应节点
- **结尾偏离意图**: 需要续集悬念时把已确认钩子弱化为空泛思考或“下集见”；大结局/自闭合单元则检查冲突兑现与情感收束，不以没有悬念判失败，也不强加新悬念破坏闭合
- **跨集承接断裂**: 改动违背已确认角色状态或遗漏必要线索；有意时空跳切本身不是失败
- **丢失文学层价值**: 改编无理由丢掉来源中的关键动机、互动过程或台词纹理，只剩金句而缺少理解与情绪过渡
