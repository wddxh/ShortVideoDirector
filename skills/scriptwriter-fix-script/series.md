# Series Mode: scriptwriter-fix-script 专属指南

## 额外上下文读取
- 本集 novel / arc / outline 存在且与修改有关时选读，分别核对文学纹理、人物弧和场景意图；缺少不阻止剧本修订。
- 涉及续集承接时读前集 script 末场景；涉及角色认知或伏笔回收时读其相关场景，不全读历史小说。

## Phase 3: Series 专属修正点

按当前问题选用以下方法，不是必须逐项处理的链条。核对相关事实后只改授权范围，跨场景或跨集影响先报告并协调。

### 改对白 / 内心独白
- 台词变得泛泛时，找回角色惯用的措辞、隐瞒方式和声音反应：有人急于接话，有人笑着岔开，有人在说谎前先吸气。比较修改前后的交流目的，而非给所有人加相同口头禅；内心独白仍可积极表现人物如何为自己的选择辩解。
- 角色声音必须对照 `assets/characters/{name}.md` 的「声音特征」字段——改之前重读
- 若 novel 中该场景有同角色对白细节，新台词不能与 novel 的语气基调脱节 (允许提炼，不允许改人设)
- 主角内心独白改动后核对当前动机与已知信息；有适用 arc 时再核对人物弧位置

### 改场景结构 / 主要事件
- 若本次改了揭示内容，检查人物后续的判断、信任和行动是否仍成立；只改真相不改授权范围内必要反应，会让戏像没有发生。范围外的余波列入交接，不自动重写后续集。
- 有适用规划时回查本集目标；没有则核对委托和已确认剧本中的因果、人物变化与待回收伏笔。
- 若改动偏离既定阶段目标或使文学素材不再兼容，报告具体冲突与调整建议，交 Director 协调相应 owner；不自行改 outline / novel，也不要求无条件反向同步。

### 改集尾钩子相关场景
- 有续集悬念委托时，最后场景具象化承载已确认钩子；单元剧或大结局保留本集情感收束，不强造“下集见”
- 画面、对白、动作、旁白或字幕都可承载钩子；应有具体戏剧含义，不能只剩空泛提示

### 改跨集承接场景（涉及承接时）
- 比对相关前集 script 的收尾、认知与关系状态，保留既成事实
- 可跳时、换视角或延后回应悬念；在需要理解时给足线索，不要求首场连续时空或固定情绪

## Series 专属失败模式
- **改台词丢失角色声音特征**: 套用通用对话腔调，角色辨识度崩塌 → 改前重读 character 资产「声音特征」
- **修正打破阶段推进**: 改后人物变化或事件与已确认目标冲突；有适用 arc / outline 时回查对应节点
- **结尾偏离意图**: 需要续集悬念时把已确认钩子弱化为空泛思考或“下集见”；大结局/自闭合单元则检查冲突兑现与情感收束，不以没有悬念判失败，也不强加新悬念破坏闭合
- **跨集承接断裂**: 改动违背已确认角色状态或遗漏必要线索；有意时空跳切本身不是失败
- **丢失文学层价值**: 采用 novel 的改编无理由丢掉关键动机/台词纹理；不以没有 novel 判失败
