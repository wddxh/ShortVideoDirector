# Short Mode: scriptwriter-fix-script 专属指南

## 额外上下文读取
- 实际配置 SVD_CONFIG（未设时 config.md）、受影响资产与委托材料；outline / novel 存在且相关时读取，直接采用剧本不倒补规划。

## Phase 3: Short 专属修正点

仅修本次授权目标及必要的一致性影响。回看全篇用于诊断，不是全文重构授权；若需改变开场、结尾意图或其他场景，先报告具体影响并交 Director 协调，不能为套节奏模板扩改。

### 改对白 / 内心独白
- 对白缺乏现场感时，可恢复一次有作用的反应：没接住的笑、话被哭腔截断、急促换气后的改口。由谁想得到什么、对方如何回应来选，而非为密度补句子；保留已经成立的沉默和内心声。
- 台词按戏剧作用取舍；寒暄也可表现权力、回避或关系张力，不能只为补字数而加
- 角色声音对照 `assets/characters/{name}.md`「声音特征」字段
- 改后立即估算场景内对白密度 (字数 / 时长)，避免单场景超目标

### 改场景结构 / 主要事件
- 时长目标硬约束: 改场景增减台词 / 动作后，sum(场景目标时长) 必须仍落在 config 时长目标范围内
- Phase 4 自检必跑 `scripts/scene-duration.sh` 验证；FAIL 在授权范围内调整，需扩大修改范围则报告阻塞，不擅改其他场景
- 加事件后检查已确认结尾是否仍有表达空间；开放结尾不等于“长剧第一集”，缺少必要动机或情感支撑才是要解决的问题

### 改开场场景
- 第一场景具象化已确认开场意图；有 outline 时核对「开场策略」，不靠“下集承接”
- 节奏角色准确描述实际功能，允许直接冲突或跳跃式开场；核对观众能否理解必要处境，不为标签补加铺垫场

### 改结局场景
- 情感落点变薄时，优先找回关键选择之后的可感知反应，如手从门把上松开、把准备退回的物件收好；依据原场景和人物意图选择，不为“更感人”另造关系或强加解释台词。
- 最后场景须给出已确认的情感落点：观众离场记住的画面 / 台词 / 情绪；有 outline 时核对「结局设计」
- 若剧本修改与已有规划的结局类型/动作矛盾，报告冲突并由 Director 协调，不在本 skill 改写 outline
- 保留已确认的开放、悬念或闭合意图。离开、沉默或留白可以承载情感；检查其前文支撑与观众感受，不凭动作字面判潦草，也不擅自补写答案

### 单集戏剧弧完整性
- 用铺垫、冲突、高潮、收束诊断必要信息、因果与情绪，不要求四段齐备、固定顺序或闭环
- 改某场景节奏角色时回看有关场景的功能与承接；没有独立铺垫/收束场或采用开放结尾，本身不构成修订理由

## Short 专属失败模式
- **改后超时长目标**: 增台词 / 加场景后校验失败，在授权内修正或报告需扩大范围，不能忽略失败
- **结尾表达受损**: 改动挤掉必要情绪/因果支撑，或擅自封闭已确认的开放结尾；不能仅凭留白判潦草
- **开场意图受损**: 修改使注意力入口或理解处境的必要线索丢失；直接冲突与跳跃式开场本身不是缺陷
- **戏剧弧断裂**: 必要动机、因果或情绪推进被破坏，或结尾背离确认意图；不以缺某个节奏标签判失败
- **无意义填充**: 为计数达标添加对白却没有人物、情绪或戏剧作用；按实际表达判断，不一概删除寒暄
- **结局类型 / 描述脱节**: 有适用规划时改结局未核对意图，也未报告需要跨 owner 协调的冲突
