# Short Mode: scriptwriter-fix-script 专属指南

## 额外上下文读取
- 仅 outline.md / config.md / character 资产 (无 novel, 无 arc, 无上一集)

## Phase 3: Short 专属修正点

### 改对白 / 内心独白
- 短视频每秒都贵——加台词须通过"剧情推进 / 人物塑造"二选一过滤，禁止寒暄填充
- 角色声音对照 `assets/characters/{name}.md`「声音特征」字段
- 改后立即估算场景内对白密度 (字数 / 时长)，避免单场景超目标

### 改场景结构 / 主要事件
- 时长目标硬约束: 改场景增减台词 / 动作后，sum(场景目标时长) 必须仍落在 config 时长目标范围内
- Phase 4 自检必跑 `scripts/scene-duration.sh` 验证，FAIL 必须再调
- 加事件须警惕"长剧第一集"陷阱: 加完后结局段落是否仍有具体画面 / 动作，没被压缩潦草

### 改开场场景
- 第一场景须具象化 outline.md「开场策略」——第一秒抓人，不靠"下集承接"
- 节奏角色应为"开场"或"铺垫"，不允许改成直接"冲突"以外的杂项

### 改结局场景
- 最后场景须给出 outline.md「结局设计」的**情感落点**: 观众离场记住的画面 / 台词 / 情绪
- 结局类型 (outline 字段) 与剧本结局段落的画面 / 动作必须对得上——改一处时同步检查另一处
- 不允许把结局改成"故事结束 / 主角离开"等仅完成事件的收束

### 单集戏剧弧完整性
- 修正后单集仍须含 铺垫 → 冲突 → 高潮 → 收束 四段闭环
- 改某场景节奏角色时，全集分布回扫一遍

## Short 专属失败模式
- **改后超时长目标**: 增台词 / 加场景后 `scene-duration.sh` FAIL → 必须回调
- **改完结局潦草**: 加事件后结局段落被压缩成"主角离开" → 情感落点丢失
- **改首场景开场策略失效**: 修正后第一秒不再抓人 → 重写开场具象化画面
- **戏剧弧断裂**: 改场景节奏角色后铺垫 / 收束缺失 → 全集节奏角色分布须复查
- **塞自然客套填台词**: 趁修正加寒暄占用宝贵秒数 → "剧情推进 / 人物塑造"二选一过滤
- **结局类型 / 描述脱节**: 改了结局画面忘对应结局类型字段 → 改一处同步另一处
