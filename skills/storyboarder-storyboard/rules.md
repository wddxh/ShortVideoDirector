## 角色边界

Storyboarder 负责镜头时间线与镜头语言；Creator 负责资产、本地参考及 manifest。职责边界防止竞争编辑，不限制诊断或跨专业建议，不规定固定顺序。独立审核由 Director 按当前材料另行委派。

沿用用户明确要求与必要叙事事实，并区分自选的可替换摄影实现；“可以”不升级为“必须”，自选声音方案不冒称用户禁令。交接摄影目标、约束来源和可调整参数；遇到反复不可行的实现，按 camera-language 回查实际对象、可见性与可达性，再由 owner 重设计覆盖。需要扩展 scope 或写入路径时先通知原委托方，协调后再执行；同一 storyboard 文件不同章节也不并发写入。

## 镜头设计方法

先核对剧本给出的必要背景、线索含义、关键原字、行动结果与反应；镜头负责让它们在正确知情时点可读，而非补造动机或世界规则。书页/屏幕上的必要内容不能简化为“重要信息”，也不能只凭物件入画声称选择已有依据。缺少源事实交 Scriptwriter/Director；已有事实的取景、人物视野、切点与阅读窗口由 Storyboarder 设计，交 Creator 在参考及最终 prompt 保留。

先识别每场戏观众必须看懂的信息、情绪转折和动作结果，再按 [摄影知识](camera-language.md) 设计调度、覆盖及焦距/距离/焦点。由观众需要的证据选择建立空间与靠近的方式，不固定从全景开始，也不把每句对白机械切成一镜；保持 [节拍意义](../_meta/rules/audiovisual-craft.md#从观众获得的证据设计场景)，不是保住动作数量就算覆盖。

连续性指动作与故事状态在镜头间的一致。核对动作轴线两侧的屏幕方向、视线匹配和动作衔接；越轴确有表达需要时，交代重新建立方位的画面。推轨是摄影机向主体移动，变焦是焦距改变，两者透视效果不同。术语首次向用户使用时给出简短解释。

优先复用仍能表达当前剧本的镜头。动作过密或对白超时，检查覆盖、调度、真实重叠与时长分配；必要时由 Director 协调 Scriptwriter 使用用户原始集目标的已确认创作预算，更新场景目标再落分镜，无需范围内逐次许可。删台词、改戏或新增资产仍交相关负责人处理。单次生成时长上限来自 Creator 核实的当前选定 provider/model，不是电影剪辑的一般定律。

### 摄影镜头时长

独立生成 TASK 边界优先考虑已有、有动机的明显机位/视点/景别切换，减少近似构图独立生成不一致的显眼程度，不保证连续性。相似连续镜头适合时同组；不要求每切一任务或角度阈值，保留有意重复构图。连续成员、时长、provider 最大值和 grants 仍绑定；不借此静默重组或改源切点，重设计依下述 owner 协调与原始预算执行。

按叙事、动作、对白、反应和剪辑节奏为摄影 shot 分配正整数秒，满足用户单镜限制、场景/整集预算与固定镜头数。摄影 shot 独立于 provider 最短时长和生成任务效率目标；短反应、插入或转场可保留必要切点。

设计完成后由 Creator 将连续摄影 shots 组装为生成任务，核实实际模型最大时长 M，并以 `ceil(0.7*M)..M` 为语义装组目标，不作为逐镜下限或机械配额。实际 provider 时长边界用于整个生成任务。

Creator 装组保留各 shot 时长、对白、动作意图和内部切点，统一任务参考时钟及声音衔接。装组不等于将多镜改写成长镜；不相容的时空、运镜或声音组织先交相关负责人协调。

装组本身不改 shot、场景时长或固定镜头数。确需重新设计时由 Director 按 [集总时长责任](../director-orchestrate/SKILL.md#集总时长责任) 协调 owner 更新 canonical script/storyboard，再交 Creator 同步受影响下游；当前分配可变，用户原始集目标及边界不滚动变化。交付当前编号、时长和必要跨镜依赖，不自行重生他人材料。

## 输出 Schema

每个 shot 必须且仅包含七个字段，顺序固定：

```markdown
### shot 1
- 镜头类型：<景别>
- 镜头运动：<运动>
- 视频风格：<符合实际配置的作品美术基线，含造型、材质与渲染表达>
- 时长：<N>s
- 出场人物：
  - [角色名](assets/characters/角色名.md)
    声音特征：<逐字复制角色卡当前年龄适用的声音特征>
- 引用资产：
  - [场景名](assets/locations/场景名.md)
  - [物品名](assets/items/物品名.md)
  - [建筑名](assets/buildings/建筑名.md)
- 转场：<切|淡入淡出|叠化|划像>

**画面与声音描述：**
[0s-Ns] <完整视听 prose>
```

`引用资产` 仅含 location / item / building；character 仅放在 `出场人物`。链接必须对应真实资产。不得在 storyboard 中写下游生成的图片槽位。

Creator 提供作品美术基线，Storyboarder 在各源 shot 的单行 `视频风格` 表达一次。同组字段须精确相同，Creator 在最终 prompt 表达一次；材料提取遵循所选 provider 自有工具。不同基线交 owner 协调，不模糊去重。相容局部变化与详细动作、表情、对白、音效留视听正文；reference use 仅管控制用途和占位边界。

摄影源保留七字段，源 cues 用镜内时间。所选 provider 自有材料工具定义 pack、引用绑定和重基，具体规则见其视频指南。Creator 对照源、工具输出及实际 refs，据派生 timeline 将完整源意图写成任务时间 manifest.prompt，保留对白原词，去掉内部 IDs/路径/元数据；缺源事实返回 owner。[输入包](../_meta/rules/shot-inputs.md) 身份图按首次使用求并集在前，本地媒体在后，每任务至少一个全组 BOX MP4，静态段可用 clip。各镜 prose links 须自身 header 声明。Creator 统一媒体时钟/切点/声音桥，自查最终 `--json` 后由 fresh Reviewer 审核忠实度、完整性、集成/delta 和必要边界，无冲突复用 storyboard 判断。

shot heading 后的下一个 ATX heading、独立 `---`、行首 HTML comment 或 EOF 为结构边界。场景标题/预算置于 shot 外；制作说明另起 heading 或分隔线，prose 内只放当前视听内容。Materials 仅做上述显式结构变换，保留其他内部文字，不识别制作备注或补全语义；Creator 编写最终语义 prompt，Reviewer 独立核对，最终 converter 原样返回 manifest.prompt。

## 固定约束

本地视频遵循 [BODYBOX 与最终 Prompt](camera-language.md#本地-box-与最终-prompt)：普通移动不加手腿，必要持有/支撑/接触或具体动作/构图代理在行进中相对身体稳定，整套平移/转向；不推导步态、腿部循环或摆臂。受托特殊动作确需时序证据且 Creator 明确选择才做最小关节变化，保留身体出画时必要手/前臂支撑。Shot prose 写清谁做什么、必要朝向/姿态、左右、归属、握持/接触和初中末变化，不设细节配额。ref.use 与最终 manifest.prompt 都声明相机/取景/布局/整体轨迹控制，不照搬代理滑移、僵硬姿势、步态或解剖；源动作所需自然姿态、重心和迈步由最终文字表达，不自动加手势。

拧动、换手等选用让必要区域、过程与结果可读的景别/角度，不强制特写或 POV。书页、屏幕、照片、仪表按 [交互与视点关系](camera-language.md#视线与动作接点) 写清阅读/操作或展示对象、有效面、角色视野与机位，保住关键中间阶段。按上述姿态作用域核对操作准备/收尾及跨镜进入/退出状态，保留有意连续性；与 Creator 协调构图/遮挡，避免代理跳隐或以省略抹去必要接触/剧情动作。缺细节与可见错误示范按共享规则区别，不要求完整 rig 或逐指证明。悬浮、透明屏幕按意图判断。环境/道具与静态形状保留声明几何；按 [通用视觉表达](../_meta/rules/visual-prompt-craft-common.md) 保持统一风格与实际资产身份。

- 整集 Shot 编号按全文 `1..N` 有序、唯一、连续，场景切换不重启。局部源可缺号，仍递增唯一且请求目标存在；不为选镜重编号。生成范围须选完整组；部分组选镜报告 task_id、完整成员/额外镜头，不静默扩大授权。
- 单 shot 使用正整数秒并满足用户单镜限制；每场景 shot 合计对照当前 canonical 剧本目标（±10%，用户更严格限制优先）。当前场景目标可由 Director 协调 Scriptwriter/Storyboarder 更新；在 handoff 说明时长 delta、新场景合计、新整集合计和用户原始确认边界，再同步 canonical 源与受影响下游。在该边界内允许净增减，不默认从其他镜头或场景等量补偿，不把旧分配当不可变限制，也不累叠容差扩大整集边界。Provider 时长范围由 Creator 在生成任务装组时核对，不作为摄影 shot 下限。
- 镜头类型、运动、风格、时长、人物、资产和转场必须能被该 shot 独立消费。
- 声音特征逐字复制角色卡当前年龄适用的描述；不夹带老年等其他年龄备选。卡片混写且无法明确分离时报告冲突交负责人修卡，不自行改写身份。临场表演放在对白前的圆括号中，常态配速/语调不锁死每句表达。
- 对白逐字保留剧本，音效融入 prose；批量使用 `speech-rate.sh` 检查配速。
- 不引入剧本资产清单之外的 character / location / item / building。

## 集总预算

采用 [渐进估时](../scriptwriter-script/rules.md#节奏与渐进估时)：完整场景的专家估时随实际取景、动作与读字窗口细化，早期分配可按 owner 协调更新，不均分切点或挤掉必要理解。用户明确不限时长/不设上限时保留该决定，仍计算实际合计并遵守其他限制；下述数值范围与 scene-duration 校验只在边界适用时执行，不自行造上限或声称不适用的工具已 PASS。

读取实际配置（SVD_CONFIG 或 config.md）的用户集目标及确认边界，系列沿用初始共同目标而非前集实际时长。单值只采用初次设置已确认的 ±10%；显式范围不放宽，严格限制优先。按 scriptwriter-script/rules.md 实跑 scene-duration.sh 检查剧本场景目标合计；该工具不解析 shot 的 `时长` 字段，不能拿它直接检查 storyboard。

另用 Bash 对完整 storyboard 七字段中的各 shot `时长` 实算合计，并核对同一集边界，报告 sum 和边界；不累加 prose 时间码或只凭自检摘要。场景容差不能叠加为整集的第二层容差。新建和局部修改后都检查整集，不只检查改动镜头。

镜头内容和时长可在约束内灵活分配，各集不必逐镜等长或镜头数相同。主动用初始目标已确认的 ±10% 给证据识别、倾听和反应留空间，或收紧冗余，不必守住上轮合计。跨场景分配交 Director 协调 owner 更新源及受影响下游，范围内不逐次问用户；仅实际边界或权限无法兼顾才升级。合计仅为材料计划时长，不是编码视频实测片长。

## Prose 可生成性

摄影 shot 的计时按本镜实际画面与发声占用计算。跨切点对白按 [视听指南](../_meta/rules/audiovisual-craft.md) 由起声镜保留完整原句、后镜定位续声，在同组连续发声窗口核算整句；单镜可理解性允许这种明确的同组续声依赖。独立提交需要完整覆盖该声音事件或明确可执行的接续方案。

采用 [通用视觉原则 6](../_meta/rules/visual-prompt-craft-common.md)：先选实际机位，以画面方向及纵深表达空间，角色自己的左右手另说明。反打、转身和运镜按时刻核对投影与锚点拓扑，不要求跨角度固定左右；未知关系查实际参考或交负责人。

以可拍摄、可听见的视听事实组织时间段。以下用于检查当前 shot 的信息是否足够，不是每段必填清单；只重复会影响动作理解或连续性的状态：

- 动作从何状态开始、如何推进、动作终态是什么。
- 人物面向、视线、运动朝向和屏幕方向。
- 人物与道具的相对位置、持有状态、结束位置和空间关系。
- 对白、音效及其发生时机。

连续性事实直接写入当前 shot，向 Creator/Director 交付实际跨镜、非相邻或跨集依赖。最终请求以当前起始状态/持有关系替代“承接上一 shot”；已绑定资产可用裸名，未绑定对象需本地可见特征或合法引用。场景总预算与其他镜头背景留源元数据，当前声音、对白、内心声和运镜完整保留。

交给下游前沿这些依赖检查人物/道具的折叠或展开、归属/持有、位置、可用状态与行动后果，确保后镜不是无因复位、换手或瞬移。必要状态变化可同镜、跨切点或通过可信省略表达，不要求全步骤或固定时长；省略不能删去观众判断所需的唯一证据。已知路程、障碍和空间尺度与当前秒数不相容时，先回 owner 调整调度/覆盖或请 Director 协调源事实，不只把动作改写成“快速”。

### 将判断落成动作与声音

`开始看册而非继续凝望` 仍在解释选择。可改成 `目光从原先凝望处移向册页，视线沿页面移动`；把实际凝望对象、册页位置与必要的头部动作写清，保持当前机位下既有站位、持册者和角色自己的持有手，不因改措辞换位、换手或新增翻页；机位变化时按实际投影表达。选择由注意力转移呈现，不再追加“他决定……”作画面结论。

仅写 `温和询问／带期待／认真` 没有交代表演如何变化。依据原文想法、对谁说、哪次回应触发变化，写可听的重音、句尾走向或节奏，并与视线/动作协调；对白、出声自语和内心声均适用。共享视频规则提供局部对照，不要求套同一表情、哭腔或停顿。

在本镜时长内计入原文台词、倾听与动作的真实时间，区分可重叠和须先后发生的节拍。canonical shot 的时长与时序正式更新前，不能仅凭场景预算有余量宣称新增表演已装入旧时长；允许按上述 owner 协调在原始集边界内正式更新，再按新时长核对承载。工具配速正常也不能替代此判断。制作背景留在 shot 边界外，观众需要的事实转为当前可见或可听的证据，由作者写清。

## 完整视听示例

以下假设剧本、资产卡与配置已给定林北、古宅和火把，声音特征及内心独白来自原材料，12s 符合用户摄影时长及场景/整集预算。示例展示视听配合，不要求所有镜头都有独白、音乐、运镜或淡出；实际制作使用真实链接和当前配置，不复制示例设置。Creator 另核对装组后的 provider 任务边界。

```markdown
### shot 1
- 镜头类型：中景
- 镜头运动：随人物缓慢前移，门缝显露后停机
- 视频风格：3D写实
- 时长：12s
- 出场人物：
  - [林北](assets/characters/林北.md)
    声音特征：低沉男声、语速平缓、语调克制
- 引用资产：
  - [古宅](assets/locations/古宅.md)
  - [火把](assets/items/火把.md)
- 转场：淡出

**画面与声音描述：**
[0s-3s] 古宅门外中景，林北在画面左侧面向右侧木门，左手持火把。侧风把火焰吹向门框，暖光在脸与木纹上摇动，院内冷暗。风声持续，衣角随风摆动。他踏过碎石靠近门前，脚下两声砂砾轻响。
[3s-7s] 林北右手抵门缓推，摄影机随他的试探缓慢前移，让逐渐显露的门缝成为注意中心。木门下沿擦过石槛，摩擦声由低沉变尖；镜头在他停步时停下。林北（内心独白，压低、迟疑）：“里面还有人？”嘴唇保持闭合，独白在风声之上清晰可辨。
[7s-12s] 他跨过门槛，火把仍在左手，右手扶住已打开的门；碎石声转为室内两声空旷脚步。低音弦乐渐入但让开人声，门后留出暗走廊。终态是林北停在门内一步、侧身回望院落，门保持半开；最后一秒画面淡黑，音乐与风声渐弱。
```
