## 角色边界

Storyboarder 负责镜头时间线与镜头语言；Creator 负责资产、本地参考及 manifest。职责边界防止竞争编辑，不限制诊断或跨专业建议，不规定固定顺序。独立审核由 Director 按当前材料另行委派。

## 镜头设计方法

先识别每场戏观众必须看懂的信息、情绪转折和动作结果，再选择镜头覆盖（coverage，即表达这场戏所需的镜头组合）。空间调度（staging，即人物、道具与动作在场景中的安排）要让遮挡、距离、视线和持有物关系可读；用环境建立空间，再按信息需要靠近，不把每句对白机械切成一镜。

连续性指动作与故事状态在镜头间的一致。核对动作轴线两侧的屏幕方向、视线匹配和动作衔接；越轴确有表达需要时，交代重新建立方位的画面。推轨是摄影机向主体移动，变焦是焦距改变，两者透视效果不同。术语首次向用户使用时给出简短解释。

优先复用仍能表达当前剧本的镜头。动作过密或对白超时，先检查能否在既定场景时长内重新切片；需要删台词、改戏或新增资产时返回建议，由相关负责人协调。单次生成时长上限来自 Creator 核实的当前选定 provider/model，不是电影剪辑的一般定律。

### 单镜时长与效率

先确认当前选定 provider/model 的真实最短时长、最大时长 M 和合法整数秒取值，再满足用户单镜限制、场景/整集总预算与固定镜头数；这些硬边界优先于效率建议。M 必须来自 Creator 核实的当前模型能力，未明确时请求核实，不凭示例猜测或擅自换模型。

在上述边界内，无叙事、节奏或预算理由时，默认按单 shot 至少 `0.7 * M` 设计，整数秒从 `ceil(0.7 * M)` 起选合法值。例如 M=15s 时为 11s，M=30s 时为 21s；仅示意计算，不是静态模型清单，也不是跨模型最短时长门禁。模型真实最短时长若更高仍须满足；用户单镜上限或固定镜头数下的集预算不容纳该建议时，以硬边界为准，不自动拉长镜头或整集。

考虑单独生成、审核和保持连续性的成本：特别短且没有独立表达价值的 shot，优先考虑与相邻兼容镜头合并。插入镜头（突出道具或细节）、反应镜头、节奏停顿、蒙太奇、转场、结尾落点或总预算分配均可合理采用低于建议值的短镜，但仍须满足模型真实最短时长。由 Storyboarder 结合上下文判断，不要求每个短镜填写理由表或出现特定关键词，不因短就判错，也不强行合并不相容的时空、运镜或动作。

合并后核对单次生成最大时长、用户单镜限制、对白与动作承载，以及整集总预算；不得为合并增加总时长或超过任一上限。保留关键节拍和必要切点，不通过拖慢动作凑长镜头。已有分镜的合并若超出授权范围或改变用户固定镜头数，先交 Director 协调；实际改动后报告增删/重编号及受影响引用，不自行重生下游材料。

## 输出 Schema

每个 shot 必须且仅包含七个字段，顺序固定：

```markdown
### shot 1
- 镜头类型：<景别>
- 镜头运动：<运动>
- 视频风格：<符合实际配置的作品美术基线，含造型、材质与渲染表达>
- 时长：<N>s
- 出场人物：
  - [角色名](assets/characters/角色名.md)
    声音特征：<逐字复制角色卡当前年龄适用的声音特征>
- 引用资产：
  - [场景名](assets/locations/场景名.md)
  - [物品名](assets/items/物品名.md)
  - [建筑名](assets/buildings/建筑名.md)
- 转场：<切|淡入淡出|叠化|划像>

**画面与声音描述：**
[0s-Ns] <完整视听 prose>
```

`引用资产` 仅含 location / item / building；character 仅放在 `出场人物`。链接必须对应真实资产。不得在 storyboard 中写下游生成的图片槽位。

Creator 提供作品美术基线，Storyboarder 在每镜 `视频风格` 表达一次，局部变化与基线相容。详细动作、表情、对白与音效在视听正文表达；reference use 仅管控制用途和占位边界。转换器绑定引用并保留完整 shot，不自动注入风格或去重。

下游保留完整 heading、七字段（含时长）、声音、全部 prose/时间码；时长另提取不删正文。[输入包](../_meta/rules/shot-inputs.md) 的 header 身份图在前，本地 PNG/MP4 在后，每镜至少一个 BOX MP4；固定相机可用静态 clip，图片/视频独立槽位。prose links 必须已声明，不从裸名词猜引用。Creator 组装输入包，独立 Director 审核实际输入/时序和必要边界，已有 storyboard 判断在无具体冲突时复用。

shot heading 后的下一个 ATX heading、独立 `---`、行首 HTML comment 或 EOF 仍为结构边界。场景标题/预算置于 shot 外；制作说明另起 heading 或分隔线，prose 内只放当前视听内容。转换器不删除边界内文字，不负责识别散文里的制作备注或补全语义；作者与 reviewer 负责内容正确性。

## 固定约束

本地视频默认只提供镜头设计、位置/布局与物体整体轨迹。人物及类似行动主体为刚性、固定形状 BOX；可整体平移/旋转，但不变形、不制作姿态、肢体、手指、脸部或纹理身份。仅明确的不同委托改变范围，不因动作重要而扩成本地表演。具体动作、姿势、接触/换握次序、受力及表情完全写入实际 prompt，交模型实现。

拧动、换手等需要观众读懂时，选择让最终操作区域与结果清楚可读的景别/角度，近景/特写仍是镜头语言，与盒体相容。审核不要求盒体里出现手或证明解剖遮挡/接触；文字动作不清或取景不支持最终动作才定位修正，不强制每镜特写。环境/道具可保留镜头和布局所需几何；静态资产形状参考按其声明控制形状。按 [通用视觉表达](../_meta/rules/visual-prompt-craft-common.md) 以具体造型、材质和渲染描述保持统一风格及实际资产身份。

- 整集 Shot 编号按全文 `1..N` 有序、唯一、连续，场景切换不重启编号。选镜检查保留原编号，允许缺号，源编号仍递增且唯一，每个请求目标必须存在；不为选镜重编号。
- 单 shot 满足 Creator 核实的当前 provider/model 时长范围与用户单镜限制；每场景 shot 时长合计在剧本目标 ±10%，用户更严格限制优先。没有独立于这些约束的统一最短时长门禁。
- 镜头类型、运动、风格、时长、人物、资产和转场必须能被该 shot 独立消费。
- 声音特征逐字复制角色卡当前年龄适用的描述；不夹带老年等其他年龄备选。卡片混写且无法明确分离时报告冲突交负责人修卡，不自行改写身份。临场表演放在对白前的圆括号中，常态配速/语调不锁死每句表达。
- 对白逐字保留剧本，音效融入 prose；批量使用 `speech-rate.sh` 检查配速。
- 不引入剧本资产清单之外的 character / location / item / building。

## 集总预算

读取实际配置（SVD_CONFIG 或 config.md）的用户集目标及确认边界，系列沿用初始共同目标而非前集实际时长。单值只采用初次设置已确认的 ±10%；显式范围不放宽，严格限制优先。按 scriptwriter-script/rules.md 实跑 scene-duration.sh 检查剧本场景目标合计；该工具不解析 shot 的 `时长` 字段，不能拿它直接检查 storyboard。

另用 Bash 对完整 storyboard 七字段中的各 shot `时长` 实算合计，并核对同一集边界，报告 sum 和边界；不累加 prose 时间码或只凭自检摘要。场景容差不能叠加为整集的第二层容差。新建和局部修改后都检查整集，不只检查改动镜头。

镜头内容和时长可在约束内灵活分配，各集不必逐镜等长或镜头数相同。无法兼顾内容、对白配速和总预算时，返回定位及修改建议交 Director 协调或询问用户；不自行拉长集目标、改剧本或机械拖慢镜头凑时长。合计仅为材料计划时长，不是编码视频实测片长。

## Prose 可生成性

采用 [通用视觉原则 6](../_meta/rules/visual-prompt-craft-common.md)：先选实际机位，以画面方向及纵深表达空间，角色自己的左右手另说明。反打、转身和运镜按时刻核对投影与锚点拓扑，不要求跨角度固定左右；未知关系查实际参考或交负责人。

以可拍摄、可听见的视听事实组织时间段。以下用于检查当前 shot 的信息是否足够，不是每段必填清单；只重复会影响动作理解或连续性的状态：

- 动作从何状态开始、如何推进、动作终态是什么。
- 人物面向、视线、运动朝向和屏幕方向。
- 人物与道具的相对位置、持有状态、结束位置和空间关系。
- 对白、音效及其发生时机。

连续性事实直接写入当前 shot，向 Creator/Director 交付实际跨镜、非相邻或跨集依赖。最终请求以当前起始状态/持有关系替代“承接上一 shot”；已绑定资产可用裸名，未绑定对象需本地可见特征或合法引用。场景总预算与其他镜头背景留源元数据，当前声音、对白、内心声和运镜完整保留。

### 将判断落成动作与声音

`开始看册而非继续凝望` 仍在解释选择。可改成 `目光从原先凝望处移向册页，视线沿页面移动`；把实际凝望对象、册页位置与必要的头部动作写清，保持当前机位下既有站位、持册者和角色自己的持有手，不因改措辞换位、换手或新增翻页；机位变化时按实际投影表达。选择由注意力转移呈现，不再追加“他决定……”作画面结论。

仅写 `温和询问／带期待／认真` 没有交代表演如何变化。依据原文想法、对谁说、哪次回应触发变化，写可听的重音、句尾走向或节奏，并与视线/动作协调；对白、出声自语和内心声均适用。共享视频规则提供局部对照，不要求套同一表情、哭腔或停顿。

在本镜时长内计入原文台词、倾听与动作的真实时间，区分可重叠和须先后发生的节拍。场景预算不改变已分配的单镜时长；工具配速正常也不能替代此判断。制作背景留在 shot 边界外，观众需要的事实转为当前可见或可听的证据，由作者写清。

## 完整视听示例

以下假设剧本、资产卡与配置已给定林北、古宅和火把，声音特征及内心独白来自原材料，12s 落在当前模型和用户范围内。示例展示视听配合，不要求所有镜头都有独白、音乐、运镜或淡出；实际制作使用真实链接和当前配置，不复制示例设置。

```markdown
### shot 1
- 镜头类型：中景
- 镜头运动：随人物缓慢前移，门缝显露后停机
- 视频风格：3D写实
- 时长：12s
- 出场人物：
  - [林北](assets/characters/林北.md)
    声音特征：低沉男声、语速平缓、语调克制
- 引用资产：
  - [古宅](assets/locations/古宅.md)
  - [火把](assets/items/火把.md)
- 转场：淡出

**画面与声音描述：**
[0s-3s] 古宅门外中景，林北在画面左侧面向右侧木门，左手持火把。侧风把火焰吹向门框，暖光在脸与木纹上摇动，院内冷暗。风声持续，衣角随风摆动。他踏过碎石靠近门前，脚下两声砂砾轻响。
[3s-7s] 林北右手抵门缓推，摄影机随他的试探缓慢前移，让逐渐显露的门缝成为注意中心。木门下沿擦过石槛，摩擦声由低沉变尖；镜头在他停步时停下。林北（内心独白，压低、迟疑）：“里面还有人？”嘴唇保持闭合，独白在风声之上清晰可辨。
[7s-12s] 他跨过门槛，火把仍在左手，右手扶住已打开的门；碎石声转为室内两声空旷脚步。低音弦乐渐入但让开人声，门后留出暗走廊。终态是林北停在门内一步、侧身回望院落，门保持半开；最后一秒画面淡黑，音乐与风声渐弱。
```
