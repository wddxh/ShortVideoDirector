# 视点、镜头与连续性

本页是按叙事问题取用的摄影知识，不是固定镜头表或必经流程。先判断观众此刻应知道什么、与谁共享体验、需要看清什么，再选择视点、景别、角度与运动；不默认第三人称，也不把第一人称设成新的统一答案。保持现有七字段，视点归属和具体实现写入镜头类型、运动及完整视听正文，不增加 schema 字段。

## 选择视点

| 方式 | 适合表达 | 取舍 |
| --- | --- | --- |
| 主观 POV／第一人称 | 与角色共享观察、发现、选择或操作 | 明确是谁的眼睛、看向哪里；当下通常不能同时看见自己的正脸 |
| 过肩 OTS | 保留观察者与目标的空间关系、对话距离 | 机位在肩后或旁侧，不冒称占据眼睛位置；前景肩部不能盖住重点 |
| 外部观察 | 人物全身行动、关系、环境与反应 | 根据叙事选择远近，不为展示全身而牺牲关键操作的可读性 |
| 插入镜头／动作细节特写 | 突出手、物件、信息或关键状态 | 特写描述画面尺度，不自动说明视点归谁；可以主观，也可以客观 |
| 俯视、低机位或物件位置视角 | 展示布局、力量关系或特殊信息 | 不是天然“高级”；只有来源可理解时才称某角色或设备的主观视点 |

POV 不等于运动相机、鱼眼、固定广角或剧烈摇晃。它可以稳定，视线也可俯向手边物件；仅让相机 Tilt 俯转并未把机位搬到角色眼位。普通角色 POV 不能同时出现自己的正脸，除非实际场景支持镜面反射、屏幕回传等明确来源。若强调操作代入感，第一人称值得优先比较；若要看操作者的情绪或两人关系，外部反应镜头可能更合适。视点可切换，不要求整个作品一种视点。

## 场面调度与覆盖

先从剧本节拍安排人物、道具、出入口和行动路线，再从观众所需证据选择覆盖。问此刻谁知道什么、谁能看见什么、注意应从哪里移到哪里；站位、转身、遮挡和距离应支持这些关系。建立空间不必总用大全景，已清楚的关系也不必重复交代；用能保住因果的镜头组合，而非对白一句一切或全景、正反打、特写各凑一份。

例如信封移开才显露钥匙，随后听者停手：双人镜若能看清钥匙和停手，可保留同镜；钥匙太小则比较插入、靠近或重排站位，再回到关系反应。不能为了看清结果直接从已露出的钥匙开始，也不能用说话者的近景盖掉唯一的停手证据。依据 [视听 craft](../_meta/rules/audiovisual-craft.md) 保留节拍意义，不按动作数量安排覆盖。

## 视线与动作接点

书页、屏幕、照片、仪表/操作面等有方向的表面，先明确角色是在自己阅读/操作，还是展示给谁；再确定有效表面朝向谁、观察者与相机各在哪一侧，以及角色实际能看到和使用的区域。观众能读清文字不等于角色能读或操作。按具体意图理解透明/双面介质、场内显示装置和主动展示，不把“相机与角色必须同侧”当通用规则。

在保住交互关系后选择客观侧面高角度、OTS、插入或合理 POV 等覆盖，不强制某一种方案。可调整机位、取景或物件物理上合理的倾角，必要时切镜；不能仅为镜头可读把有效面转到操作者无法使用的一侧。过程按实际节拍核对接近、拿起、转动、阅读/使用、放低与反应中的重要关系变化，不只写可读的中段或首尾，也不为凑阶段新增动作。

例如角色拿起照片自己辨认后递给同伴看：辨认时图面供自己观看，可从侧上方或肩后取景；转向同伴是明确的展示动作，后续取景按接收者位置选择。不能从拿起起就把图面转离持有者去追随镜头，却仍描述持有者一直读着图面。此例不规定镜头数或唯一视点。

“角色看向目标 → 所见 → 反应”是常用主观镜头组织方式，不要求每次完整重复三镜。上下文已清楚时可直接进入 POV；不清楚时用视线、位置锚点或声音建立归属，不靠标签要求观众猜。

视线匹配同时包括水平与高低：低处目标应与角色的下视相容。反打后按新投影理解画面左右，不要求目标永远处于相同屏幕坐标；匹配也不意味着所有镜头必须相同焦距或景别。

动作接点（match-on-action）可在运动中切换景别，保留相同手、对象、接触状态和动作进度。若正在拧轮，下一视角不能重新开始或跳到相反转角。关键变化可在一个稳定取景中持续呈现，也可明确跨切点衔接，不强制一个动作只能长镜头完成。

轴线可以是人物与注视对象的关系线，也可以是运动方向，不是固定世界坐标的禁区。同侧拍摄通常有助维持屏幕方向；需要越轴时，可用可见的相机运动、重新建立空间或其他清楚线索让观众理解变化。主动制造迷失是另一种创作选择，不能把未经设计的混乱当成越轴技巧。

## 运动与光学

独立生成 TASK 边界优先落在已有、有动机且机位/视点/景别明显不同的切点，以减少近似构图独立生成时不一致的显眼程度，不保证连续性。相似连续镜头适合时放同组，不要求每切一任务、不设角度阈值，也不破坏有意重复构图。保留连续成员、当前时长、provider 最大值和 grants；需源重设计由 Director 协调 owner 在原始预算内更新，再同步下游，不静默重组受保护任务或改切点。

分别写清相机平移、相机转向、焦距变化和主体轨迹。Dolly 是摄影机位置移动，Pan/Tilt 是水平/垂直转向，Zoom 是焦距变化；固定位置的变焦不会产生移动机位带来的前后景视差。写明跟随什么、显露什么、何时开始和停在哪里，不只堆运动名词。

移动应服务于注意力、发现、距离或关系变化；稳定机位同样有效。POV 中手在转轮不意味着镜头随轮滚转，俯看、身体前倾与手部动作也不是同一运动。焦距结合视野、距离和物件比例选择，不用固定毫米数保证“电影感”。

把机位距离、焦距/视野和焦点作为一组选择：距离改变透视与前后景关系，焦距在给定画幅下决定视野，景别本身不能代替两者。先让必要证据在实际画幅中有可读尺度且不被遮挡，再决定焦点落在哪个深度、何时转移、景深是否容得下同时要读的信息。若要同时看清近处钥匙与远处听者反应，可比较调度到相近焦平面、增加景深或分镜；若有意先读钥匙再读反应，转焦必须留出识别与注意转移的空间，不能让反应在焦外发生完才转过去。仅在问题需要时细化光学数值或渲染景深，不以镜头毫米数、虚化强度作为验收配额。

## 本地 BOX 与最终 Prompt

以下是本项目对摄影知识的应用，不是外部资料对生成模型的性能承诺。BOX 默认表示位置、占地和整体轨迹，可整体平移/旋转；持有、支撑或动作若否则不可读或显得非预期悬浮，就补最小手/前臂、相关肢体或接触代理。身体出画尤其要留意，画内必要支撑同样适用；属于已授权本地工作，默认不做完整 rig、精细手指或脸部动画。相机独立设置视点、方向、景别与运动。

POV 相机放在角色合理的眼睛位置或明确的主观观察位置，朝目标取景。隐藏自身 BOX 的挡镜内部，保留实际环境遮挡及必要操作/支撑代理；其他视角仍可显示其位置。需要屏内肖像时，将肖像置于声明的屏幕平面；普通角色 POV 则呈现该角色所见的全幅场景。

拧阀示例：由操作者视点略向下看向选中的阀轮，取景保留辨位锚点、轮缘关键标记与操作空间。以最小手/前臂代理标明必要接触与归属，不建完整手指 rig。最终 prompt 写清该角色视点、双手从何处进入、哪手握哪段轮缘、受阻后如何换握、从操作者看何种转向及终态，并解释代理还原为该角色的正常手臂与握姿。身份与统一材质/渲染沿用实际资产和作品美术基线。

不要为了把轮子放大而把相机移到角色眼睛不可能到达的阀轴位置，仍声称普通眼睛 POV；可选择合理的靠近、俯身视点或改为客观插入特写。视点改变可能改变顺/逆时针的屏幕投影，需以命名观察面明确，不默认所有阀门的开向相同。

粗参考需要足够详细的 shot prose：谁做什么，必要身体/头部/道具朝向和姿态、画面与解剖左右、归属、握持/接触及初中末变化；按动作需要选细节，不要求机械全字段或数量。`use` 说明代理控制而非最终风格，最终 prompt 说明实际代理如何实现为最终解剖、姿态、握向与动作。

审核看视点归属、必要画面信息、相机/位置/轨迹/支撑与 prompt 是否相容。缺指节、完整 rig 或表情不是失败；缺必要支撑而使持有物悬浮或动作矛盾则须修正，按意图区分真实悬浮、透明屏幕及有意遮挡。不能把 BOX 外形当最终姿势，也不能用“主观”掩盖外部机位错误。作品修改仍由受托 Storyboarder 决定，示例不自动重写现有 shot。

以下来源支持摄影概念；BOX 与阀门示例是这些概念的制作应用，不代表 provider 能力承诺。

- [StudioBinder: What is an Eyeline Match?](https://www.studiobinder.com/blog/what-is-an-eyeline-match/)：视线连接目标与空间关系，同时考虑高低方向。
- [Learn About Film: Continuity](https://learnaboutfilm.com/film-language/sequence/)：动作接点、互动/运动轴线，以及建立与重新建立空间的作用。
- [StudioBinder: The Dolly Shot](https://www.studiobinder.com/blog/dolly-shot-camera-movements/)：相机位置移动与变焦的区别；运镜的揭示、跟随和情绪用途。
