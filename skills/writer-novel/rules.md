## 输出格式

```markdown
# 第{X}集

{小说正文，含章节标题}
```

## 输出约束

- 场景描写具体可视觉化
- 人物外貌、动作、表情有细节描写

## 规则

1. **呼应集尾钩子** — 每集结尾必须呼应 Director 设定的集尾钩子，留下吸引观众继续观看的结尾
2. **与 outline.md 保持一致** — 不得出现与已有内容的矛盾
3. **人物性格连贯** — 人物性格、说话风格在各集之间保持连贯统一
4. **场景详实** — 场景描写要足够详细，以支撑后续视觉化和分镜制作
5. **用词精炼** — 适合短视频叙事，避免冗长铺陈。长度由内容完整度 + 场景级密度预算共同决定（见 ## 长度原则 与 ## 场景级内容密度预算）。
6. **注重画面感** — 多用具象描写而非抽象叙述
7. **丰富台词设计** — 尽可能多地设计角色对白、内心独白和角色声音反应（吼叫、哭泣、叹息等），同时场景描写和动作描写要足够详细
8. **禁止旁白式叙述** — 场景信息应通过角色对话、自白或反应来传达
9. **主角内心独白** — 多设计主角的内心独白，展现主角的想法、感受和判断，增强观众的代入感


## 长度原则

novel 长度由两部分共同决定——内容完整度（下述 3 维）+ 场景级密度预算（下段）：

1. **完整覆盖 outline 所有场景** — 每个 outline 场景在 novel 中必须可识别（场景标题、关键动作、关键对白可被 grep / 读出）
2. **因果链清晰** — 每场景的"果"在 novel 中明确承接上场景的"因"；任何因果跳跃必须用过渡句/段交代
3. **过渡自然** — 场景切换不突兀，时空跳转有铺垫

## 场景级内容密度预算

outline 每个场景有 `目标时长: Ns` 字段。novel 写作时按该字段为每场景算字数预算。

**密度档位：8-12 字 / 秒**（中文字符 + 英文 word 混合计数，含对白 + 动作描写 + 场景细节 + 内心独白；不计 markdown 章节标题等结构性字符）

| 场景目标时长 | 字数预算（中位 10 字/秒） |
|---|---|
| ≤10s | 80-120 字 |
| 10-25s | 100-300 字 |
| 25-60s | 200-720 字 |
| >60s | 按 10 字/秒线性外推（罕见） |

**±30% 容差合法**：
- 对白密集场景（多角色快速交锋，短句多）→ 字数可偏少
- 动作 / 视觉场景（追逐 / 沉默对峙 / 大调度）→ 字数可偏多
- 远超 / 远低 → 增 / 删内容，**不动场景时长**（时长是 outline 权威，不准动）

**自检方法**：写完每场景后默数字数，落在区间 ±30% 即可继续。

**全集字数兜底**：sum(场景目标时长) × 10 ± 30% 是全集字数粗预算。下游 director-review-novel 调 `scripts/novel-budget.sh` 算实际 vs 期望，>±40% 越界打回。

**与「长度原则」3 维关系**：3 维（覆盖 / 因果 / 过渡）是必要条件，密度档位是预算锚点。两者冲突时（如某场景因果链清晰但字数远低）→ 检查是否漏了场景描写或内心独白，而不是注水。

**config.md `每集小说字数` 字段已废弃**：本次密度方案改用 outline 场景目标时长推导期望字数，writer / director-review-novel / check-episode.sh 均不再读取 config.md `每集小说字数`。该字段若仍存在于用户 config.md 中，所有流程静默忽略；建议用户从 config.md 删除以避免混淆。
