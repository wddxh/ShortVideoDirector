## 输出格式

```markdown
# 第{X}集

{小说正文，含章节标题}
```

## 输出约束

配置使用实际 SVD_CONFIG（未设时 config.md）。文学方法按委托与视角选用，不规定写作顺序；格式、人物身份和保留要求仍须遵守。

- 场景描写具体可视觉化
- 人物外貌、动作、表情有细节描写

## 规则

1. **回应结尾意图** — 按委托落实悬念、开放或闭合结尾；用画面、人物选择或余韵形成情感落点，不强塞“下集”悬念，也不把有意留白补成封闭答案
2. **与已确认材料保持一致** — 有适用 outline 时参考；无大纲时依委托和相关剧本事实，不另造前置文件
3. **人物性格连贯** — 人物性格、说话风格在各集之间保持连贯统一
4. **场景详实** — 场景描写要足够详细，以支撑后续视觉化和分镜制作
5. **用词精炼** — 篇幅服务委托、人物体验与改编需要；密度数字仅作诊断参考，不替代内容判断。
6. **注重画面感** — 多用具象描写而非抽象叙述
7. **人物声音** — 用措辞、节奏、回避和声音反应表现关系与欲望；对白、独白或沉默按人物处境选择，不追求数量
8. **叙述视角** — 旁白、概述、自由间接引语（第三人称叙述中融入人物的语气与判断）或具体场景均可使用；检验叙述者知道什么、隐瞒什么以及如何塑造体验，不一概禁止叙述
9. **用内心独白增强代入感** — 在人物独处、权衡、误判或压抑情绪时，多设计主角的内心独白，具体展现想法、感受和判断。让读者听见他的自我辩解、愿望和言行矛盾；自言自语也能让犹豫与自我鼓励带上人物声音。这是经验推荐，不按场次或字数配额添加。

## 具体互动与内在声音

**主观视角（通过某个人物的感知和判断体验现场）**能让细节带上态度。同一扇没关的门，等待归家者看见希望，躲避追问者看见危险。优先选人物会注意的声音、气味、物件和身体感受，不平均罗列环境；叙述视角需要切换时，用清楚的关注对象或时空线索帮助读者跟上。

**潜台词（话语背后未直说的愿望、压力或回避）**让对白不只是传信息。想挽留却问“伞带了吗”，可由手没有松开伞柄、故作轻松的语调和内心辩解共同表现。重要段落可按**戏剧节拍（一次回应引起策略、认知或情绪变化）**展开，让人物听见对方后真的改变下一步。

**声音反应调色板**：倒吸一口气、急促换气、吞回笑声、哭腔截断半句、喊叫、长叹或话到嘴边的停顿，都能使人物声音具体。选与身体状态、关系和节拍相符的反应，例如努力开玩笑却笑不出声，比统一写“悲伤地说”更能让人体验压抑；不要把所有反应堆进同一场。

**铺垫与回收（先建立细节或期待，后让它产生新意义）**可服务感情而非只服务反转。前文角色总把热茶推给别人，结尾第一次有人替他倒茶，就能让被照顾的瞬间有来处；必要时用回忆或再认识揭示联系，不固定铺垫段数。

重要告白、交锋和关系转折值得展开具体台词、动作与回应，不用“A 告诉 B 这件事”跳过戏剧过程。关键情绪用触发细节、感官、联想和选择给出依据，让读者体验悲伤或恐惧，而不只接受抽象定性。

- **内心独白**：人物未说出口的思想，可在文学叙述中直接展开；保留其词汇、偏见和思考节奏，不必假装都是嘴上说的话。
- **自言自语**：人物实际说给自己听的话，如低声排练道歉、给自己打气；写出说话情境和声音反应，在场他人可能听见。
- **画外音**：影视声音的呈现方式，不等于心理内容本身；可承载内心独白、叙述者旁白，也可来自画面外真实说话的人。文学稿可提供相应文字与语境，改编时再明确谁能听见。

例如，“他很内疚”可展开为：他把道歉信息删到只剩一个“我”字，心想“发出去，她会不会以为我只想求个心安？”又低声试了一句“对不起”。动作、内心独白和自言自语共同呈现挣扎。示例展示经验方法，不要求所有情绪都照此写；概述仍适合压缩次要经过。


## 长度原则

novel 长度由委托与内容需要决定；以下维度用于发现遗漏，密度只提供另一种观察角度：

1. **覆盖约定事件** — 若委托为大纲展开，保留各场景的关键动作、对白及功能；采用其他素材时按本次范围检查，不用关键词命中替代叙事判断
2. **因果依据清晰** — 故事中的事件、动机与后果须有支撑，但呈现顺序可以倒叙、交叉或高潮先行；在需要理解时给足线索，不要求每场都是前一场的结果
3. **过渡有意图** — 时空或视角变化有足够辨识依据，可用动作、意象或时间线索，不强制解释段；有意跳切不等于承接失败

## 场景级内容密度参考

本次文学稿对应适用 outline 且有有效 `目标时长: Ns` 时，可用密度辅助观察展开程度。没有 timed outline 时按文学目标判断，不补建大纲；文学字数不等于可拍时长。

可把约 10 字/秒作为观察展开程度的起点，不是逐场配额。novel-budget.sh 实际按整篇字数与 outline 总秒数计算：7-13 字/秒为 `ok`，6-14 内的其余部分为 `warn`，之外为 `fail`；不是逐场语义审核。计数由 word-count.sh 执行，包含正文中对白、动作、心理等文字，无法分辨其表演时长。

**偏差的解释线索（不是合格区间）**：
- 10s 场景写了 500 字/英文词时，问哪些真要说出口、哪些是瞬时画面或文学心理；30s 场景只有 50 字/词时，问是否已有足够的动作、等待与反应支撑，还是漏写了关键互动。示例只是诊断问题，中文字符与英文词不等时，不构成自动补删阈值。
- 对白密集场景（多角色快速交锋，短句多）→ 字数可偏少
- 动作 / 视觉场景（追逐 / 沉默对峙 / 大调度）→ 字数可偏多
- 远超 / 远低 → 检查内容取舍；不能为达标擅改别人的场景时长，确需调整则提出原因交 Director 协调

**自检方法**：比较角色选择、声音、场景体验是否足够。沉默或概述可以很短，复杂心理可以较长；不按密度自动补写、删减或改变确认的集时长。

**工具诊断**：适用时可运行 `bash ${CLAUDE_PLUGIN_ROOT}/scripts/novel-budget.sh <ep>`，读取实际 `status`；退出 0 不代表内容合格。`ok` / `warn` / `fail` 是计数结果，不是创作 pass/fail，不自动触发补删；`missing:outline|novel|duration` 表示缺计算依据。无输入不补造大纲，可交有 Bash 权限的上下文执行。

**与制作预算的关系**：覆盖、因果和过渡依具体意图判断；用户确认的单集总时长是制作硬约束，系列沿用初始共同目标，不随前集实际时长漂移。字数信号不能推翻该预算或代替可拍性判断。

**旧配置字段**：`每集小说字数` 不再是工具预算来源，不据此恢复机械门禁。但当前用户明确的篇幅要求仍是委托约束；旧字段与当前要求冲突时说明并确认，不静默忽略用户意图或擅改配置。
