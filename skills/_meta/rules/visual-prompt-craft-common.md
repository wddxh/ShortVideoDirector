# 视觉 Prompt 创作通用规则（共享）

本文件提供图像与视频共通的视觉表达方法。具体目标状态、信息层次与身份引用帮助专业判断，不规定创作工序或技能调用；资产链接和输出 schema 则是下游消费的真实契约。

**适用前提**：本文件提供精确表达的专业方法，不以过时印象限制创作，也不保证“写得出就能生成”。将预期画面、模型已验证能力和当前接入限制分开；复杂效果先表达清楚，再由 Creator 核实当前模型/操作支持，遇到不确定性说明风险与取舍，不擅自降级或付费试错。

## 单次请求独立成立

### 作品级风格与具体细化

采用具体、正面的外观细化描述：按当前主体展开曲面处理、材质与表面细节尺度、粗糙度和反射、使用痕迹、光照层次及渲染质感。细节服务于既定作品风格与已确认结构，保留必要美术信息。表达方式本身不要求额外试生成，也不构成付费授权或计费承诺。

同一作品共享一份明确的风格基线，涵盖写实/风格化程度、造型语言、材质表现、细节尺度、色彩关系、光影与渲染处理。Creator 优先复用项目现有美术说明；缺少时在现有授权内写入一份项目美术说明并交接路径。Storyboarder 结合配置，将适用基线整合进每个源 shot 现有的 `视频风格` 字段。每次新上下文读取该基线及必要身份参考，保持作品风格一致。

每次请求只表达一次适用的作品级共同风格，并绑定实际上传资产参考。基础图像 prompt 写目标风格与外观；视频要求同组源 shot 的单行 `视频风格` 字段精确相同，Creator 在最终 prompt 表达一次，提取行为遵循所选 provider 材料工具。不同字段交 owner 协调，局部变化写 prose，不模糊去重。Prose 保留详细动作、表情、状态、空间、摄影与声音；manifest use 只说明控制用途/占位边界。路径或前次任务记忆不能代替输入。

金属、布料与皮肤采用相容且适合各自主体的材质表达。日夜、景别、情绪与场景光源可以变化，造型与渲染语言保持统一。局部细化不得擅自重设计已确认身份、配色或结构；需要改变作品基线时交 Director 协调影响，保留未变材料，不自动全量重生。

独立审核既看单图/单镜是否成立，也对照实际采用的风格基线与最小必要作品内参考，判断是否出现材质尺度、写实程度、调色或渲染风格漂移。将实际读取的美术说明纳入当前 inputs 指纹；不把所有历史图塞进上下文，不用关键词一致代替视觉一致，也不把风格判断做成机械词表。

### 粗模控制与外观依据分离

二维参考负责构图、位置、节拍、切点及必要整体运动轨迹；静帧保持、刚体平移、固定支撑姿态和有限动画可作为有意抽象，不表示成片必须停顿、滑移或僵硬。Creator 在实际 `ref.use` 与最终 `manifest.prompt` 明确控制/非模仿范围，按源意图正面写自然动作即可，不因抽象本身要求补步态、完整肢体或三维表演。

最终自然动作以既定主体、作品风格和源意图为准，由 Creator 的实际最终 prompt 正面表达。必要支撑代理随 BODYBOX 整体移动仍是归属/接触示意，不要求步态、摆臂或完整表演。参考事实若与源意图冲突，例如误导接触归属、颠倒遮挡揭示顺序或丢失关键动作时序，才须修正；不能把非写实外观直接判为动作错误。

本地视频参考默认提供相机/取景、位置/布局与整体运动轨迹。人物及类似行动主体的普通移动只用刚性、固定形状 BODYBOX，整体平移/转向，不加手腿。只有既定持有、支撑、接触或构图中的必要动作证据才使用最小肢体/接触代理；例如身体出画、POV 或操作特写中保留最小手掌/前臂，避免手持物失去归属或错误悬浮，画内必要支撑同样适用。这些例外属于已授权本地参考工作，不表示肢体可随意添加。

为持有或构图确需保留的肢体，在普通行进期间采用与源动作相容的姿态，保持相对身体稳定，整套代理一起平移/转向；不为写实感推导步态、腿部循环或摆臂。操作姿态只用于该动作及必要准备/收尾，不作为通用休息或行进姿态。复用场景/运动时核对当前进入、退出状态，保留有意连续动作，不自动重置。手仅在确需的 shot/阶段提供证据；跨阶段用相容构图、遮挡或交源 owner 调整衔接，不能让可见肢体突然出现/消失。例如“指向仪表后收手走开”，指向姿态不沿用为行走休息态；若源意图是边走边指则保留。只有受托的具体特殊动作确需关节运动的时序证据，且 Creator 有意识选择此表达时，才制作最小关节变化；缺解剖本身不触发补肢体或动画。默认不制作完整 rig、精细手指、脸部动画或纹理身份。

复用动画先核对实际求值的 action、曲线、driver、可见性、材质与 gamma、约束、父子关系及时钟，只修冲突通道，保留有意关键帧。必要接触的手、前臂与道具沿一致接触变换保持握位，不各自插值世界位置；松开/换握按源事件发生。按风险检查可达性及中间帧，所选特殊动作的关节变化需要中间运动/支撑证据；插值可能翻转、脱离或过冲时检查子帧；四元数保持等价朝向的半球连续并选相容旋转插值，保留有意长转。具体方法见 [动画复用与接触](../../creator-local-reference/tools.md#animation-reuse-and-contact)，不要求逐帧验收或完整 rig/碰撞框架。

粗参考越省略细节，shot prose 越需把影响理解的事实写清：谁做什么，身体/头部与道具的朝向和姿态，画面左右与角色自己的左右，归属、握持/接触，以及必要的初态、中间变化和终态。具体受力、视线、表情和口型也由文字与模型负责；按当前动作需要选择细节，不设每镜全字段或数量配额。最终 prompt 解释实际肢体/接触代理如何还原为该角色的解剖、姿态、握向和动作，不把粗盒外形当最终人体。环境/道具几何和静态资产形状参考保留各自用途，统一风格与实际身份不因 BOX 改变。

当某个具体动作是叙事重点，由镜头与动作 prompt 共同表达：选择让最终动作清楚可读的景别/角度，必要时采用近景或特写。本地视频提供相应取景、位置、轨迹及必要支撑，文字写清哪只手、接触哪里、先后关系及结果。例如拧阀与换手时，近景聚焦轮缘操作区域，以最小手/前臂代理标明必要的操作归属与接触走向；文字明确一手保持接触、另一手松开移到新握位后重新握住，不要求逐指动画。

粗参考审核按实际媒体控制责任核对叙事时钟、取景、尺度、布局、轨迹、相机及必要支撑与源动作是否相容。静帧保持、刚体平移、固定代理姿态、SVG 平面风格及省略表演细节本身不失败。必要动作初中末的关键关系、接触和揭示按声明控制保留可见依据，不要求连续自然表演。肢体/支撑或投影异常只有实际误导归属、接触、空间或关键动作时序才须修；不能从粗略姿态直接推定源人物僵硬。正常肩部连接、合理遮挡/投影重叠不套零相交或完整解剖门禁。

具体源冲突出现时，优先省去非必要误导代理，或修正相容的姿态、机位及动作支撑；保留必要接触和剧情动作。必要设计冲突交源 owner，明确冲突未解为 needs_revision；确有必要控制证据缺口为 unknown。实际 use/最终 prompt 明确抽象与自然动作的分工足以处理有意省略，但不能反转矛盾的参考事实。按意图区分真实悬浮、透明屏幕和有意遮挡，不凭无支撑外观一律加手；不要求完整本地表演证明，缺媒体、输入指纹与独立审核门禁不变。

图像和视频使用粗模参考时，最终 prompt 须逐份绑定实际媒体并明确职责。基础资产图主要提供身份/外观、风格、画质与材质；静态形状 PNG 按声明控制形态/结构，BOX MP4 可控制透视、空间遮挡、取景、尺度、位置/布局、整体轨迹及时序、机位/运镜和必要支撑，不承载完整人物表演。资产静帧无需精确复制逐镜控制，非剧情关键的细节不一不自动成为冲突；用户明确要求、关键可辨特征/动作与真实身份/质量问题仍绑定。基础图不以未来视频存在为前提，最终集成按实际媒体核对，不虚称未提供或未查看的视频已解决问题。内部备注不能代替模型输入。

粗模的权限限于声明的结构、布局与相机控制。人物形象与服装由本次实际资产参考和正面目标描述确定，统一材质、配色、光影与渲染按本次风格要求实现。没有其他参考就直接写清外观目标，不能虚称存在风格图。本地视频为主体、重要道具与环境/背景安排相互可辨的占位色，同时拉开必要明度，不只靠色相；同一角色在装组及相关镜头保持稳定配色。简单表面、光照与背景须让场景所需轮廓、空间遮挡及整体物体接触关系可读，避免过曝白或死黑吞没线索，不追求写实材质、纹理或美术精修。保留有意遮蔽及揭示时机，区分相邻主体不授权提前暴露秘密或取消遮挡。现有 reference `use` 写明颜色对应的角色/道具及其内部位置标识用途，不把颜色当最终身份、材质或风格；生产参考不加内部位置/调试文字标签，正式文字按 [转场与片中文字](transition-craft.md) 使用，不增 schema。配色按场景选择，不规定通用色板、善恶色码或精确颜色门禁；只因具体可读性冲突定向修正已有目标，不全量重涂，不改变静态资产图的外观/形状职责。最终人物按实际身份参考和文字动作实现，保持声明的布局、轨迹与相机关系。

### 按实际参考限定非目标特征

Creator 依据实际参考的检查证据、源意图与各 ref 的职责，识别本次容易被误带到成片的具体非目标特征。每份视频 `ref.use` 写清声明的控制用途；有具体歧义时，在相关 `use` 和最终 prompt 实际使用处／任务时间段落明确：保留哪些控制、不照搬该参考的哪些实际非目标特征，以及按源动作、实际身份依据和既定风格正面实现什么。泛化开场说明不能代替局部消歧。Creator 在审核前亲写确切 `manifest.prompt`，保留稳定实体名、真实有序输入及 provider 专用内联绑定，不由工具自动注入说明。

例如，仅当实际参考与源意图支持时：BODYBOX 滑移保留路径和时序，人物按源意图自然迈步；必要支撑代理的固定姿态只提供归属、握向和接触证据，最终姿态随源动作自然变化，保持必要持有与连续性；占位色只标识位置，最终外观取实际身份图；参考中的非目标渲染噪点或粗模质感不照搬，最终采用已确认风格。这些是条件示例，不是每条 prompt 的负面清单；不编造未观察的特征或缺失的源事实，不自动增加手势。内部标注应从上传媒体排除，不能上传后靠 prompt 要求忽略；正式片中文字仍按其源意图保留。

只针对实际参考职责与具体歧义写必要排除并给正面目标，不设固定黑名单或通用 `negative prompt` 参数；具体表达与可用字段遵循所选 provider 指南。

接点的停顿/重启判断同样按控制职责：构图或支撑代理的静帧保持不自动声称角色停步；只有实际控制或最终文字改变了源事件进度、关键时序或连续关系，才构成需要修正的新增停顿。

将源表演落实到实际 BOX 与最终任务时间段落时，遵循 [触发、反应与任务时间整合](audiovisual-craft.md#从触发到人物反应) 及 [跨镜头、任务与场幕的剪辑关系](audiovisual-craft.md#剪辑关系跨越镜头任务与场幕)。TASK 是生成单元，进入/离开状态可仍在动作或发声，不在参考尾部默认刹停、摆结束姿势或在下组重启。最终 prompt 带当前局部事实；同一连续事件保住必要动作进度、持有/接触、空间与声音的相容延续，不要求相同帧；场幕/时空跳转保留源意图的叙事关系与观众定位，不强制同位置、续动作、续声、过桥场或顺滑解释，保留有依据的悬念、突兀感与硬切。同集底层身份/世界事实仍保持源一致。BOX 仍只承担声明控制，不新增表演或解剖要求。

实际 `use` 与最终 prompt 已清楚区分控制和成片动作时，静帧保持、二维滑移、固定代理姿态或有限动画本身无需返工；不因假想模型模仿或风格泄漏增加制作/审核轮次，也不宣称未经实际模型对照的“完全杜绝”。只修具有具体源冲突的参考事实，prompt 不能把错误接触归属、遮挡揭示顺序或关键动作时序改成相反事实。Reviewer 依据源意图、媒体职责、最终文字与观察证据判断：明确冲突为 needs_revision，确有必要控制证据缺口才为 unknown；不按动画精细度、否定词或 token 数量验收。静态形状参考仍按声明控制轮廓、拓扑/连接与比例，不要求复制无关细节。

最终视频输入遵循 [shot-inputs](shot-inputs.md)：Creator 设计后装组连续摄影 shots，保留时长、对白和切点；`task-inputs/taskNN.json` 草稿恰为 `{shots,references}`，最终恰为 `{shots,references,prompt}`，Creator 据 materials 写完整语义 prompt 并自查最终 `--json`。每任务至少一个全组 MP4。Header 身份图按首次使用求并集在前，本地媒体在后；各镜链接须自身 header 声明，sources 不上传。BOX 表达相机/布局/整体轨迹，静态段可用 clip，GIF 不支持。独立 shot-input 以最终 manifest 为 target，审核源忠实度、完整性、集成/delta、任务时钟、内部切点/声音桥和必要边界，无冲突复用 storyboard 判断；草稿不就绪。以下“参考图”也包括声明的 video refs。

必要物件不可见时，先查相关时刻是否真正参与渲染、隐藏曲线、求值后几何及场景尺度/尺寸，再诊断遮挡、裁切与投影；视口中存在不等于成片可见。不要靠搜索机位弥补对象未渲染或尺寸错误。既定人物视点、取景与几何确实不相容时，把具体冲突交源 owner 协调，不能以 prompt 要求“看清”覆盖媒体矛盾。

本地视频参考默认采用轻量 animatic／混合参考。完整性要求是最终 task MP4 时间轴，不是所有画面都用 SVG；Creator 按镜头选择已有资产 PNG、分层图像、二维动画、必要 3D 或已有视频片段。SVG 是可优先选择的可编辑平面素材之一，工具是素材生成组件，不强制每镜 SVG 或单一生产路线，不重做已合适的素材，不以工具纯度验收。保留源取景、布局、节拍、切点、必要整体轨迹及动作关键关系，复用背景/对象、局部修订减少耦合，不做细 rig。

正式 selected clean 默认对齐已选视频比例/分辨率，用户明确本地 override 优先。Creator 核实实际像素依据，16:9 + 720p 常见的 1280×720 不是所有比例/provider 档位映射，未知档位不猜短边。每集统一 CFR fps：用户指定优先，否则 Creator 为本集选择一次源时钟兼容值，未选不默认 30。最迟在最早正式参考制作前，Director 协调有界配置 owner 在 canonical config 的 `## 本地参考 epNN` 存 `epNN 本地参考宽度`、`epNN 本地参考高度`、`epNN 本地参考fps`，注明 final settings 或 explicit local override 来源及依据；源码/导出读实际存值，不抄示例。

低分辨率草稿可用于迭代，正式选中 clean 按已存规格核实际媒体。复用先查尺寸/fps/时长，合适则保留；不符只局部补导出/转换并保持相机、比例与 canonical 时钟，metadata 改名不能代替匹配。配置缺规格由有界 owner 补齐，与环境报告分开，不新增初始化探针或自动迁移历史。配置变化对既有审核作 scoped 兼容性评估，不盲刷指纹。Creator 交付前运行 [selected-media 检查](../../creator-local-reference/tools.md#saved-spec-and-selected-media-check)，Reviewer 先采集 config/selected media 再核实；工具诊断不是语义 pass，不新增 kind/schema/自动 gate 或额外轮次。

静帧保持、刚体平移和离散姿态可表达构图/节拍，不自动等于源人物停止或动作错误；按实际素材声明的控制及最终 prompt 判断是否保住必要接触、揭示顺序和关键动作时序，自然成片表演由 Creator 的实际最终 prompt 引导，不以素材或动画形式一刀切。

Creator 将静态空间素材与时间合成分开：固定构图可只制作一帧 SVG/PNG 或 Blender 静帧，再按源区间 timed hold、叠加 UI/可见性状态层。必要运镜、整体轨迹、接触变化或揭示仍以适当的最简动画表达，静帧不能替代必要运动证据，合成保留当前 shot、对白、切点和 task clock。最终仍交完整 clean MP4 及同源完整字幕审阅 MP4。

Creator 自读固定项目报告 `story/work/shared/environment/environment.md`，在已验证能力中按镜选材；报告作为常规稳定 read 依赖，不进 manifest.sources 或默认审核语义 inputs。Director 协调初始化/定向更新的占用与稳定性，交接指定视觉成果及源边界；保留用户固定或 Creator 确选的局部实现，其余材料由 Creator 决定，不预设全组 `.blend`/CUDA。在现有 handoff 简短说明可复用什么、还缺什么控制、最简材料为何适用，不另建选材表或审批。

允许为有界场景编写 SVG 相机/透视投影并复用显式图层，按实际结果披露几何与遮挡的适用范围；这不要求所有素材使用 SVG。合适的复用素材与轻量投影仍无法表达必要复杂空间、旋转、推轨、遮挡或接触时，可选最小 Blender/3D 组件；不能为迁就工具改写源镜头、动作或切点。只制作未解决的空间/时序关系，混合素材最终合成覆盖当前 task 连续全部 shots 的完整 MP4。Blender 选择实测适用的 GPU 路径，区分图形与计算能力；不可用时说明依据及已验证 CPU 回退，不自动启动重型 CPU 动画，也不为绕过工具失效把有界投影扩成通用 triangle renderer、depth buffer 或任意遮挡框架。

目标是降低制作—检查—重做的迭代成本。返工先定位实际冲突，再由 Creator 重新选择适当表达：可复用或换成静帧/图层、有限二维动画、局部 3D 或混合组件，同步实际媒体、sources/use/prompt；源镜头、动作或时长重设计交 owner。完整导出前及早检查必要构图/姿态，运动、插值或接触疑点用短时序草稿验证；具体顺序与取舍由 Creator 决定，不新增 review gate、强制额外审核轮或逐轮许可。早期图片/草稿不替代最终完整组 MP4 及既有独立审核。每次视觉操作仍用 fresh task、最小必要 helper 缩略图，保留时序证据与 unknown 边界。

本地动画导出 MP4，不逐帧建脚本、持久 PNG 序列或新进程；Blender 用原生批量 FFmpeg 输出，外部 FFmpeg 负责 clip 拼接、必要转码/封装及后续按需抽帧。允许逐镜或混合 clip 合成，保留当前源时长、对白、切点和声音桥，完整组时钟无缺段或额外秒数，不要求单体场景。降低渲染秒数不代替减少返工；中断 MP4 可能不可用，短 clip 可限制损失，不自动退回序列。静态资产 PNG 仍适用；图像序列只作明确用户需求的例外。

可编辑 SVG、实际动画/绘图脚本、字体及其他导入依赖留在故事项目 `references/`，使用 Blender 时保留 `.blend`。这些实际依赖进入 `sources` 与审核 inputs，不上传；typed references 仍只接受 PNG/MP4。工具缺失先诊断，不堆叠通用框架、制作 parser、规范化 schema 或固定几何 DSL。具体方法见 [creator-local-reference](../../creator-local-reference/SKILL.md)，卡片声明见 [本地参考契约](local-reference.md)。Creator 在每份视频 `use` 及亲写的最终 `manifest.prompt` 说明控制用途/占位限制，按源动作描述自然成片的姿态、重心和迈步，不照搬 SVG 滑移、僵姿或粗代理解剖；错误媒体先修，文字不能抵消。完整 MP4、五种 kind、既有 gates、provider 最大值与 grants 保持原契约；本地预览不是付费成片或源事实修订权。

基础 prompt 绑定实际参考及本地 narrative 的控制意图；资产图在前，本地 images 按声明顺序追加，sources 不上传。Prompt review 须看已制成本地 PNG/源码，不要求未来输出 PNG。本地自检不替代独立审核。

轻量 animatic／混合参考均实际交付完整 clean MP4＋由同一 clean 派生的完整字幕审阅 MP4，供用户核对时间，不受素材组合或工具选择限制。按 [字幕审阅工具](../../creator-local-reference/tools.md#caption-review-mp4) 使用现有 `previs-preview.py --timecode` 与 PLAN：`segments` 的 `speaker/text/spans` 保留源所有对白、旁白原词及对应任务时间窗；完整性指所有原句/窗口覆盖，不是全程挂满字幕。跨切延续、重叠和停顿按源意图，未精确指定的窗口以源内估时交接，不改 canonical 时间。无需 TTS 或假音频。

字幕版 picture 宽高、fps、完整时长和切点与 clean 一致，总高度为 picture 高度加新增底栏。核实际输出，不缩放或裁切 picture 来腾字幕空间。完整审阅版用现有 PLAN 的内部标记 segments 标明每个实际内部切点及其 task 时间；窗口可用小数秒，标记原文写准确时间，`--timecode` 仍仅整秒 HH:MM:SS，不虚称自动识别或帧/毫秒时码。单镜无内切则据实说明。内部标记不进入 clean/final prompt，审阅字幕/时间码不上传，正式上屏字保留 clean。交回两版实际路径及 PLAN，工具不足报 Director/main；不新增 schema、gate 或强制审核轮，原独立 owner/helper 流程保持。

整集预演消费同一已存规格，逐 PARTS 核对完整 clean 的宽高/fps 与 canonical 组时长，不能以自动最大画布补边掩盖不符。先局部修兼容性再拼 clean 和加字幕，保持 canonical 全片累计时钟及已有音频；有声/无声混合时为无声段补等时静音，全无声保持无音轨。补充小视频按其声明用途判断，不要求每条都覆盖全组时长。

每条图像或视频 prompt 的可用上下文只有本次最终请求文本与实际随请求提供的参考图。创作者从剧本、其他卡片、场景和镜头取得设计依据，再把生成所需事实写入当前文本，或显式绑定本次确实提供的参考图；模型可消费性审核也以这个边界判断。项目内存在某卡、审核者读过原剧本或上一任务生成过图片，都不等于本次模型获得了它。

例如，可按已确认设计写“右手握黑色缠绳剑柄，窄直银灰剑身朝下，黄铜十字护手”；也可在支持的引用区声明真实道具资产，随请求提供对应图片，再用绑定名称描述持有关系。已有绑定承载可见身份，当前动作、状态与空间关系仍写在本条；未绑定对象用本地可见特征表达。

其他镜头背景、场次预算与制作说明保留在源元数据。最终 prompt 明确当前起始姿态、持有物、朝向、光线及目标状态，替代“承接上一 shot”；资产身份绑定实际上传图。审核者比较最终文本/refs 与意图，不能在心中补齐模型缺失上下文。必要边界依赖由独立 shot-input review 记录与评估。


### 从故事事实选择当前证据

取景与细节层次可参考 [视听 craft](audiovisual-craft.md)：选择观众首先注意的主体、随后能辨认的证据及背景的作用。静态图用尺度、明暗、遮挡与空间关系建立主次；视频还要落实显露和反应的时机。必要细节提供身份、生活感、行动条件或叙事证据，不把所有表面与物件等量铺开；精确关系比一串“精致、丰富、电影感”更可用。

事实正确不等于生成指令成立。先判断观众此刻是否需要知道，再选择源支持的可见或可听证据；其余留在源材料。非成片年份、罗盘方位不默认进入最终 prompt，也不把“东北”擅自换成屏幕右侧。按 [转场与片中文字](transition-craft.md) 使用必要 UI、观众 SUPER、时间/地点/章节卡及转场图像，保留有意成片原词；不为逐条兑现背景新增叙事或装置。清洁 MP4 排除内部调试污染，不排除正式文字设计；生产参考默认不加的文字标签仅指内部位置/调试标记。

例如，夜间岸边的镜头可描述已确认光源、人物相对岸线的位置及当前动作；道具状态可用已确认部件的可见位置与连接关系表达；册页特写写本镜实际可读的内容与布局。具体证据以材料和当前叙事需要为准，缺必要设计时交负责人选择。场景总预算留在 shot 结构边界外，本镜只承载自己的时长与视听事件。

依据上游意图区分观众与人物的知情时点：观众已看见的物件，人物可因视线或遮挡仍未发现；当前请求须让这种差异成立。文字写“尚未发现”却让取景、视线或反应提前泄露，不靠情绪标签修补。揭示前后的可见范围与动作按真实参考表达，不为补证据新增上游没有的秘密、道具或台词。

## 6 条核心原则

### 原则 1 — 写电影摄影指令而非小说叙事

承载视觉信息的描述要落实为可感知的动作、构图、材质、光线或空间关系。精度服务于意图，不为了显得专业给所有属性编造角度与数值；准确术语首次使用宜简释。

例如：“中近景，四分之三侧脸，黑色长发覆盖左半张脸到颧骨，右眼可见，眼尾自然上扬。”外观细节须与本次身份依据一致。

### 原则 2 — 正面描述画面真正呈现的内容

生成 prompt 直接描述希望呈现的主体、形状、材质、动作与光线。修正画面时保留控制意图，用表面、轮廓、空间占用或动作终态建立完整目标，而不是追加排除对象清单。

例如：“外壳为深灰金属，表面分布细密随机短刻痕，边缘呈柔和反射；暖光从接缝透出，亮度集中在缝口。”具体材质、纹理与发光结构以已确认设计为准。

服务专用的 `negative prompt` 字段与正面画面描述是不同接口；当前未接入的字段不能假装可用。审核判断目标是否清楚、参考权限是否准确，不扫描否定词。授权、安全、状态与执行边界中的禁止性规定仍须遵守，它们不是画面排除提示。

### 原则 3 — 显式分解复杂效果

对容易混淆的层级、位置、内容、颜色和文字尺度给出具体关系；仅在需要精确对齐时指定数值，不强求每项都填。

已确定画面需要文字时，可写：“画面下沿叠加金色简体中文字幕：‘入口’，整行文字宽度占屏宽 20%，居中对齐，字体宋体加粗。”内容与尺度按实际设计确定。

> **数量取舍**：单一阅读焦点有助于控制字形、位置和观众注意力。字幕与招牌并存时明确主次、位置和必要文字内容；密集街景可将次要招牌作为环境纹理，不必逐字规定。精确文字能否可靠生成取决于当前模型，必要时提出后期方案而非承诺一次完成。

### 原则 4 — 比喻与心理转译为可见画面

视觉信息应有观众能感知的形状、运动、光影或表演证据。比喻可帮助沟通美术意图，但含糊时宜补充具体目标状态，避免模型把比喻误作新增实体；不是通用修辞禁令。音视频中的旁白、内心独白和声音设计都是合法表达，心理信息不必全部改成外显动作。

例如，已确认的光效可写“暖色光束从人物背后向上展开，两侧对称，最高处达到人物身高的两倍”；迟疑可表现为“手停在门把上，呼吸短暂停住”。选择与当前设计和人物动机一致的证据。

**判断方法**：比喻若是风格捷径，补充轮廓、尺度或节奏；若是剧情信息，选择表演、画面或已授权的声音承载。例如“害怕被发现”可表现为手停在门把上、屏息，也可保留剧本内心独白。不要为了可见性改写对白或强加夸张表情。

### 原则 5 — 资产引用：按实际输入绑定关系与用途

省略完整外观须以实际上传图和明确绑定为前提。基础 prompt 自包容不要求空 refs；资产参考可提供同实体视图、被包含/持有/穿戴资产的外观与结构，或仅指定的共同视觉特征，仍写完整目标及关系/用途。Prompt 可指定位置、朝向、尺度、遮挡与可见部分，不默认复制参考构图；仅共享特征不强制同身份，复杂性/精度确需时才加本地 PNG。Shot 可复用身份，仍写足当前状态。路径不是模型可见参考图；源 shot 链接由所选 provider 材料工具按自身语法绑定，Creator 对照实际 refs 编写最终 prompt 的引用表达。

| 场景 | 引用机制 | 当前目标表达 |
|---|---|---|
| 标准角色 / 物品 / 场景 / 建筑 prompt | 可选基本信息「资产参考」有序 canonical 卡直链 + prose 关系/用途，由 Creator 映射图片 | 完整目标外观与空间关系；真实同实体才保持共同身份、拓扑、材质与状态，仅共享特征限定借用维度 |
| 衍生资产 prompt | `## 基本信息` 中 `基础资产: [{基础名}](...)` + `基础类型: {type}` 单向引用，参考图自动为基础 .png | 基础视觉特征（材质/颜色/布局/标志物）与状态变化 |
| 持久化造型变体卡 | `## 基本信息` 中 `基础角色: [{角色名}](...)` 单向引用，参考图自动为基础角色 .png；创建变体使用衍生资产模板 | 基础五官、发型、体型与当前服饰款式、颜色、配饰 |
| storyboard shot prose | 「出场人物」/「引用资产」字段链接 + prose 裸名字 | 当镜动作过程与终态、朝向、空间、摄影和声音，按需强调可见身份特征 |

标准卡自包容与 refs 可并用。衍生资产保留基础特征并写状态变化；shot 通过实际 refs 承载身份，正文写目标。未绑定对象补可见特征或合法引用。Shot 使用已声明 Markdown 链接，由转换器分配槽位，不手写或猜测最终 provider 槽位。

### 全局映射与实际使用处的引用

最终 prompt 先明确实际参考与稳定实体名、代理及控制维度的全局对应，再在实际使用该参考的正文中内联绑定。新时间段、对象切换、关键操作、切镜或代词可能混淆时，重申相关实体名及所用参考；连续且无歧义的文字可自然承接，不要求每个代词附 token 或逐句套清单。同一实体全篇采用稳定名称，不能在多个主体间漂移使用“机器人／他／另一个”等称呼。

每次引用说清当前采用的维度：资产图按关系/用途提供身份、外观与结构或选定共同特征，轨迹视频提供该时刻的相机、布局、位置和整体运动，文字提供当前目标关系、源表演与声音；静态形状参考按声明供结构。不要一句“照参考全部还原”混合这些权限，也不要照搬资产图的无关构图、静止姿态或 BOX 的僵硬运动为最终表演；共享特征不意味着照搬源身份。全局对照表不能代替实际段落绑定；引用语法与编号以所选 provider 的图像/视频指南为准，共享层不规定 token 格式。

Creator 亲写这些语义关系，Reviewer 通读完整最终 prompt，对照真实有序输入核对 token、实体、代理和用途在全文是否一致。指出具体错指、歧义或权限串用，不以 token 出现次数判断质量；不增加机器改写、检测器、schema 或门禁。

### 原则 6 — 方位以当前画面为基准

位置、朝向与运动方向使用当前画面坐标，显式写画面上/下/左/右；资产以选定视角、shot 以当前机位和时刻为准。保留前景/后景、靠近/远离镜头等纵深。角色解剖左右另写“角色自己的左手/右手”，不把屏幕左当左手或因转身误判换手。

东、西、南、北等世界方位可留剧本、场景背景或必要叙事上下文，但不能单独充当生成画面的定位指令。作者核对实际参考、同实体锚点与选定机位后，提交的提示只写画面中实际位置、朝向与动作，不附带“东边投影到左侧”等坐标推导。机位关系的判断留在制作诊断中，不盲换“东=右／西=左”。作者在职责内选择机位；依据不足或源材料冲突时查实际 refs，交对应内容负责人澄清，不在下游覆盖上游事实。

换机位、反打、转身或运镜可能改变屏幕投影，按当前视角和动作阶段重述必要关系，不要求所有角度固定同一左右。连续性保留同一实体的门窗邻接、内外连通等拓扑、标志物与实际持有状态，而非把锚点图的屏幕左右永久锁死。

对白、地名、招牌或地图方向文字不是位置指令，不机械改写。画内地图/罗盘确有叙事用途时分清内容与画面位置，不凭背景新增仪器。此为语义原则，不新增方向替换、正则过滤或 schema；完整 shot 与引用绑定保留。

有实际视角依据时可写“人物在画面左侧前景，吊灯在右上方后景”，或“人物向后景门口走，远离镜头”。正面、双臂未交叉且非镜像时可写“用自己的右手持杯，该手位于画面左侧”；转身后核对同一只手及投影。示例以实际机位为前提。

## 数据转换与执行接口

下图表示材料如何被现有脚本消费，不表示专家的技能链或自动下一阶段。只有实际依赖约束执行先后；是否生成、恢复或替换由当前材料与授权决定。

专家按创作需要选择工具与本地源码表达；provider wrappers、evidence 和 pending/receipt 负责实际接入、付费保护与恢复，不调度艺术决策。现有执行协议必须保留。下图的资产/衍生路径可按共享契约追加本地 images；本地制作直接使用适当工具。

图片批次仅含授权资产与当前审核提示；默认本地并发 5，Creator 按接入限制用 `--concurrency N` 覆盖，不等于账号总配额。实际资产引用依赖须就绪，无关 jobs 可并发。首次失败/pending 停新并排空 active，保留全批结果；不 shell 并行 raw 调用绕过 runner。

```
[标准 asset .md `## 图像生成提示` + 可选基本信息「资产参考」（直链 + prose 关系/用途）]
  → Creator 按声明顺序用 asset-to-image-path.sh 映射直接参考卡为 images
  → generate-images-dreamina.mjs JOBS.json（source/output/prompt/images/settings）
  → image-gen-dreamina.sh (无 refs: text2image；有 refs: image2image；第 7 参数=asset card path)
  → assets/images/{type}/{name}.png

[造型变体 .md `## 图像生成提示`] + [基础角色 .png]
  → generate-images-dreamina.mjs JOBS.json（实际基础图片依赖）
  → image-gen-dreamina.sh (image2image, 第 6 参数=基础角色 png，第 7 参数=asset card path)
  → assets/images/characters/{name}-{variant}.png

[衍生资产 .md `## 图像生成提示`] + [基础资产 .png（按基础类型动态推导）]
  → generate-images-dreamina.mjs JOBS.json（实际基础图片依赖）
  → image-gen-dreamina.sh (image2image, 第 6 参数=基础资产 png，第 7 参数=asset card path)
  → assets/images/{基础类型}s/{基础名}-{状态名}.png

[storyboard.md 连续 shots + task-inputs/taskNN.json 草稿 {shots,references}]
  → 所选 provider 自有材料工具（命令、pack、引用语法见该 provider 视频指南）
    header 身份图首次使用求并集在前，本地 PNG/MP4 在后，每任务至少一个全组 MP4
  → Creator 据 canonical 源、provider 工具输出及实际 refs 写完整语义最终 manifest {shots,references,prompt}
  → storyboard-to-prompt.sh --json STORYBOARD TASK_ID EP（.mjs 同参数），自查原样 prompt
  → fresh 独立 shot-input review: 最终 manifest、源忠实度/完整性、prompt/refs 集成及实际边界
  → tasks.json 数组 (task_id + shots + prompt + typed references + duration)，仅授权视频准备
  → video-gen-dreamina.sh --references-json
    (multimodal2video, 已登记授权与输入快照，原顺序传递 --image/--video，sources 不上传)
  → submit_id → video-check-dreamina.sh 查询/下载 → videos/taskNN.mp4
```

真实 wrapper flags 和参数以当前接口为准；需要查询执行细节时，可参考 [图像接口说明](../../creator-provider-dreamina/image.md) 与 [视频接口说明](../../creator-provider-dreamina/video.md)，它们不是必经技能或加载指令。生成 wrapper 维护 `.generation.json`（实际设置、状态、成功输出哈希）；导入/历史图片可无 receipt，不为补记录强制重生。receipt 不是独立视觉验收。

**引用绑定**：Creator 在审核前按选定 provider 的图像语法将基础 prompt 绑定到最终有序 refs，逐份写清参考与目标关系；视频使用所选 provider 自有材料工具，Creator 据源、工具输出及实际 refs 将引用/用途写入最终 manifest.prompt。具体 pack、token 计数/绑定与重基归 provider 文档所有，Dreamina 见 [video.md](../../creator-provider-dreamina/video.md#dreamina-authoring-materials)。已审核 prompt 与对应输入顺序原样提交，不在 runner/wrapper 补写或重编号。Runner 不解析资产参考声明或推断关系，但检查实际图片依赖、本地声明、ready 和有序后缀。缺图不置空或擅自扩目标。

视频上传来自各成员 header 与 task manifest；prose links 必须在自身 header 声明。材料工具的 pack、源提取、引用绑定和时间重基由所选 provider 定义；共享层不规定通用槽位或 token。Creator 据完整源、provider 材料及实际 refs，将源局部时间和派生 timeline 写成完整任务时间 prompt，对齐媒体时钟和声音桥，保留对白原词及全部动作/叙事信息，去掉内部 task/shot IDs、路径和审核元数据。缺源事实交 owner，不编造 use。部分选组报告完整成员/额外镜头，不扩授权。按 recorded ID/provider 取回 submitted，付费使用 [当前契约](shot-inputs.md) 与真实 grants。


## 适用边界

- ✅ 图像生成 prompt（character/location/item/building）
- ✅ 视频生成 prompt（storyboard shot prose）
- ✅ 视觉 review skill 的"prompt 表达"审核维度
- ❌ 不直接适用：narrative 文本（script / outline / arc）

## 与其他共享规则的关系

- `output-language.md`：管 prompt 字段**语言**，本文件管 prompt **内部表达技巧**
