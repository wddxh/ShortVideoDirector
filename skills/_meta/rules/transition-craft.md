# 转场与片中文字

供 Scriptwriter、Storyboarder、Creator 和 Reviewer 按职责共用。以观众在切换中获得的信息、时间感和情绪为设计起点；硬切、简洁字卡、转场图像、声桥和复杂匹配都可有力，不按技巧数量或复杂程度评价品味。本文提供 craft，不增加字段、角色、门禁或执行授权。

## 三类文字与清洁输入

- **场内文字（diegetic）**：书页、招牌、设备 UI 等属于故事世界。观众能读与人物能读/操作分别成立，按剧情核对有效面、视野、状态和触发。
- **面向观众的成片文字**：SUPER 是叠加在画面上的文字；时间/地点字幕、章节题字、全屏字卡和最终字幕可直接组织叙述，不需要演员阅读面、场内屏幕或人物反应。全屏卡可用纯色、黑底或设计图像；明确它是成片画面，而非调试页。
- **内部预览标注**：shot/task ID、制作标题、计时尺、调试标签、假音频及预演底栏字幕帮助内部沟通，不是片中叙述。`previs-preview.py` 的 bottom captions/elapsed clock 始终是内部非上传版本，不能代替正式文字设计。

`clean MP4` 指无内部调试污染，允许按源意图设计的 UI、SUPER、字卡和转场图像。清理 source headings 只移除非成片元数据：即使某句话也曾是章节标题，只要已明确要在成片显示，就在最终 prompt 保留其准确原词、用途和出现方式。按语义区分，不按“标题”、年份、黑底或文字关键词过滤。

## 所有权与计时

Scriptwriter 拥有成片原词、时间/地点事实与揭示顺序，在 canonical script 的场景内容/转场中明确必要正文及观众知情时点。源已确立“一天后”，选择用字卡呈现可属设计；源没有的隔日跳转会改变事件时间，须交 Scriptwriter/Director 按 scope 协调，不能当包装偷加。尚缺的成片措辞也交源 owner 落定，不能由装组临时编造。

Storyboarder 设计文字所在画面、进入/停留/退出窗口、切点及声画关系，Creator 负责字形、版式、转场图像及可选本地参考。独立全屏卡作为 shot 时仍用七字段、正整数秒，计入镜头数、场景/整集预算和用户单镜限制；不必为无人物卡虚构角色或场内道具。叠字占宿主镜头已有时间，不重复累加；渐显、阅读和退出都在该窗口内。独立卡或过渡图像的时间先进入 canonical script/storyboard，Creator 装组/拼接不额外加秒。沿用原始已确认集预算，确需改源由 owner 同步受影响材料。

## 选择切换的关系

先判断是同一事件的连续、省略，还是时空/叙述层跳转，再选择观众应带过去或刚刚失去的东西。考虑切前注意点、切后识别点、两者之间的信息差及情绪余韵：

- **图形与概念**：形状、色块、运动方向或构图重心可形成呼应，也可用反差制造突变。说清匹配哪个维度以及跨越了什么；概念关联不等于像素重合或同一动作继续。
- **声音与情绪**：前场一句话、未解问题、声响或音乐可在后场得到回答、反讽或余响。J/L-cut 的实际占用与可执行接续沿用 [视听 craft](audiovisual-craft.md)；情绪承接也可通过相反画面成立，无需强留同一声轨。
- **时间与叙述层**：日期、地点、章节卡可迅速定位，也可有意延迟说明。保住源事实与透露次序；统一字形/布局帮助识别层级，变化须有作用。不能因想用漂亮卡片而新增一天、往事或旁白者。
- **蒙太奇与省略**：选有起点、发展和落点的变化，不用素材串掩盖关键选择、学习过程或关系转折。直切到变化后的状态、一个关键场面或简洁卡片也可能更有效；比较各自保留和省去的体验，不强制桥段或技巧配额。

## 制作与验收的尺度

文字设计写明准确内容、字体/字重、层级、位置、留白、与背景的对比以及何时可读；按实际字数、语言、字号、显露方式和同时发生的声音/动作估读，不规定统一秒数。必要时让背景动作或声部让位，避免读字时错过关键反应、揭示或切点。纯黑与静止可形成有效停顿，问题在具体作用和占用，不在颜色本身。

Creator 可用可编辑 2D/SVG/分层稿及实际字体输入制作本地 PNG 或任务时钟内的 MP4 指引，并在现有 `use` 与最终 prompt 声明文字、版式、时序的控制用途，区别 BOX 占位和内部标签；方法见 [本地工具](../../creator-local-reference/tools.md#film-text-and-transition-guides)。本地文字引导是可选手段，不是新增必备资产。精确成片原词始终保留在实际请求中。

Reviewer 按阶段检查源依据、原词、阅读窗口、对比/裁切、注意竞争及揭示顺序；场内 UI 另查人物可用性，观众 SUPER/卡片不套演员阅读面。检查实际选中参考及最终 prompt，明确已观察的字形/时序与尚未生成的效果；缺必要证据为 unknown，有具体冲突为 needs_revision，不因文字、黑场或简单字卡自动判错。

源材料与本地输入验收只证明该阶段设计和控制依据成立，不保证生成模型准确复刻字形、原词或切点。Creator 按当前模型与接入能力说明具体限制，必要时交接有依据的后期合成需求；既不以“模型弱”笼统禁字，也不承诺准确生成或把输入 pass 当成片质量保证。后期计划不等于已完成合成或额外执行授权。

## 参考案例与来源

以下是对作者论述的简短转述和本项目应用，不是导演意图的唯一解释、通用规律或要求复刻的镜头：

- Kristin Thompson，[Graphic content ahead](https://www.davidbordwell.net/blog/2011/05/25/graphic-content-ahead/)：她指出《2001：太空漫游》的骨头到轨道飞行器仅有大致形状/运动呼应，明暗与背景并不贴合，并将其作用理解为跨越漫长时空的震动。可借鉴概念跳跃与局部图形关联，不把它教成完美图形匹配、同一动作接续或通常意义的 jump cut。
- David Bordwell，[The Hook](https://www.davidbordwell.net/essays/hook.php)：以《国家宝藏》中前场问题在后场得到回答、《忠奸人》中黑画面枪声随后关联靶场等说明声/画可以连接、误导或重释段落。后者的责任意味是文中解读；本项目据此考虑声响如何携带情绪余韵，不把 hook 等同必须连续的声桥。
- David Bordwell，[The Grand Budapest Hotel](https://www.davidbordwell.net/blog/2014/03/26/the-grand-budapest-hotel-wes-anderson-takes-the-43-challenge/)：分析不同时代与嵌套讲述的画幅组织，后记修正了测量值。可借鉴让形式帮助观众辨认时间与叙述层；这不是每次跳时必须换画幅/上字卡的规则，也不授权改固定输出比例。
- John August / Craig Mazin，[Scriptnotes 268](https://johnaugust.com/2016/scriptnotes-ep-268-sometimes-you-need-a-montage-transcript)：以《证人》的谷仓建造等讨论蒙太奇的过程、调性和情绪作用，并建议比较关键场面或直接跳切。借其功能判断，不照搬谈话中的类型禁令。
- [Screenwriting.io：SUPER](https://screenwriting.io/what-does-super-mean/)：SUPER 指叠加在影像上的内容，通常是文字；它是表达约定，不要求场内人物看见。
