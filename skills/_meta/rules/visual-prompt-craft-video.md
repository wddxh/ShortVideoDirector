# 视频 Prompt 创作规则（共享）

本文件被所有写视频 prompt 的 skill（storyboarder-storyboard / storyboarder-fix-storyboard）必读引用。规约视频 prompt 独有的时序 / 镜头 / 事件密度 / 音视频规约。

**前置阅读**：先读 `visual-prompt-craft-common.md`（图像 + 视频共通的 5 条核心原则）。本文件**不重复** -common 内容，只补视频独有部分。

## 4 条视频独有原则

### 原则 1 — 事件密度匹配 shot 时长

单 shot 时长按当前模型上限（如即梦 Seedance 2.0 为 15s，半年内复审），事件量随时长线性。
- 1-3s：1 个主动作 + 1 个简单镜头运动
- 3-8s：1-2 个主动作 + 1 个镜头运动 + 可含 1 个简单转场
- 8-15s：2-3 个主动作 + 1-2 个镜头运动 + 可含转场 + 复合特效

**反例（塔顶降回长街，5s 塞 7 独立事件）**：

```
[9s-14s] 镜头从塔顶降回长街——群演手中、腰间、口袋里的悬浮信息流"啵"地一声全部跳到同一画面：画面里是一道墨色的侧影——是沈昭...画面下方四个金字..."趴在地上的群演悄悄把手往自己的悬浮信息流上一盖
```
（7 个独立事件 + 多焦点 + 嵌套画面无显式分解 + 文学比喻 + 心理动机）

**正例（拆 3 个独立 shot）**：

- **Shot A [9s-11s]** (2s):
  ```
  MEDIUM SHOT，俯视角，长街群演 5 人散落手心悬浮光屏。
  Camera dolly down 缓速从俯视 30° 降至 5°。
  所有光屏 cut 同步切换。
  音效：5 道短促电子音"啵"在 0.3 秒集中触发。
  ```
- **Shot B [11s-13s]** (2s):
  ```
  CLOSE-UP，单个群演手中悬浮光屏占画面 60%。
  屏内嵌入层：女性 3/4 侧脸特写（参考沈昭.md），
  金红色火焰光柱从剪影背后两侧向上喷出，高度 2 倍剪影身高。
  屏内下沿叠加金色繁体中文："古法异常体·沈"，字号占屏宽 70%。
  STATIC。
  ```
- **Shot C [13s-14s]** (1s):
  ```
  CLOSE-UP，群演手腕翻转，掌心 0.5 秒内从向上翻为向下覆盖光屏，光屏熄灭。
  STATIC。
  ```

### 原则 2 — 镜头运动具象（pan / tilt / dolly / zoom / handheld + 速度修饰）

| 反例（运动方式模糊）| 正例（运动方式具体）|
|---|---|
| `镜头从塔顶降回长街` | `Camera dolly down 缓速，从俯视 30° 降至俯视 5°（贴近群演手部高度），耗时 2 秒` |

**常用运镜词汇**：pan（横摇）/ tilt（纵摇）/ dolly（推拉）/ truck（横移）/ zoom（变焦）/ crane（升降）/ handheld（手持）/ STATIC（固定）

**速度修饰**：缓速 / 标准 / 快速 / 急推 / 慢拉

### 原则 3 — 转场显式（cut / dissolve / fade / wipe + 时长）

| 反例（转场未指定）| 正例（转场显式）|
|---|---|
| `画面切换到下一场景` | `cross dissolve 转场，0.5 秒完成` |

**常用转场词**：cut（硬切，瞬时）/ dissolve（叠化）/ cross dissolve（交叉叠化）/ fade in / fade out / wipe（划像）

### 原则 4 — 音视频事件显式指定（音效 / 对白 / BGM 的触发时间 / 音色 / 音量）

即梦 Seedance 2.0 / Veo 3 / LTX-2 等新模型支持音频生成。音频事件应像视觉事件一样具体指定。

| 反例（音效模糊）| 正例（音效具体）|
|---|---|
| `"啵"地一声` | `音效：5 道短促电子音"啵"（音色：高频脉冲，单音长 0.05 秒）在 9.3-9.6 秒内集中触发` |

*（与原则 1 反例同一镜头，此处单独看音效粒度）*

## 复杂效果显式分解模板

### 画中画模板
```
主画面（占比 X% / 构图 / 主体动作）
+ 嵌入层（位置：屏内 / 左上角 / 中心；
  大小：占嵌入屏 X%；
  内容：嵌入画面描述；
  边框：颜色 + 宽度；
  层级关系：嵌入层在主画面之上）
```

### 画面文字模板
```
内容（具体文字）+ 位置（屏内 X 处）+ 颜色（具体色值）
+ 字号（占屏宽 X%）+ 字体（宋体/黑体/楷体加粗/...）
+ 持续时间（出现到消失的秒数）
```

### 复合特效模板
```
主体动作（动作具体词）+ 视觉效果（颜色 / 形状 / 尺寸 / 方向）
+ 持续时间（秒）
```
