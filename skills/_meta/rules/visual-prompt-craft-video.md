# 视频 Prompt 创作规则（共享）

本文件提供视频 prompt 的时序、镜头、事件密度和音视频表达方法，供创作与修正时按问题取用，不指定内部技能或工序。

**相关参考**：[通用视觉表达](visual-prompt-craft-common.md)讨论图像与视频共通的表达原则，本文件补充视频独有部分；两者不是先后执行阶段。

## 单镜输入边界

视频模型获得本次请求的文本和实际提供的 refs。当前 shot 的起始状态、动作过程、终态、运镜、声音身份和转场在本条明确成立；故事连续性由这些局部事实实现。“承接上一 shot”可改为“人物位于门内一步，左手持火把，右手扶住半开的木门，侧身望向院落”。服饰或道具身份可使用本次绑定的图片，当前持有关系仍写明。

场次、制作备注和“场5共35秒”一类场景总预算由作者放在 shot 结构边界外。生成文本保留本镜 heading、完整七字段（含时长/声音特征）、全部 prose 和本地文字；本镜时长另作参数，时序从 0s 起。仅源资产 Markdown 链接替换为声明的实际上传图片绑定，转换器不删字段或语义过滤。对白、内心独白、音效、音乐和摄影信息完整保留。转场写本镜内可执行的画面变化和占用时间；跨镜剪辑关系另留源材料，所需目标画面落实在当前描述。

当前 sheet 的 PANEL labels/timecodes 是参考格定位信息，生成 sheet 时属于有意设计的图像内容；视频解释它们为视觉路线，输出格内场景的全幅运动画面。最终文本自带完整视听描述，使用本次 sheet 与资产 refs 即可理解；源剧本用于核对内容，不充当模型的隐含输入。

## 4 条视频独有原则

方向按通用原则 6 的当前画面基准表达；转身、反打或运镜时区分角色自己的左右与屏幕投影，写清有信息价值的起落位置及纵深变化，不把每镜锁在同一左右。sheet 参考中的方向属于各 PANEL 内部画面，不是整板格位；对白和仪器上的方向文字仍保留原意。

### 原则 1 — 事件密度匹配 shot 时长

单 shot 先满足 Creator 核实的当前选定 provider/model 真实最小/最大时长、合法整数秒，以及用户单镜限制、场景/整集预算和固定镜头数；不以 15s 作为跨模型上限。以该模型实际最大时长为 M，无叙事、节奏或预算理由时默认设计至少 `0.7 * M`，从 `ceil(0.7 * M)` 起选合法整数秒。M=15s 得 11s、M=30s 得 21s 仅为计算示例，不是静态模型清单。硬边界优先，能力未知先核实，不为达建议值自动延时或换模型。事件承载不随秒数简单线性增加：对白、视线转移、空间重建和复杂动作都占用理解时间。

可先为一个短片段设计一个清楚的主动作；较长片段可展开准备、动作与结果。比如约 2s 的道具插入适合一个识别点，约 6s 的反应可容纳发现与迟疑，约 12s 的开门可交代试探、显露和终态。这些是节奏示例，不是时长或动作数配额；最终须落在当前模型和用户允许范围。

特别短且无独立表达价值的镜头优先考虑与相邻兼容镜头合并，节省生成与连续性成本；反应、插入、蒙太奇、转场、结尾落点或预算分配可合理低于建议值，不要求逐镜理由表或关键词证明。短镜仍须符合真实模型最小值；不得强合不相容时空/运镜/动作，不得超模型上限、改固定镜头数、删改对白或增加整集预算。系列沿用初始用户共同集目标，不逐集按前集实际时长漂移；显式范围与严格边界不再加容差，详见 storyboarder-storyboard/rules.md。

**反例（塔顶降回长街，5s 塞 7 独立事件）**：

```
[9s-14s] 镜头从塔顶降回长街——群演手中、腰间、口袋里的悬浮信息流"啵"地一声全部跳到同一画面：画面里是一道墨色的侧影——是沈昭...画面下方四个金字..."趴在地上的群演悄悄把手往自己的悬浮信息流上一盖
```
（多焦点切换、嵌套画面和动作结果争夺阅读时间，主要风险是信息不清，不是出现比喻或心理动机本身。）

**一种覆盖方案（拆成三个注意焦点）**：

以下沿用场景时间以便比较，不是最终七字段交付。若当前模型最短时长不接受这些片段，或合并可保持焦点清楚，应在既定场景预算内另行切片；生产 shot 时间码从 0s 开始。不要为迁就示例而擅自延长剧本。

- **Shot A [9s-11s]** (2s):
  ```
  MEDIUM SHOT，俯视角，长街群演 5 人分散站立，各自掌心上方悬浮一块光屏。
  摄影机缓慢垂直下降至群演手部高度，同时抬镜保持光屏在画面中心。
  所有光屏内容同步切换，主镜头保持连续。
  音效：5 道短促电子音"啵"在 0.3 秒集中触发。
  ```
- **Shot B [11s-13s]** (2s):
  ```
  CLOSE-UP，单个群演手中悬浮光屏占画面 60%。
  屏内嵌入层：沈昭四分之三侧脸特写（在七字段中声明真实资产链接），
  金红色火焰光柱从剪影背后两侧向上喷出，高度 2 倍剪影身高。
  屏内下沿叠加金色简体中文："古法异常体·沈"，整行文字宽度占屏宽 70%。
  STATIC。
  ```
- **Shot C [13s-14s]** (1s):
  ```
  CLOSE-UP，群演手腕翻转，掌心 0.5 秒内从向上翻为向下覆盖光屏，光屏熄灭。
  STATIC。
  ```

### 原则 2 — 镜头运动具象（pan / tilt / dolly / zoom / handheld + 速度修饰）

| 反例（运动方式模糊）| 正例（运动方式具体）|
|---|---|
| `镜头从塔顶降回长街` | `摄影机沿立面缓慢下降至群演手部高度，同时抬镜保持光屏居中；实际距离与所需时长匹配` |

**常用运镜词汇**：pan（机位不动，水平转向）/ tilt（机位不动，上下转向）/ dolly in/out（摄影机前后移动）/ truck（横移）/ zoom（改变焦距）/ crane（摇臂升降或弧线移动）/ handheld（手持）/ STATIC（固定）。垂直下降不是 dolly in/out；俯仰角变化也不代表机位高度变化。

**速度修饰**：缓速 / 标准 / 快速 / 急推 / 慢拉

运镜应有信息或情绪动机：推近可强调发现，横移可揭示遮挡后的主体，固定镜头可让演员动作承担变化。根据空间和节奏选择，不给每镜强加运动；复杂路径需说明起点、终点和注意中心，避免只堆术语。

### 原则 3 — 转场显式（cut / dissolve / fade / wipe + 时长）

| 反例（转场未指定）| 正例（转场显式）|
|---|---|
| `画面切换到下一场景` | `cross dissolve 转场，0.5 秒完成` |

**常用转场词**：cut（硬切，瞬时）/ dissolve（叠化）/ cross dissolve（交叉叠化）/ fade in / fade out / wipe（划像）

硬切适合清晰换焦点，叠化可表达时间流逝但会叠加两个画面的信息，淡出可形成结束感却可能削弱连续动作。选择应服务于段落关系；需精确执行时说明过渡占用哪段时间，不在既定 shot 时长外再加片长。

### 原则 4 — 音视频事件显式指定（音效 / 对白 / BGM 的触发时间 / 音色 / 音量）

按当前模型/操作核实原生音频与接口支持；未支持的声音保留为制作意图并说明后期需求，不静默丢弃。对白、内心独白、环境声、动作音效和音乐各有叙事作用，按需要写清进入时机、质感、空间感与混音主次，不要求每镜具备全部声部。

| 反例（音效模糊）| 正例（音效具体）|
|---|---|
| `"啵"地一声` | `音效：5 道短促电子音"啵"（音色：高频脉冲，单音长 0.05 秒）在 9.3-9.6 秒内集中触发` |

*（与原则 1 反例同一镜头，此处单独看音效粒度）*

细粒度数值用于关键同步，不保证模型逐毫秒执行。对白保持原文，表演提示置于对白前；角色声音身份复制卡片当前年龄适用的描述，冲突交负责人处理。内心独白可明确为非口型同步声，环境声提供地点感，摩擦/脚步等动作声锚定因果，音乐让开人声。完整七字段与火把、风、开门、独白和淡出配合的示例见 `${CLAUDE_PLUGIN_ROOT}/skills/storyboarder-storyboard/rules.md`。

### 声音身份与当场表演

角色卡的音色、共鸣质感、口音等支持稳定身份；常态语速与语调是基线，不是整镜不变的声学锁定。当前台词可随意图和触发改变重音、呼吸、节奏、音量与音高走向，不必改变角色音色。只带当前年龄的声音，不把青年与老年备选指导一起交给模型；卡片混写时指出冲突交负责人修正，不自行拼出第三种声音。

对白、自言自语、内心独白都要让听众、此刻的想法或态度、以及影响表达的触发可理解，再选择能听见的变化。内心声让观众听见但不让场内人物获知；自语不必一律低声。意图可说明表演动机，但不能只留“温和询问／带期待／认真”等标签。按台词需要选少量有效指令，不要求每句哭腔、耳语、停顿或大幅起伏。

局部对照（不补写样本未提供的台词或反应）：`女声常态3-4字/秒，起伏适中；带期待` → 保留该声音基线；若这句确在向对方求回应，可写“将原句疑问重点稍抬音，句尾收住，目光留在对方脸上等回应”。若回应触发下一句“认真”，可在符合原意时写“听完对方的话后，下一句重读原文承诺重点，句尾音高落稳”。具体重读字由实际台词决定；没有回应就不补造回应。青年镜头不继承卡内“老年声、音高幅度小”的备选限制。

### 表演占用真实秒数

18s 告别镜头的预算包括原文说话、听对方、呼吸、视线与动作，不是把18秒全部按3-4字/秒换算台词容量。按真实先后和确实可重叠的动作核算；新增的等待与动作也占时。配速工具通过不证明表演装得下。不静默延长18s、不改台词、不靠全程匀速或加速抹掉转折；放不下时报告具体冲突，由负责人协调获准的调整。

## 复杂效果显式分解模板

以下是需要复杂效果时的描述工具，不是每镜必填模板。选择对当前效果有决定作用的关系；准确术语不确定时核查可信原始资料，引用真实来源，不编造模型机制或文献。

### 画中画模板
```
主画面（占比 X% / 构图 / 主体动作）
+ 嵌入层（位置：屏内 / 左上角 / 中心；
  大小：占嵌入屏 X%；
  内容：嵌入画面描述；
  边框：颜色 + 宽度；
  层级关系：嵌入层在主画面之上）
```

### 画面文字模板
```
内容（具体文字）+ 位置（屏内 X 处）+ 颜色（需要时给色值）
+ 字体大小或整行文字宽度（区分两者）+ 字体（宋体/黑体/楷体加粗/...）
+ 持续时间（出现到消失的秒数）
```

> **阅读负担**：单一文字焦点通常更清楚；字幕与招牌并存时明确主次、位置和需要读懂的内容，不强制所有背景文字逐项填参数。可靠性需结合当前模型评估，必要时提出后期合成方案。

### 复合特效模板
```
主体动作（动作具体词）+ 视觉效果（颜色 / 形状 / 尺寸 / 方向）
+ 持续时间（秒）
```
