# 视频 Prompt 创作规则（共享）

本文件提供视频 prompt 的时序、镜头、事件密度和音视频表达方法，供创作与修正时按问题取用，不指定内部技能或工序。

**相关参考**：[通用视觉表达](visual-prompt-craft-common.md)讨论图像与视频共通的表达原则，本文件补充视频独有部分；两者不是先后执行阶段。

## 镜头与任务边界

独立生成 TASK 边界默认强烈优先采用有动机、明显不同的机位／视点／景别，降低近似构图独立生成差异的显眼程度；每个接点按 [剪辑关系](audiovisual-craft.md#剪辑关系跨越镜头任务与场幕) 的源意图判断。同一连续事件保住必要动作进度、持有/接触、空间与声音的相容延续；场/幕或时空跳转判断因果、情绪、信息、主题反差或平行关系及观众定位，不强制同位置、续动作、连续声音或过桥场。保留源支持的悬念、突兀感与硬切，不要求总是顺滑或立即解释；同集底层身份与世界事实一致，有意变化须有源依据。

沿已有动机切点装组；相似镜头可同组，实际需要的匹配／重复构图保留，关键接触或必须无缝续声可行时留同组，取舍在现有交接中说明，不新增许可。此偏好不要求每镜变化、每切一任务或角度配额，不保证连续性或豁免违背源意图的身份／状态／动作错接。TASK 是生成单元，不等于场景或幕，约束内可含多个镜头/场景，不强制幕结构；运动中硬切有效，不默认停步、摆终姿、停顿或下组重新建立空间。遵循 [装组契约](shot-inputs.md) 的连续成员、时长、模型最大值和 grants；源重设计由 Director/owner 在原始预算内同步，不静默重组。

视频模型获得本次请求的文本和实际提供的 refs。当前 shot 的起始状态、动作过程、终态、运镜、声音身份和转场在本条明确成立；故事连续性由这些局部事实实现。“承接上一 shot”可改为“人物位于门内一步，左手持火把，右手扶住半开的木门，侧身望向院落”。服饰或道具身份可使用本次绑定的图片，当前持有关系仍写明。

Creator 提供统一美术基线，Storyboarder 写入各源 shot 的单行 `视频风格`。同组字段须精确相同，Creator 在最终 prompt 表达一次。差异交 owner，局部变化写 prose，不模糊去重。Shot prose 写当镜动作、摄影、空间与声音；manifest use 只声明参考权限。每镜链接须自身 header 声明，按首次使用求身份图并集。所选 provider 的自有材料工具定义提取、pack 与引用语法，Dreamina 见 [video.md](../../creator-provider-dreamina/video.md#dreamina-authoring-materials)，不把其槽位规则泛化为共享契约。

场次、制作备注和场景预算放在 shot 结构边界外。摄影源保留七字段、对白、内心声、音效、音乐和摄影正文；源 cue 从镜内 0s 起。任务 timeline/duration 由原镜时长派生；材料工具按所选 provider 契约处理引用绑定与重基。Creator 对照完整源、工具输出及实际 refs，将局部时间落实为最终任务时间 prose，保留合理重叠、完整源事实及对白原词。转场明确两端画面及原预算内占用，Creator 对齐全组媒体时钟、内部切点和声音桥。

按 [shot-inputs](shot-inputs.md)，`task-inputs/taskNN.json` 草稿恰为 `{shots,references}`，最终恰为 `{shots,references,prompt}`。Creator 据 materials 写完整任务时间 prompt，绑定实际 tokens/代理映射并去掉内部 IDs/路径/元数据，保留源叙事、动作、对白原词、切点、时长和声音；自查最终 `--json`。task_id 独立于首镜，每任务至少一个全组本地 MP4，静态段可用 clip。MP4 控制相机、位置/布局、整体轨迹及时序；可选 PNG 控制静态形态，资产图供身份，sources 不上传。最终 prompt/refs 须独立成立，必要轨迹无法核实为 unknown。独立 shot-input target 为最终 manifest，审核源忠实度、完整性、集成/delta、内部切点/声音桥及必要边界，无冲突复用 storyboard 判断；草稿不就绪，提交不重写。

本地视频与源 shot prose 遵循 [粗模控制与外观依据分离](visual-prompt-craft-common.md#粗模控制与外观依据分离) 的完整规则：BODYBOX 默认、必要代理及姿态作用域、详细动作表达、各类参考权限与错误媒体修正。Creator 在每份视频 ref.use 和最终 manifest.prompt 中落实控制边界，保留必要接触与源动作。

候选渲染/检查成功后，Creator 按 [发布与选用契约](shot-inputs.md) 把实际选中结果落实到当前 manifest，核对完整 prompt、每份 use、媒体、可编辑 sources 与真实源时序。已发布 JSON 每次小步编辑后仍可解析；长字符串可在临时文件完整组装、验证后授权原子替换。候选证据不自动覆盖当前选择；Creator 亲写的 prompt 只有与精确选中输入一起通过独立审核才可用于提交，保留现有草稿/最终形式与受保护提交记录。

最终任务时间正文按 [触发、反应与任务时间整合](audiovisual-craft.md#从触发到人物反应) 保留源表演，并按 [全局映射与实际使用处的引用](visual-prompt-craft-common.md#全局映射与实际使用处的引用) 绑定实际输入；具体语法归 provider。

## 4 条视频独有原则

方向按通用原则 6 的当前画面基准表达；转身、反打或运镜时区分角色自己的左右与屏幕投影，写清有信息价值的起落位置及纵深变化，不把每镜锁在同一左右；对白和仪器上的方向文字仍保留原意。

### 原则 1 — 事件密度匹配 shot 时长

摄影 shot 按叙事、动作和剪辑节奏分配正整数秒，满足用户单镜限制、当前场景分配/整集预算及固定镜头数；短镜不受 provider 最短时长或 70% 目标约束。设计后 Creator 将连续 shots 装组，按已核实模型最大 M 以 `ceil(0.7*M)..M` 为生成任务语义目标，而非机械下限；实际 provider 时长范围约束整个任务。不适配交 owner 在下述创作预算内重设计，不由装组暗改。事件承载不随秒数简单线性增加：对白、视线转移、空间重建和复杂动作都占理解时间。

按 [视听 craft](audiovisual-craft.md) 保留节拍意义，而非动作条数或固定秒数：由起始状态推到观众必须看到的变化，区分真实先后与可重叠的占用，并给注意转移留空间。时间不足可调整覆盖/调度，或由 owner 主动使用用户原始集目标已确认的 ±10% 创作预算，协调更新 canonical script/storyboard 与受影响参考；不是在装组中延长旧镜头。精确目标和实际范围优先，原始基准不滚动。

反应、插入、蒙太奇、转场和结尾可采用有独立表达价值的短镜，不要求逐镜理由表。Creator 装组保留原时长、对白、动作与内部切点，不把摄影短镜改成长镜；不相容的时空/运镜/声音组织交 owner 协调。部分选组报告 task_id、完整成员及额外镜头，不静默扩大授权。系列沿用初始用户共同集目标，显式范围与严格边界不再加容差，详见 storyboarder-storyboard/rules.md。

例如，一镜可以围绕“发现门后亮光”展开：先建立人物与门的位置，随后人物推门，亮光随门缝扩大显露，最后停留在人物反应。为动作、揭示和反应各留可读时间；若需要切分，在既定预算内安排摄影镜头，源时间码各从 0s 开始，最终任务结构 cues 按派生 offset 重基。多焦点切换、画中画和文字阅读都占注意时间，须与主动作协调。

屏幕/UI 或控制动作按“触发 → 操作反馈 → 后果”明确状态和时序，保留必要文字、数值、结果及完成、松开、冻结/保持状态。正弦、取模循环或泛称“运行中”不能替代因果完成，也不能在停止事件后继续；周期行为仅用于源本来需要的循环。使用已有设计的界面，不为补证据新增控件。像素检查只证明采样尺寸/对比等可见属性，时间检查只证明对应时段，不能单独证明读懂、操作完成或因果成立；以实际时序结果判断，不靠 prompt 豁免相反媒体。

### 原则 2 — 镜头运动具象（pan / tilt / dolly / zoom / handheld + 速度修饰）

例如：“摄影机沿立面缓慢下降至人物肩部高度，同时抬镜保持门口居中。”说明机位移动与朝向变化，实际距离与所需时长匹配。

**常用运镜词汇**：pan（机位不动，水平转向）/ tilt（机位不动，上下转向）/ dolly in/out（摄影机前后移动）/ truck（横移）/ zoom（改变焦距）/ crane（摇臂升降或弧线移动）/ handheld（手持）/ STATIC（固定）。垂直下降不是 dolly in/out；俯仰角变化也不代表机位高度变化。

**速度修饰**：缓速 / 标准 / 快速 / 急推 / 慢拉

运镜应有信息或情绪动机：推近可强调发现，横移可揭示遮挡后的主体，固定镜头可让演员动作承担变化。根据空间和节奏选择，不给每镜强加运动；复杂路径需说明起点、终点和注意中心，避免只堆术语。

把“观众感到紧张”落实为注意与证据的时序：先看/听什么，哪次移动解除遮挡或转移焦点，观众与人物谁先发现，发现后留给反应什么空间。构图、动作和声音共同引导注意，背景保留地点感但让关键变化可读。方法和例子见 [视听 craft](audiovisual-craft.md)，不以更多形容词、运镜术语或同时发生的细节代替体验设计。

### 原则 3 — 转场显式（cut / dissolve / fade / wipe + 时长）

按 [转场与片中文字](transition-craft.md) 选择观众应保留、重释或新获知的关系，再落实方式和窗口；字卡、转场图像与有意黑场均可成立。独立卡计源 shot/预算，叠字不重复计时，不在拼接时添加未入源的过渡秒数。

例如：“本镜最后 0.5 秒 fade out，画面亮度逐渐降至黑场。”需要交叉叠化时，写明本次已提供的两端画面和占用时段。

**常用转场词**：cut（硬切，瞬时）/ dissolve（叠化）/ cross dissolve（交叉叠化）/ fade in / fade out / wipe（划像）

硬切可在注意、想法或动作阶段变化处发生，包括行走、伸手、转身和说话途中；连续动作核对跨视角相容的方向、姿态、握持与进度，不要求静止接静止或相同帧。省略、反差和平行按源关系表达。叠化可表达时间流逝但会叠加信息，淡出可形成结束感却可能削弱连续动作；均非跨任务/场幕必需。精确转场说明原预算内占用，不另加片长。当前 prompt 写明切入/切出事实与声相，“终态”不等于动作已经结束。

声桥可让下一镜声音先进入再切画面（J-cut），或切到下一画面后保留上一镜声音（L-cut）。据揭示、听者反应或段落反差选择，不等同两人同时说话。源 shots 写清两端声音和本地时序，组内桥在最终 prompt 与全组 MP4 的共同任务时钟上对齐；同一原句在成片连续一次，不让两镜各从头重念。跨任务桥明确各请求承担的部分及实际后期接续需求，不把“延续上一镜声音”当作模型已获得音轨；装组和转换保留原句，不因跨切点重复、摘要或改词。

分段渲染、叠层或局部替换后，检查完整合成结果及相关接缝前、中、后，不只检查成功片段或端点。源本为未切镜头时，额外留意接缝处噪声/降噪、光照、颜色/gamma、运动速度和实际声音的无意跳变；有意切点与声音桥按源保留。抽样说明覆盖限制，必要时查看连续播放；修正实际不连续，不能让 prompt 代为掩盖。

### 原则 4 — 音视频事件显式指定（音效 / 对白 / BGM 的触发时间 / 音色 / 音量）

按当前模型/操作核实原生音频与接口支持；未支持的声音保留为制作意图并说明后期需求，不静默丢弃。对白、内心独白、环境声、动作音效和音乐各有叙事作用，按需要写清进入时机、质感、空间感与混音主次，不要求每镜具备全部声部。

例如：“门锁扣合时触发一声短促金属咔嗒，位于画面右侧近处，音量低于随后的人声。”关键同步需要时可补实际时间点与持续时间。

细粒度数值用于关键同步，不保证模型逐毫秒执行。对白保持原文，表演提示置于对白前；角色声音身份复制卡片当前年龄适用的描述，冲突交负责人处理。内心独白可明确为非口型同步声，环境声提供地点感，摩擦/脚步等动作声锚定因果，音乐让开人声。完整七字段与火把、风、开门、独白和淡出配合的示例见 `${CLAUDE_PLUGIN_ROOT}/skills/storyboarder-storyboard/rules.md`。

### 声音空间与注意主次

关键声源写清画内/画外位置、相对听点的距离、门墙等阻隔及随行动发生的音质变化。按场景需要选择客观空间声或人物主观听觉，说明观众与其他角色能听到什么。比如门合上后门外人声变闷但室内原句仍清楚，比“有空间感的声音”更明确；具体声源须来自已有材料。

对白、动作声、环境底声和音乐按当刻注意安排前后景，说明何时让位，不要求每镜声部齐全。Room tone 是维持室内空间感的连续底声；无人说话、停音乐、环境声消失与全静音分别表达。声音减少可让轻微动作浮现，音乐也可退出而非始终解释情绪。需要双人重叠对白时写清起止关系、谁打断谁及听觉重点，完整保留双方原句，不能借遮蔽吞掉关键内容。

### 声音身份与当场表演

角色卡的音色、共鸣质感、口音等支持稳定身份；常态语速与语调是基线，不是整镜不变的声学锁定。当前台词可随意图和触发改变重音、呼吸、节奏、音量与音高走向，不必改变角色音色。只带当前年龄的声音，不把青年与老年备选指导一起交给模型；卡片混写时指出冲突交负责人修正，不自行拼出第三种声音。

对白、自言自语、内心独白都按 [源触发与人物反应](audiovisual-craft.md#从触发到人物反应) 写明听众、此刻获得的触发、注意/态度/情绪变化及其对下一句或行动的影响。内心声让观众听见但不让场内人物获知；自语不必一律低声。意图可说明表演动机，但不能只留“自然／复杂／温和询问／带期待”等标签。表达幅度由人物、处境与关系决定，按台词需要选择有效指令，不要求每句哭腔、耳语、停顿或大幅起伏。

人物词汇、句法、称呼、比喻和交锋中的策略来自剧本，声音身份与临场音高不能替代这些语言差异。下游完整保留场景对白、内心声及旁白原句，按原句回应关系安排表演；不为“更自然”改词、补俚语、加口吃或换成主题警句。若语言本身缺乏人物依据，定位交回授权剧本修订，不在 prompt 中重写。VO 可承载视角、自我辩解或声画反差，不默认另加解释情绪的旁白，也不擅删有效的直陈思想。

保留当前年龄的声音基线后，按实际台词写局部表演。例如求回应时可写“将原句疑问重点稍抬音，句尾收住，目光留在对方脸上等回应”；回应确实触发承诺时可写“听完对方的话后，下一句重读原文承诺重点，句尾音高落稳”。具体重读字由台词决定，不补造材料中没有的回应。

### 表演占用真实秒数

跨切点整句按 [视听指南](audiovisual-craft.md) 的连续窗口核算，每个摄影 shot 只计其实际发声部分；同组后镜通过起声镜解析续声，完整原句保持一份。

单镜预算包括原文说话、听对方、呼吸、视线与动作。按真实先后和确实可重叠的动作核算，等待与动作同样占时。配速工具通过不证明表演装得下；Creator 可结合 BOX 与可选假音频试排这些估计，不作表演验收。放不下先定位具体冲突，再由负责人在上述创作预算内调整源材料，无需逐次许可；不在下游暗改台词/时长或靠全程加速抹掉转折。

## 复杂效果显式分解模板

以下是需要复杂效果时的描述工具，不是每镜必填模板。选择对当前效果有决定作用的关系；准确术语不确定时核查可信原始资料，引用真实来源，不编造模型机制或文献。

### 画中画模板
```
主画面（占比 X% / 构图 / 主体动作）
+ 嵌入层（位置：屏内 / 左上角 / 中心；
  大小：占嵌入屏 X%；
  内容：嵌入画面描述；
  边框：颜色 + 宽度；
  层级关系：嵌入层在主画面之上）
```

### 画面文字模板

先说明场内 UI/纸面、观众 SUPER/全屏卡或内部调试的用途；正式文字保留源原词，内部标注不进入上传参考。观众文字不需要演员阅读面，详见 [共享文字设计与验收](transition-craft.md#制作与验收的尺度)。
```
内容（具体文字）+ 位置（屏内 X 处）+ 颜色（需要时给色值）
+ 字体大小或整行文字宽度（区分两者）+ 字体（宋体/黑体/楷体加粗/...）
+ 持续时间（出现到消失的秒数）
```

> **阅读负担**：单一文字焦点通常更清楚；字幕与招牌并存时明确主次、位置和需要读懂的内容，不强制所有背景文字逐项填参数。可靠性需结合当前模型评估，必要时提出后期合成方案。

### 复合特效模板
```
主体动作（动作具体词）+ 视觉效果（颜色 / 形状 / 尺寸 / 方向）
+ 持续时间（秒）
```
