## 参数选择授权

此处记录参数裁量，不是额外生成许可。short 制作请求已包含所需新增资产/分镜板图片，按真实选择保存配置并完成 intake/审核后生成；始终停止在视频生成前，用户后续手动 generate-video 的实际请求才登记首次视频 grant。无需生图/视频“是否授权”握手，不自动更改固定值。普通图片制作包含同范围可恢复失败重试及必要质量修复/重生和独立复审，默认不设尝试/轮次上限，不另问重试许可；用户明确的单次、次数、范围、检查点和费用限制优先。按共享 user-decision-relay 规则诊断与推进，不盲目无限尝试；真实阻塞停止受影响工作。视频仍独立遵守原 grants 与次数限制。

必要选择尽早逐题解决。原角色一次提供全部相关问题/表、明确题界、完整选项/解释、稳定标签和分支。主 AI 内部保留全表，仅沿作者题界完整展示当前题后用可用原生键盘选择器，questions 恰好一项；相关原始答复及条件批量回原角色，不逐题往返。仅缺内容/映射、不相容或计划外决定才提前回询，不有损改写或倾倒全表。Markdown 不替代可用控件，宿主限制须明说。已答/已定/已委托字段不重问，后续艺术细节由 owner 决定，范围内修复/审核不逐轮批准，也不追加启动确认。

先复用固定/继承/已委托设置。Creator 只读查询当前能力与接入，一次给齐各 scope 的 provider -> model -> 相容 ratio -> resolution 问题、具体值、完整解释及“此字段交 Creator 决定”，标明相容分支。主 AI 只应用所给条件，不推断技术知识；若委托模型须专家解析且无后续分支，先回 Creator 再问依赖项。按 scope 跳过已答/继承/已委托字段，sheet 继承/授权覆盖分清，横屏不等于数值比例；不保存静态模型目录，不因用户不懂隐藏选项。

用户选定模型即按可访问处理，不查权益/会员/凭据/账号/积分，不索证明或要求确认访问不确定性声明。仍验证当前 CLI/API 技术组合与工作流接入，不声称访问已核实或生成成功。按选定参数使用，不做预算/余额/最低价前置、不为省钱降级；用户明确限制有效，仅授权执行实际返回账号/provider 错误时报告并处理必要决定，不换固定模型。示例不是用户决定，不复制为授权或执行值。
仅在实际授权后保存一个 JSON 块，例如：

```json
{"decision":"用户允许Creator选择分镜板比例和分辨率","delegated":{"sheets":["ratio","resolution"]}}
```

scope 为 images/sheets/video；字段为 provider/model/ratio/resolution。缺失、空值或 auto 不授予自主权。共享图像固定值也约束 sheets，除非用户明确改变作用域；冲突先澄清。sheet 覆盖不修改基础图，画布比例不等于视频比例。任务选择留在任务中，不提升为默认。上方注释只说明字段，启用时填写实际值。

## 创作配置

剧情未指定但基本意图足够时默认三个展开候选故事，每个含人物动机、冲突、推进和结局，作为当前单题全部展示后选择，可委托 Director。明确候选数、已有剧本/方向/选择委托优先；不先问谁决定，不以类型标签代剧情。无关技术设置不阻塞候选探索；正式剧本/资产仍待相关选择已知或委托。此默认仅指未指定数量的剧情探索，不将下方风格/时长示例变为默认。

具体创作（包括预览材料）前按 `${CLAUDE_PLUGIN_ROOT}/skills/_meta/rules/user-decision-relay.md` 复用已知需求，只问必要缺口或让用户明确委托责任角色决定。将实际决定、角色、范围和约束记入配置说明/委托，不增加状态 schema。沉默不是授权，受托艺术细节可留待创作；集总时长仍由用户确认。风格、数量、时长示例均不是启用默认，只有实际选择才去注释填写。
- 总集数: 1                  # short 模式恒为 1 (短视频单集, 此字段为 schema 统一保留)
- 语言: auto                 # auto(跟随输入语言) / zh / en / 自定义
# - 每集分镜数: 用户固定值或明确委托 Storyboarder 按叙事决定
# - 每集时长目标: 用户确认的单值或允许范围（注明单位；正式制作前填写，无默认值）
# - 单镜头时长范围: 用户限制或明确委托在模型与集时长边界内分配

唯一短剧集开始时先确定集总时长；用户已有明确配置直接复用，缺失则询问，不把模板当决定。单值初次设置须说明并确认 scene-duration 的 ±10% 及对应秒数边界；用户更严格限制优先，精确值按相等上下界处理。显式范围直接使用，不再放宽。在本段保留实际目标及用户确认的容差/严格边界。

每集分镜数是规划参考，不以镜头数乘模板单镜头时长反推集目标。镜头内容和时长可在 provider/项目限制内灵活安排，合计仍须符合集预算。Creator 的参数选择授权不包含修改集目标；适配冲突交 Director 提修改方案或询问用户，不能自动拉长。仅查看配置不得创建配置或填入目标。

## 制作前确认记录（按需）

outline、novel、arc 是按需要选择的规划材料；缺少它们不阻止常规制作。
仅当用户要求先看材料时，由用户交互上下文在本配置中增加独立的
`## 制作前确认 epNN` 段，段内只放一个 fenced JSON（语言标记 `json`）：

```json
{"episode":"ep01","required":["outline"],"approval":null}
```

`required` 只允许 outline、novel、arc，分别指本集 outline.md、novel.md 和
story/arc.md。缺失、空白或尚未批准的指定材料阻止正式制作。
实际确认后，用户交互上下文将 approval 写为
`{"decision":"保留用户实际确认内容","inputs":[...]}`；inputs 使用
`node "${CLAUDE_PLUGIN_ROOT}/scripts/review-evidence.mjs" fingerprint PATH...` 返回的 path/sha256 对。
确认前后核对相同输入；材料变化后需重新确认。审核通过不能代替用户确认。
无请求时保留本说明即可，勿创建 episode-specific 记录。
图像提供方 none 仅禁用新提交；必需资产和分镜板图片仍须存在且审核有效。
