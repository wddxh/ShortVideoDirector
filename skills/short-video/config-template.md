## 本地参考 ep01

正式 selected clean MP4 默认对齐已选视频比例和分辨率；用户 explicit local override 优先，仅改变本地参考。Creator 核实实际像素尺寸及依据，16:9 + 720p 常见为 1280×720，仅是示例，不是其他比例/provider 档位的映射；未知档位须核实，不按短边猜测。

以下三项仅示范格式，实际决定后由 Director 协调有界配置 owner 最迟在本集最早正式参考制作前落盘；说明来源为 final settings 或用户 explicit local override，以及像素依据与 fps 选择理由。键名始终带实际 epNN，单集为 ep01，不用裸 width/height/fps 或未限定集数的键。

示例键保持注释；实际落盘时去注释并填写真实值，避免 reader 将模板当已选规格。

```markdown
# - ep01 本地参考宽度: 1280
# - ep01 本地参考高度: 720
# - ep01 本地参考fps: 24
```

本集统一 CFR fps：用户明确值优先，否则 Creator 为本集选择一次与源时钟兼容的值并保存；未选择时不默认 30，也不照抄示例 24。草稿可低分辨率，正式选中 clean 按已存三项导出并核对实际媒体。字幕版 picture 宽高、fps、时长与 clean 一致，总高另加底栏。缺少规格由有界 owner 补齐，与共享环境报告分开，不新增初始化探针或自动迁移历史材料。配置变更涉及已有审核指纹时作 scoped 兼容性评估，不盲刷哈希。

实际宽高为正偶数像素，媒体工具还要求宽度至少 64；fps 可为正整数、小数或分数，工具精确约分，canonical task 时长 × fps 须为整数帧。审核绑定整份配置指纹，已知规格应尽早由获准 owner 保存并交回 stable，再启动依赖该配置的审核。

## 参数选择授权

此处记录参数裁量，不是额外许可。short 请求包含所需新增资产图和本地参考，真实配置、intake/审核满足后执行，始终停在付费视频提交前；后续手动 generate-video 请求才登记 initial grant。不重复许可握手或自动改固定值。图片制作含同范围恢复重试、必要修复/重生和独立复审，无默认轮次上限；用户明确次数、范围、检查点及费用限制优先。按共享规则诊断进展，不盲目无限尝试，真实阻塞只停受影响工作。视频独立遵守 grants/次数。

必要选择尽早逐题解决。原角色一次提供全部相关问题/表、明确题界、完整选项/解释、稳定标签和分支。主 AI 内部保留全表，仅沿作者题界完整展示当前题后用可用原生键盘选择器，questions 恰好一项；相关原始答复及条件批量回原角色，不逐题往返。仅缺内容/映射、不相容或计划外决定才提前回询，不有损改写或倾倒全表。Markdown 不替代可用控件，宿主限制须明说。已答/已定/已委托字段不重问，后续艺术细节由 owner 决定，范围内修复/审核不逐轮批准，也不追加启动确认。

复用固定/继承/已委托设置。Creator 只读查询能力，给齐 images/video 的 provider -> model -> 相容 ratio -> resolution、全部具体值/解释、逐字段委托选项及分支。主 AI 只按作者条件逐题询问；委托模型需解析且无后续分支时先回 Creator。跳过已答/继承/委托项，横屏不等于数值比例；不存静态模型表，不隐藏选项。

用户选定模型即按可访问处理，不查权益/会员/凭据/账号/积分，不索证明或要求确认访问不确定性声明。仍验证当前 CLI/API 技术组合与工作流接入，不声称访问已核实或生成成功。按选定参数使用，不做预算/余额/最低价前置、不为省钱降级；用户明确限制有效，仅授权执行实际返回账号/provider 错误时报告并处理必要决定，不换固定模型。示例不是用户决定，不复制为授权或执行值。
仅在实际授权后保存一个 JSON 块，例如：

```json
{"decision":"用户允许Creator选择资产图片比例和分辨率","delegated":{"images":["ratio","resolution"]}}
```

scope 为 images/video；字段为 provider/model/ratio/resolution。缺失、空值或 auto 不授予自主权。固定值冲突先澄清；图片比例与视频比例分别选择。任务选择留在任务中，不提升为默认。上方注释只说明字段，启用时填写实际值。

## 创作配置

剧情未指定但基本意图足够时默认三个展开候选故事，每个含人物动机、冲突、推进和结局，作为当前单题全部展示后选择，可委托 Director。明确候选数、已有剧本/方向/选择委托优先；不先问谁决定，不以类型标签代剧情。无关技术设置不阻塞候选探索；正式剧本/资产仍待相关选择已知或委托。此默认仅指未指定数量的剧情探索，不将下方风格/时长示例变为默认。

具体创作（包括预览材料）前按 `${CLAUDE_PLUGIN_ROOT}/skills/_meta/rules/user-decision-relay.md` 复用已知需求，只问必要缺口或让用户明确委托责任角色决定。将实际决定、角色、范围和约束记入配置说明/委托，不增加状态 schema。沉默不是授权，受托艺术细节可留待创作；集总时长仍由用户确认。风格、数量、时长示例均不是启用默认，只有实际选择才去注释填写。
- 总集数: 1                  # short 模式恒为 1 (短视频单集, 此字段为 schema 统一保留)
- 语言: auto                 # auto(跟随输入语言) / zh / en / 自定义
# - 每集分镜数: 用户固定值或明确委托 Storyboarder 按叙事决定
# - 每集时长目标: 用户确认的单值或允许范围（注明单位；正式制作前填写，无默认值）
# - 单镜头时长范围: 用户限制或明确委托按叙事在集时长边界内分配正整数秒

唯一短剧集开始时确定用户原始集总时长；已有明确配置直接复用，缺失则询问，不把模板当决定。单值初次设置说明并确认 ±10% 创作预算及秒数边界；owner 可主动用于揭示、倾听与反应，不只是完稿容错。精确值按相等上下界，更严格限制优先，显式范围不放宽。本段保留原始目标与确认边界，不用调整后的合计覆盖基准。范围内由 Director 协调 owner 更新 canonical script/storyboard 和受影响参考/manifest，无需逐次许可；既有任务与授权记录仍受保护。

每集分镜数是规划参考，用户固定值仍绑定，不以镜头数乘模板时长反推集目标。摄影 shot 按叙事分配正整数秒，可用短镜；provider 最短/70% 目标仅用于 Creator 设计后装组的生成任务。装组保留当前 canonical 时长、对白和切点；不适配按上述预算由 Director 协调 owner 重设计，不在装组中偷加秒，参数裁量不改变用户基准。仅查看配置不创建或填目标。

## 制作前确认记录（按需）

outline、arc 是按需要选择的规划材料；缺少它们不阻止常规制作。用户小说、章节和节选按实际路径与采用范围作为 Scriptwriter 改编输入。
仅当用户要求先看材料时，由用户交互上下文在本配置中增加独立的
`## 制作前确认 epNN` 段，段内只放一个 fenced JSON（语言标记 `json`）：

```json
{"episode":"ep01","required":["outline"],"approval":null}
```

`required` 只允许 outline、arc，分别指本集 outline.md 和 story/arc.md。
required 中的未知类型阻塞正式制作，不静默过滤或自动批准。详见 [制作前确认](../director-orchestrate/SKILL.md#来源与制作前确认)。
缺失、空白或尚未批准的指定材料阻止正式制作。
实际确认后，用户交互上下文将 approval 写为
`{"decision":"保留用户实际确认内容","inputs":[...]}`；inputs 使用
`node "${CLAUDE_PLUGIN_ROOT}/scripts/review-evidence.mjs" fingerprint PATH...` 返回的 path/sha256 对。
确认前后核对相同输入；材料变化后需重新确认。审核通过不能代替用户确认。
无请求时保留本说明即可，勿创建 episode-specific 记录。
图像提供方 none 仅禁新图片提交；必需图仍须存在且审核有效。`task-inputs/taskNN.json` 草稿恰为 `{shots,references}`，最终恰为 `{shots,references,prompt}`，含 Creator 编写的非空白最终 prompt；草稿不就绪。每生成任务至少一个全组 MP4，静态段可用 clip，sources 不上传。独立 shot-input 审核最终 prompt 源忠实度、完整性、集成、内部切点/声音桥及必要边界；部分选组报告完整成员/额外镜头，不扩授权。None 不豁免材料。
