# Series Mode: director-review-script 专属指南

## 额外上下文读取
- `story/arc.md` — 必读 (核对本集应推进的 arc 节点 + 该节点的人物弧)
- `story/episodes/{ep}/novel.md` — 必读 (校对剧本是否真正提炼 novel 的情感纹理 / 角色声音 / 视觉细节)
- mode='continue-series': 上一集 `story/episodes/{prev_ep}/script.md` (验证开场承接)

## Series 专属 review 项

1. **跨集人物弧延续**
   - outline.md「在 arc 中的位置」声明的 arc 节点是否在剧本场景中真正推进 (冲突升级 / 关系转折 / 信息揭示 / 人物弧位移)
   - 主要角色的台词 / 行为是否反映其在该 arc 节点的人物弧位置 (与 arc.md 人物弧描述对照)
   - mode='continue-series': 本集首场景是否与上集末场景在时空 / 情绪 / 角色状态上自然衔接 (不能硬切日常或与上集集尾钩子矛盾)

2. **集尾钩子戏剧悬念**
   - outline.md 末尾「集尾钩子」是否在剧本**最后一个场景**中具象化呈现 (画面 / 对白 / 动作)
   - 钩子不能写成旁白 / 字幕 / "主角思考" / "下集见"
   - 钩子是否真"留疑"——观众带什么疑问走？若钩子只是"事件结束"，不是悬念，须打回
   - 钩子是否与本集 arc 节点推进的后续 arc 节点自然承接 (与 arc.md 下一节点比对)

3. **novel 提炼度**
   - 剧本对白是否提炼了 novel 中最具戏剧张力的台词 (而非自行编写新对白完全脱离 novel 基调)
   - 主角内心独白是否反映 novel 中的心理描写 (主角优先)
   - 视觉摘要是否提炼 novel 中的环境 / 道具 / 光线描写
   - 不要求逐句对应，但脱离 novel 文学层即丧失 series 模式价值——明显脱节须打回

## Series 专属失败模式
- **arc 节点空转**: 剧本场景虽存在，但未真正推进 arc 节点声明的位移
- **角色弧不连贯**: 角色台词 / 行为与 arc 当前节点的人物弧位置矛盾 (例: 已知 Y 的角色又问 Y)
- **集尾钩子退化**: 钩子写成"事件结束 / 主角思考" → 丢失悬念
- **跨集承接断裂**: continue-series 首场景与上集末时空 / 情绪 / 状态不连续
- **novel 文学层丢失**: 剧本对白 / 内心独白 / 视觉细节与 novel 完全脱节
- **越界 review 钩子的实现细节**: 提具体台词写法，应只提"钩子未具象化"方向
