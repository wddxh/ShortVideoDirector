# Short Mode: director-review-script 专属指南

## 额外上下文读取
- 仅 outline.md / config.md / asset 资产 (无 arc, 无 novel, 无上一集)

## Short 专属 review 项

1. **单集戏剧弧完整性 (铺垫→冲突→高潮→收束)**
   - 按场景顺序看节奏角色分布: 必须含 铺垫 → 冲突 → 高潮 → 收束 四段闭环
   - 缺铺垫直接进冲突 → 观众无情绪铺垫，须打回
   - 高潮后无收束 → 故事悬挂未落地，须打回
   - 第一场景节奏角色应为"开场"或"铺垫"，不允许直接是"冲突"以外的杂项
   - 高潮场景必须有足够视觉 / 戏剧支撑 (非一句台词带过)
   - 铺垫场景不能被压缩成 1-2 秒

2. **开场策略具象化**
   - outline.md「开场策略」是否在剧本第一场景中具象化呈现 (画面 / 对白 / 动作)
   - 不能是"用紧张刺激场景吸引观众"等空话翻版
   - 第一秒必须抓人——短视频无"下集承接"缓冲

3. **结局情感落点**
   - outline.md「结局设计」是否在剧本最后一个场景中给出**情感落点**: 观众离场记住的画面 / 台词 / 情绪
   - 不能是"故事结束 / 主角离开"等仅完成事件的收束
   - 结局类型 (outline 字段) 与剧本结局段落的画面 / 动作必须对得上 (类型字段说"反转"但剧本只是"主角揭露真相"，没真反转 → 打回)
   - 结局是否与开场策略呼应 (埋的钩子在结局兑现)

4. **时长目标硬约束**
   - `scene-duration.sh` 必须 PASS (range 由 config 时长目标决定)
   - FAIL 时优先列入意见，比节奏曲线美感更高优先级

## Short 专属失败模式
- **"长剧第一集"陷阱**: 铺垫 / 冲突过满，结局段落被压缩成"主角离开" → 情感落点丢失
- **戏剧弧断裂**: 缺铺垫直接进冲突 / 高潮后无收束
- **开场策略空话化**: 第一场景未具象化策略，写成"紧张场景"
- **结局类型 / 描述脱节**: outline 类型说"反转"但剧本无真反转
- **结局仅完成事件**: 写成"故事结束"，无观众离场记忆点
- **时长 FAIL 被忽视**: 模型靠"节奏感"判断，忽略 scene-duration.sh 硬数据
- **第一场景节奏角色错位**: 直接"冲突"以外的杂项 (非开场/铺垫)
