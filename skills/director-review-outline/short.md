# Short Mode: director-review-outline 专属指南

## 额外上下文读取
- 实际配置（SVD_CONFIG 或 config.md）与确认素材；已有相关规划可参考，不虚构 arc 或前集

## Review 项 (逐项检查)

1. **节奏角色分布合理性 (含戏剧结构完整性)**
   - 节奏角色是否准确描述信息、压力与情绪变化，不要求标签种类齐备
    - **戏剧结构完整性**：用铺垫、冲突、高潮、收束诊断因果与情绪，不强制四段顺序或闭环
      - 冲突开场需让观众理解必要处境
      - 开放、悬念或闭合结尾按用户确认意图判断，有意留白不等于漏写
    - 首场景节奏角色应准确描述实际功能，允许跳跃式开场
   - 一场景只挂一个节奏角色（与公共规则呼应）

2. **场景数量合理性**
   - 与 config.md 中"每集时长 / 场景数量目标"匹配
   - 可用 3-7 场试排观察承载与转场成本，但单场戏或蒙太奇也可成立，不按数量判失败

3. **新增 asset 合理性**
   - 新增角色是否挤占理解与共情空间；同场群像也可有清晰焦点，不按人数自动警告
   - 新增角色是否对本集叙事必需

4. **asset dangling reference**
   - 场景中出现的所有 character / location 必须 ∈ (assets/ 已注册 ∪ 本集新增资产清单)
   - 列出所有 dangling 引用

5. **跳跃式开场承接合理性**
   - 若"开场策略"或场景 1 用高潮/悬疑跳跃式抓人
   - 观众需要理解时提供时空、目标或因果线索；回溯、意象和后置揭示均可，不强制场景 2 加解释桥，有意跳切可服务反差

6. **结局设计的情感落点**
   - "结局设计"字段是否真给出**情感落点**（观众离场记住的情绪 / 意象 / 反差）
   - 不能是"故事结束 / 主角离开"等仅完成事件的收束
   - 结局是否与开场策略呼应（埋的钩子在结局是否兑现）
