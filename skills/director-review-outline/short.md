# Short Mode: director-review-outline 专属指南

## 额外上下文读取
- 仅 `config.md` (无 arc，无全局 outline，无上一集)

## Review 项 (逐项检查)

1. **节奏角色分布合理性 (含戏剧结构完整性)**
   - 场景节奏角色 (开场 / 铺垫 / 推进 / 冲突 / 高潮 / 收束 / 钩子) 是否多样不单调
   - **戏剧结构完整性**：单集必须包含 铺垫 → 冲突 → 高潮 → 收束 四段闭环
     - 缺铺垫直接进冲突 → 观众无情绪铺垫
     - 高潮后无收束 → 故事悬挂未落地
   - 第一场景节奏角色应为"开场"或"铺垫"，不能直接是"冲突"以外的杂项
   - 一场景只挂一个节奏角色（与公共规则呼应）

2. **场景数量合理性**
   - 与 config.md 中"每集时长 / 场景数量目标"匹配
   - 短视频通常 3-7 个场景；过少 → 单场景过载；过多 → 颗粒度碎裂

3. **新增 asset 合理性**
   - 短视频角色总数本就少，新增角色 ≥3 → 警告
   - 新增角色是否对本集叙事必需

4. **asset dangling reference**
   - 场景中出现的所有 character / location 必须 ∈ (assets/ 已注册 ∪ 本集新增资产清单)
   - 列出所有 dangling 引用

5. **跳跃式开场承接合理性**
   - 若"开场策略"或场景 1 用高潮/悬疑跳跃式抓人
   - 检查场景 2 是否存在叙事桥（回溯 / 解释 / 时间线锚点），不能硬切日常

6. **结局设计的情感落点**
   - "结局设计"字段是否真给出**情感落点**（观众离场记住的情绪 / 意象 / 反差）
   - 不能是"故事结束 / 主角离开"等仅完成事件的收束
   - 结局是否与开场策略呼应（埋的钩子在结局是否兑现）
