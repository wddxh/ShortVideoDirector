# Series Mode: director-review-outline 专属指南

## 额外上下文读取
- `story/arc.md` 存在且已采用时读，核对本集节点与范围，不强制创建
- mode='continue-series': 读取相关既有剧本；`story/outline.md` 和上一集 `story/episodes/{prev_ep}/outline.md` 存在时可核对承接

## Review 项 (逐项检查)

作为可选规划 review 的 mode 指南，遵循共享独立性与只写受托记录边界。结尾按确认意图验收，续集悬念、开放结尾和终章闭合均可，不强制每集制造钩子。

1. **节奏角色分布合理性**
   - 场景节奏角色是否准确描述功能，信息、压力与情绪有可感知的变化，不要求每类标签齐备
   - 持续冲突也需策略或代价变化；长铺垫应积累期待，避免重复挤掉关键回应
   - 一场景只挂一个节奏角色（与公共规则呼应）

2. **场景数量合理性**
   - 与 config.md 中"每集时长 / 场景数量目标"匹配
   - 用事件承载、反应空间与转场成本判断是否过载或碎裂，场景数本身不是失败依据

3. **与 arc 节点契合**（仅已采用 arc 时）
   - "在 arc 中的位置"声明的节点是否在 arc.md 中存在
   - 当前 ep 编号是否落在该节点 `(epXX-YY)` 集数范围内
   - "本集对节点的推进" 是否真在场景中兑现，例如选择带来关系或认知变化，不限句数
   - mode='continue-series'：本集场景是否与上集集尾钩子自然承接，是否引入与 arc 冲突的新元素

4. **新增 asset 合理性**
   - 按剧情自由安排, 不设硬阈值（character / location / item / building 数量任意）
   - 新增角色是否对本集叙事必需，能否复用已有角色

5. **asset dangling reference**
   - 场景中出现的所有 character / location 必须 ∈ (assets/ 已注册 ∪ 本集新增资产清单)
   - 列出所有 dangling 引用

6. **跳跃式开场承接合理性**
   - 若"开场策略"或场景 1 用高潮/悬疑跳跃式抓人
   - 观众需要理解时，应有足够的时空、人物目标或因果线索；可通过回溯、意象或后置揭示建立联系，不强制场景 2 加解释桥。有意硬切日常可以制造反差，实际失去理解依据才列问题

7. **arc 必需事件覆盖**（仅已采用 arc 时，按分配到本集的事件验收）
   - 对照 arc.md 当前节点的"必需" bullet 列表（每条 `(~Ns, 必需)`）
    - 逐项确认分配给本集的必需事件在 outline 中可识别，不要求每集重复多集节点全集：
     - 形式一：有专门场景对应该事件
     - 形式二：被分散吸收到其他场景的动作/铺垫中（rules.md `## 时长规划原则` #1 允许）
   - 任何丢失（既无场景也无分散载体）→ FAIL，意见列具体丢失事件
